◆ nx_eth_port_apply_link()

nx_result_t nx_eth_port_apply_link ( const nx_eth_port_t * port,
const nx_eth_link_t * link )

Apply external PHY observations, not auto-negotiate or invent link.

Parameters
[in]portSerialized task-owner face.
[in]linkObserved up/speed/duplex fact, never a guess.
Returns
Success, BUSY until real drain, or STATE/IO/context error.
Note
Task owner; changing speed/duplex first requires explicit link-down and observed idle TX/RX engines and FIFOs. BUSY keeps the old mode. Reapplying an unchanged up fact is idempotent. Link-down closes admission and drains pending TX with IO; later up requires real quiescence. This is not a PHY power/reset/electrical proof.

Close TX admission and drain the shared TX engine without replay.

Parameters
[in]portSerialized task-owner face.
[in,out]requestLive request accepted by this instance.
Returns
Success requests drain; STATE for a foreign request.
Note
Task owner. Cancel is controller-wide: other pending TX requests also become CANCELLED. It never revokes a borrow. Stuck sources quarantine. Apply a confirmed link again after successful drain to reopen TX.

◆ nx_eth_port_stop()

nx_result_t nx_eth_port_stop ( const nx_eth_port_t * port)

Close admission and withdraw MAC/DMA/IRQ sources with readback.

Parameters
[in]portLive face and all storage, including held loans.
Returns
Success releases sources; BUSY/IO retain remaining ownership.
Note
Task owner. Closing rejects new RX loans; existing loans still release. BUSY retains hardware/storage/wake ownership; timeout quarantines pending TX. Held RX loans remain valid and must be released before SUCCESS. Caller joins IRQ/consumers before reclaiming storage.

nx_result_t nx_eth_port_submit ( const nx_eth_port_t * port,

Admit one frame into caller-owned hardware descriptors.

Parameters
[in]portStable face and live private assembly.
[in,out]requestPrepared storage borrowed on acceptance.
Returns
Success means ACCEPTED; BUSY/STATE/IO/invalid inputs reject.
Note
Privileged serialized task, masks clear. SUCCESS is ACCEPTED. Borrow includes request and frame until acquire-observed SETTLED. Completion reports MAC wire status, never delivery to another application.
