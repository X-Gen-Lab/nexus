void * item,
uint64_t deadline_us )

Receive one item; closed queues can still be drained.

Parameters
[in,out]queueLive queue
[out]itemAt least item_size bytes; valid only on SUCCESS
[in]deadline_usAbsolute CLOCK_MONOTONIC deadline or NX_DEADLINE_NEVER
Returns
SUCCESS, TIMEOUT, STATE (closed) or error
Note
An immediately available item can be received at an expired deadline. On failure the output is unchanged. Closed queues return STATE only after existing items have been drained.

◆ nx_native_task_join()

nx_result_t nx_native_task_join ( nx_native_task_t * task)

Join after requesting cooperative application stop.

Parameters
[in,out]taskStarted task; caller must not be the joined task
Returns
NX_SUCCESS only after pthread_join confirms execution exit
Note
May block until entry returns. No forced cancellation. Caller may release context, handle and stack only after success. One external owner serializes start/join; multiple simultaneous joiners and external pthread_cancel/detach are unsupported. Stop/join publishers before destroying their notification or queue storage.
