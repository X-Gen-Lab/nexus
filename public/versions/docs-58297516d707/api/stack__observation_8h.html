Read a bounded low-address paint prefix without mutation.

Parameters
[in]baseLive downward-growing stack region, caller-provenance.
[in]bytesOriginal positive painted region capacity in bytes.
[in]paintExact fill used before the region became active.
[out]outDistinct output, unchanged on invalid span or alias.
Returns
SUCCESS or INVALID, without allocation or retained pointers.
Note
Caller ensures this region is quiescent and painting had no live frames. No Arch/OS dependency or internal mask occurs. Work is at most bytes reads. Unwritten reservations or writes equal to paint can hide usage; this is not overflow detection. MSP qualification needs independently established boot paint and a quiescent sampling point. The span excludes current SP, all active frames and exception-stack reservation. It never paints or claims to read the physical MSP register.
