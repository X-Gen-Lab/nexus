◆ nx_freertos_secure_context_for_task()

nx_freertos_secure_context_t * nx_freertos_secure_context_for_task ( void * task)

Resolve a trusted, statically composed Secure task record.

Parameters
[in]taskOpaque identity supplied by the trusted NS kernel.
Returns
Prepared caller-owned metadata, or NULL when unauthorized.
Note
Secure application overrides the weak NULL default with an immutable mapping. Called with both PRIMASK states held; never dereference an NS-provided metadata pointer, allocate, block, discover objects, call a kernel or mutate mappings. The NS kernel and its SVC/PendSV are trusted: this mechanism does not authenticate an adversarial NS privileged kernel. NS Thread calls cannot spoof Handler origin.

Prepare exact Secure storage for one trusted task identity.

Parameters
[out]contextZero-initialized caller-owned Secure metadata.
[in]stackEight-byte-aligned Secure writable stack allocation.
[in]bytesWhole allocation, including eight-byte upper seal.
[in]taskOpaque NS task identity, never dereferenced here.
Returns
SUCCESS, INVALID, CONTEXT, STATE or BUSY.
Note
Secure privileged Thread startup/exclusive lifecycle owner. Both memory spans must be Secure, writable and disjoint. No NS task may run against this identity during prepare. Repeat prepare is rejected; epochs are never reset. No allocation, kernel operation or runtime registry is used.
