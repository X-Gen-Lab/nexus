nx_result_t nx_can_port_attach_wake ( const nx_can_port_t * port,
const nx_irq_wake_t * wake,
uint8_t syscall_ceiling )

Borrow an optional wake target after checking all four actual IRQs.

Parameters
[in]portSerialized task owner, started and masks clear.
[in]wakeImmutable target kept alive until successful stop/detach.
[in]syscall_ceilingAdditional numerical BASEPRI ceiling.
Returns
Success, BUSY while an earlier publisher is live, PERMISSION, INVALID or CONTEXT, with no new borrow on failure.
Note
No implicit OS policy; NULL detaches. Wake is only a hint. The sink must support both task service/cancel and configurable IRQ contexts.

Request abort without revoking a borrowed request.

Parameters

[in,out]requestLive request previously accepted by this instance.
Returns
Success requests drain; STATE for an unrelated request.
Note
Abort may race real transmission; observed TXOK remains SUCCESS. Failed abort remains QUARANTINED and must keep storage alive.

◆ nx_can_port_stop()

nx_result_t nx_can_port_stop ( const nx_can_port_t * port)

Close admission, abort TX and detach IRQ/RX publishers.

Parameters
[in]portSerialized owner; external observers must also join.
Returns
Success after hardware drain; BUSY retains requests/ring/wake loans.
Note
Never resets the shared primary controller to release a peer's loan. Retry after progress. Success ends provider access to RX/wake storage.
