nx_result_t nx_request_observer_sample ( nx_request_observer_t * observer,
nx_time_us_t now,
nx_request_observation_t * out )

Copy state and acquire-observed final result for exact epoch.

Parameters
[in,out]observerBound sidecar under caller serialization.
[in]nowSame monotonic domain as the request deadline.
[out]outDistinct output, unchanged on error.
Returns
SUCCESS, STATE for stale/released identity, INVALID or IO for reversed time; counters saturate without epoch reuse.
Note
Borrowed state exposes no speculative result/count. NULL slot, stale epoch and overlap reject before request access. This neither services hardware nor interprets deadline as borrow release. Caller guarantees binding storage lifetime. Output is disjoint from the complete descriptor and borrowed buffers; only the common request span is checked here.
