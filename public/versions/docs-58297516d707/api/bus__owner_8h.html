Establish the chain's unique admission.

Parameters
[in,out]ownerLive accepting adapter
[in,out]requestPrepared READY storage, retained until SETTLED
[in]operationExecutor-specific descriptor and payload storage
[in]completionOptional static caller wake port, or NULL
[out]ticketStable cancellation identity, valid on SUCCESS
Returns
SUCCESS means ACCEPTED; rejection retains zero references
Note
Task multi-producer context. Free-slot admission and FIFO insertion use constant metadata work under the guard. An exhausted epoch permanently retires its slot. Deadline includes queue residence. Caller must not modify request, operation or buffers after admission. A notification error after admission cannot change SUCCESS to rejection; executor must recheck/pump periodically.
