nx_result_t nx_exti_port_attach_wake ( const nx_exti_port_t * port,
const nx_irq_wake_t * wake,
uint8_t syscall_ceiling )

Attach or detach an explicit event/loss IRQ wake target.

Parameters
[in]portInitialized line, controlled by one task executor.
[in]wakeImmutable live target, or NULL to detach.
[in]syscall_ceilingOptional additional unshifted kernel-safe priority floor; cannot weaken generated policy. PRIMASK kernel targets require zero. Ignored without kernel calls.
Returns
Success or CONTEXT/STATE/PERMISSION/UNSUPPORTED.
Note
Actual shared-vector priority must satisfy the target. Stop and join publishers before freeing old target storage. Wake callbacks observe already-latched event or loss facts.

◆ nx_exti_port_stop()

nx_result_t nx_exti_port_stop ( const nx_exti_port_t * port)

Disable the line source, clear pending and drain its handler.

Parameters
[in,out]portExecution owner; consumer/writers must quiesce first.
Returns
Success proves no remaining accesses to event storage; BUSY or IO retains storage, wake targets and cleanup responsibility. Shared vectors preserve other lines.
Note
Failed withdrawal may already have disabled part of the source. Retry and observe success before reclaiming event or wake storage. Face and state remain live while a shared dispatch domain still refers to them.
