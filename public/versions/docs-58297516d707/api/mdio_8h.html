Read one Clause22 PHY register without retaining output storage.

Parameters
[in]portStable face and caller-owned execution context.
[in]addressClause22 PHY address, from 0 through 31.
[in]regClause22 register address, from 0 through 31.
[out]valueWritten only after timely observed completion.
[in]deadlineFinite absolute provider-clock deadline.
Returns
Success, BUSY without a new command, or timeout/input/context error.
Note
Serialized privileged task, incoming masks clear; finite absolute deadline in the provider clock. Address and register are 0..31. BUSY rejects before new MMIO effects; timeout does not pretend busy cleared.
