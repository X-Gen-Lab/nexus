Erase a whole physical sector range with pulse settlement.

Parameters

[in]offsetExact sector-start physical offset.
[in]lengthPositive sum of whole sectors.
[in]deadlineAbsolute deadline checked between erase pulses.
Returns

◆ nx_flash_port_program()

nx_result_t nx_flash_port_program ( const nx_flash_port_t * port,
uint32_t offset,
const void * data,
size_t length,
nx_time_us_t deadline )

Program aligned physical Flash and settle all hardware pulses.

Parameters
[in,out]portSingle execution owner with valid voltage/clock policy.
[in]offsetProgram-unit aligned physical offset.
[in]dataAligned-length input retained only until return.
[in]lengthPositive program-unit multiple.
[in]deadlineAbsolute deadline checked between hardware pulses.
Returns
Success or INVALID/TIMEOUT/IO. Return proves no remaining buffer/hardware access; an active pulse cannot be preempted.
Note
Task-only CPU-active operation. Product owns execution-from- Flash stall, watchdog and power-loss policy. No RAM fake on MCU.
