Detailed Description

Immutable complete-scan timing facts for the selected mode.

Note
sample_times are codes into sample_cycles, in channel order. scan_cycles includes each channel's sample and conversion. Clock declarations and cycle counts describe scheduling; they do not establish electrical accuracy or sample aperture timestamps. Arrays remain valid through provider lifetime.
