◆ nx_freertos_mpu_task_delete()

nx_result_t nx_freertos_mpu_task_delete ( nx_freertos_mpu_task_t * task)

Delete another isolated task after external users quiesce.

Parameters
[in,out]taskOwned live protected metadata; never the calling task.
Returns
Success, INVALID, CONTEXT or STATE with storage retained.
Note
One privileged lifecycle owner stops external access first. Single-core kernel deletion removes scheduler references synchronously. Self deletion is rejected; no hidden reaper.

◆ nx_freertos_mpu_task_start()

nx_result_t nx_freertos_mpu_task_start ( nx_freertos_mpu_task_t * task,
const nx_freertos_mpu_config_t * config )

Create an unprivileged task from exact caller-owned storage.

Parameters
[in,out]taskZero/live-free metadata in protected linker RAM.
[in]configValidated user entry, stack and data mappings.
Returns
Success or INVALID/CONTEXT/STATE/BUSY/IO before admission.
Note
Privileged Thread only, scheduler not suspended, no manual masks. Rejection retains no references and calls no kernel creation API. Actual linker bounds and MPU_TYPE are checked. Minimum creation capacity is 64 words; applications budget actual execution depth separately. No heap or object pool.
