Copy bounded stack paint facts using actual kernel identity.

Parameters
[in]bindingExact original TCB, stack and capacity, all live.
[out]outDistinct output, unchanged on rejection.
Returns
SUCCESS, INVALID, CONTEXT or STATE for a binding mismatch.
Note
Privileged unmasked running Thread; task stack quiescent throughout the scan. Available only with NEXUS_OS_TRACE. xTaskGetStaticBuffers verifies TCB/stack identity, not size. The original capacity is a caller contract. No task suspend, interrupt mask, allocation or live painting is performed. Worst-case work is words*sizeof(StackType_t) byte reads. Paint is the locked kernel's 0xA5. Untouched/touched bytes do not prove physical stack peaks. The POSIX kernel port uses a separate pthread execution stack; its query is not an MCU or Linux execution-stack peak measurement.
