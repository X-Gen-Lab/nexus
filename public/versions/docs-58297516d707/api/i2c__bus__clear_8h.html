Retry only retained STOP cleanup and ownership return.

Parameters
[in,out]clearInitialized session with a retained lease.
[in]deadlineNew finite absolute cleanup deadline.
[out]resultPreserved primary/pulse count and latest cleanup.
Returns
Latest cleanup result; INVALID/STATE rejects without effects. A proved STOP is not repeated after release fails. Failure retains the lease and must not trigger a new clear or transaction. Success does not change a failed primary operation into success.

◆ nx_i2c_bus_clear_run()

nx_result_t nx_i2c_bus_clear_run ( nx_i2c_bus_clear_t * clear,
nx_time_us_t deadline,
nx_time_us_t cleanup_deadline,
nx_i2c_bus_clear_result_t * result )

Clear one idle, authorized bus with at most nine pulses.

Parameters
[in,out]clearInitialized session with no retained lease.
[in]deadlineFinite absolute primary-operation deadline.
[in]cleanup_deadlineFinite absolute STOP/lease deadline in the same clock domain, at or after deadline.
[out]resultIndependent primary/cleanup and retained effects.
Returns
Primary failure, otherwise cleanup result. Invalid inputs and an existing lease reject without callbacks or changing result. An expired primary deadline has no pin effects. Each released SCL must be physically HIGH before timing its high period. A frozen/reversed clock reports IO and exits rather than spinning. Every acquired attempt performs explicit STOP cleanup under its independent budget; failed STOP or release method retains the lease. If release succeeds after its deadline, cleanup reports TIMEOUT with lease_held false to preserve actual returned ownership. It never replays the failed I2C transaction or retries recovery pulses.
Note
Task-only, all other bus users quiescent. Timing evidence and actual open-drain behavior require physical HIL.
