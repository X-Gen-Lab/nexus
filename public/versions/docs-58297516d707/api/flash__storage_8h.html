nx_storage_port_t * port )

Bind an explicit writable uniform-erase physical region.

Parameters
[out]adapterUnused caller storage kept through all store calls
[in]regionExternally selected writable physical region
[in]deadlineAbsolute whole-transaction deadline for mutations
[out]portNarrow synchronous persistent port, valid on SUCCESS
Returns
SUCCESS or INVALID/PERMISSION/UNSUPPORTED geometry error
Note
Task-only, serialized caller. No region is reserved by the platform. Mixed sector geometries require another explicit storage adapter; this one rejects them. IO pulse settlement guarantees sync durability; no caller buffer survives a port call. Physical power-loss remains unqualified.
