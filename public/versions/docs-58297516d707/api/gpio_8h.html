nx_result_t nx_gpio_port_write ( const nx_gpio_port_t * port,
uint32_t set_mask,
uint32_t reset_mask )

Atomically set/reset one port's authorized output mask.

Parameters
[in]portFixed initialized binding, no registry or OS lock.
[in]set_maskAuthorized bits to set.
[in]reset_maskAuthorized bits to reset; disjoint from set_mask.
Returns
NX_SUCCESS or INVALID/PERMISSION before any register write.
Note
Task/IRQ bounded, no wait. One serialized writer owns the binding. Stop/mode changes require writers and IRQ quiescence.
