Parameters

◆ nx_spi_endpoint_submit_memory()

nx_result_t nx_spi_endpoint_submit_memory ( const nx_spi_endpoint_t * endpoint,
nx_spi_request_t * request,
uint8_t memory_flags )

Submit explicit incrementing or single-cell DMA memory.

Parameters
[in]endpointInitialized single-executor DMA endpoint
[in,out]requestREADY request with two non-NULL caller addresses
[in]memory_flagsTX_FIXED repeats one immutable dummy byte; RX_FIXED repeatedly writes one caller-owned discard byte; zero uses complete incrementing TX/RX buffers
Returns
ACCEPTED on SUCCESS; other results retain no references
Note
Fixed directions require one byte, other directions length bytes, within reviewed DMA domains. The actual spans must not overlap. All addresses remain borrowed through drain until acquire-observed SETTLED. No hidden scratch is used. Both fixed flags permit explicit clock-only transfers. Request preparation does not retain these flags; only this successful admission selects them. Ordinary submit and the existing owner continue their ordinary buffer contract.

const uint8_t * tx,

nx_time_us_t deadline,
size_t * transferred )

Execute one bounded full-duplex 8-bit polling transaction.

Parameters
[in]endpointFixed CS/mode/rate binding on one controller.
[in]txTransmit bytes, or NULL to send 0xff.
[out]rxReceive bytes, or NULL to discard.
[in]lengthPositive transfer length; at least one buffer exists.
[in]deadlineAbsolute deadline; includes adapter queue residence.
[out]transferredComplete bytes; reset to zero before execution.
Returns
Success, BUSY/INVALID/TIMEOUT/IO. Return releases all buffers and CS after drain; polling is CPU-active, not IRQ/DMA async.
Note
Task-only single executor, no allocation/OS lock. One CS interval covers the entire transfer. Deadline cannot preempt an in-flight hardware byte; peripheral drain may exceed it.
