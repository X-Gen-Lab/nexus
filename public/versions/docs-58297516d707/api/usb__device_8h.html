◆ nx_usb_device_stop()

nx_result_t nx_usb_device_stop ( const nx_usb_device_port_t * port)

Disconnect, disable, drain, detach IRQs, then release clock consumer.

Parameters
[in]portSerialized owner; external observers must also join.
Returns
Success ends provider access to endpoint/ring/wake storage; BUSY retains all storage and 48MHz ownership until actual progress.
Note
PIO OUT0 may remain enabled: successful global stop proves disconnect, OUT NAK, no DMA, empty RX FIFO, IRQ withdrawal and publisher join before final SETTLED. No forced reset revokes an unproved accepted borrow.

nx_result_t nx_usb_endpoint_cancel ( const nx_usb_endpoint_port_t * port,
nx_usb_request_t * request )

Request endpoint disable/drain without revoking a buffer loan.

Parameters
[in]portSame serialized privileged task owner.
[in,out]requestLive request accepted by this exact endpoint.
Returns
Success requests drain; failures retain all prior accepted loans.
Note
Control OUT0 has no hardware disable command: cancellation may require full device stop to settle. Missing proof becomes QUARANTINED. Reset/SETUP invalidates epochs but releases only after actual source drain.

Admit one packet, never a hidden queue or complete USB transaction.

Parameters
[in]portStable endpoint face and private state.
[in,out]requestREADY packet, buffers alive until acquire SETTLED.
Returns
Success means ACCEPTED; fourth-party buffers are not copied early.
Note
One privileged task executor, IRQ masks clear. IN FIFO writes do not prove host ACK. OUT overrun drains all packet words without overflow.
