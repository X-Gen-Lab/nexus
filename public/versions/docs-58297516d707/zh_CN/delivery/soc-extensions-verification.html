公共设备架构仍为静态类型化工厂与不可变多态接口。Factory 获取不分配、不启动硬件、不加锁。新模式扩展选中的私有 provider 和配置事实，不增加运行时 registry、隐式 worker 或必需 OS 层。

H743 DMA 借用 request 和 payload 到 acquire-observed SETTLED。启用 Cache 时，调用者须独占完整对齐 cache line；provider 不向外取整触及相邻分配，也不分配 bounce buffer。取消和超时不撤销借用，无法撤回硬件引用时保留隔离中的存储。

U575 参考只接纳固定 TZEN=1 boot profile 和不可变的非特权 NonSecure Thread，没有 NS 中断、RTOS 或并发 DMA。改变归属前先清零并验证未来 NS RAM，再检查最终保护状态，经实际编译器 CMSE 序列进入。同步 gateway 复制有界输入并在发布前检查输出。它不实现通用异步跨域借用、任意 userspace 任务、产品认证或安全升级。见完整合同。

证据规则¶

行为变更的普通 commit hooks 执行完整 GoogleTest／GoogleMock、配置和工具测试。正式资格另外绑定干净 canonical commit/tree、实际 compiler 输入、原始命令输出、配置和链接产物。失败尝试保留为失败；源码改变后需要新的源码绑定执行。

验证发现 H743 ARM 启动测试缺少生成头输入、CPU 配置测试固定虚拟环境路径、串口噪声测试不受控调度假设，以及静态分析丢失 forced-include 上下文。Sanitizer 还发现主机模型寄存器 mask 宽度转换和依赖信号的终止观察者。回归保留真实编译器警告和生产非返回循环；观察者必须不依赖循环中的信号投递点。GCC 13／LP64 sanitizer 主机还要求 U575 生产时钟和 MPU mask 在位操作前明确 32-bit operand。独立比较在归一化 __FILE__ 后发现被测旧／新 translation unit 的 ARM 已分配 section 相同；这是限定范围的代码和存储比较，不是实测 cycles 或所有编译器保证。回归及最终状态归入交付索引，关闭这些问题不能用 suppression 或跳过测试替代。

离线候选覆盖 H743／U575 维护中的八个公开组合：empty／IRQ-UART 与裸机／FreeRTOS。各自要求两次全新断网构建和实际 ELF／BIN 字节比较，并保留两份 map 及日志。H743 cache／DMA 夹具和 U575 配对参考具有各自 ARM 证据，不属于八个单镜像候选。无签名软件候选不是产品发布或物理资格。

持久证据¶

本地归档为 /workspace/nexus-soc-delivery-98270512/platform-evidence.tar.gz：1,269,027,807 bytes，SHA-256 3aae3a6b96701ce1a042cb4e43078d00d59ba5460ebc4816fa68e2fe4a8fe41c。内嵌 delivery-manifest.json 和外部清单描述 216,230 项，含 173,376 个普通文件。原始 raw path 和记录字节不变。在 platform/ 下解析最终执行根；其他根和嵌套 Native／source 归档有显式成员映射。结果索引绑定归档、清单和校验回执。独立流式审查从保留归档字节检查每个外层成员、八个候选 payload 闭包、三个嵌套 Native／source 归档及精确源码身份，没有完整解包或原始根回退。

将八个候选复制到独立全新目录并禁止访问原始 evidence、SDK、OCI、ARM 工具根后，均实际通过校验，原始路径读取尝试为零。这验证打包证据闭包；重建仍需提供记录的外部 OCI 和 GNU Arm 工具链，二进制未嵌入。此本地归档不是已发布 GitHub Release asset 或已签名产品发布。

剩余验收¶

SOC-28 至 SOC-32 和 SOC-36 是精确的部分参考，原始硬件、外设、隔离退出条件保持开放。SOC-33 bootloader／运行态交接、SOC-34 动态变频、SOC-35 连续计时 deep STOP 未实现。SOC-37 至 SOC-55 提供 station、准入、采集和结果校验工具；物理执行等待设备。

固定时钟不建立 DVFS，普通 WFI／tickless idle 不建立 deep STOP。主机模型和链接 ARM 镜像不建立电气、硅片 DMA／cache 一致性、TrustZone 隔离、中断延迟、实测功耗或 WCET。应用、PCB 专有政策与恢复由外部工程负责。
