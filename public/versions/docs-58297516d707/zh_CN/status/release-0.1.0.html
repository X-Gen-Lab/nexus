Nexus 0.1.0 Source SDK 开发者预览版¶

Nexus 0.1.0 是首个公开的平台 Source SDK 开发者预览版，日期为 2026-10-15（Asia/Shanghai）。接入消费工程前，请使用本页核对软件范围、必需输入和发行证据。所有 MCU 实板 HIL 结果仍为 not_executed。

源码与兼容性¶

发行资产清单和 SDK manifest 标识实际发布的 commit／tree 与字节。文档包独立记录 documentation_source、code_source 和历史 qualified_code；发布不会把旧软件资格转移到新源码。这些身份规则见软件验证。

dependencies/platform-compatibility.json 是唯一人工维护的语义版本策略。CMake、生成头文件和已安装包元数据从中派生 0.1.0。消费方请求 find_package(Nexus 0.1.0 EXACT CONFIG REQUIRED)。源码接口 epoch 1、authored TOML schema 2 和仅源码 SDK 的精确匹配保持各自独立且不变的合同。SDK 不承诺稳定二进制 ABI；平台、生成 bindings 和消费工程须使用相同的配置、编译器与 ABI 选择编译。

公开发行前的源码快照使用 1.0.0。它们保留历史源码身份，不会变成 0.1.0 包。2026-01-12 的第一阶段更新日志是早期开发里程碑；2026-10-15 发行盘点时未观察到对应的公开平台 GitHub tag／release。

必需的包与工具输入¶

使用干净且已提交的源码 SDK，并包含完整固定递归依赖、已审查厂商导入和许可／notice 闭包。其 .nexus-source-sdk.json 记录源码 commit／tree、依赖身份、完整文件哈希和导出的 CMake 包哈希。脏工作树的 --development-fixture 不可发布。

维护的软件交付路径使用 Linux x86_64。请阅读本次发行实际的工具版本和命令 receipt，确认所执行的 Python、CMake、Ninja、Native 编译器、GNU Arm 发行物和任何 OCI 身份。仅有最低版本声明和锁文件不能证明安装、消费工程执行或离线复现。较早的 Linux／CP312 证据不建立 CP311 离线安装或 Windows/macOS 集成执行。

从 checkout 开始时，使用源码设置指南。对于已安装前缀，遵循搬移后 SDK 教程及包内维护的核验命令。消费工程配置必须拒绝已变更的 manifest、错误源码 pin、不同的精确版本或无效装配，不能静默选择另一块 Board 或其他模式。

核验发行字节与实际结果¶

  1. 阅读发行资产清单，保留公开归档的大小和 SHA-256，并在解包至新目录前核验下载归档。保留这些哈希以及不可变源码和资产位置。

  2. 针对该精确前缀执行 SDK 的完整 manifest 核验器和真正独立、搬移后的消费工程。检查记录的 argv、退出码和原始日志。Native 执行与 ARM 链接／资源检查分别建立范围；缺少工具、空报告或仅跳过的结果均不能通过。

  3. 将源码、配置、依赖、实际执行的工具与产物哈希逐一对应到资格声明。若提供参考固件，检查其精确 ELF／BIN／map 和资源记录。只有针对相同绑定输入实际执行两次全新断网构建，才能声明离线可复现。

  4. 若提供 provenance bundle，阅读实际 bundle 及其 subject 身份。文件摘要检测字节变化；无签名校验和不构成发布者认证或产品发行签名。

  5. 物理验收须独立进行。软件模型、ARM 链接、SDK 消费工程和文档发布不会观察 Board 接线、供电、硅片修订、时钟精度、IRQ/DMA 时序、Cache 一致性或 TrustZone 隔离。

这些是核验要求，不是编造的执行 receipt。本次发行的实际结果文件决定哪些软件范围已执行。已有失败尝试和历史源码 ID 保持不变。

历史候选可取得性与剩余验收¶

正式构建系统基线仍为 cc6a065c；较早 SoC 基线独立记录。其八个无签名 H743／U575 候选只选择 HSI64／Cache off 或 MSIS4／TZEN=0、empty／IRQ-UART 以及裸机／FreeRTOS。它们不使本次新发行源码或更广的 Cache／DMA／双域夹具获得资格。

2026-10-15，八个候选归档在原始结果索引记录的路径均不可取得。其 candidate-archives 目录是指向不存在的搬移路径 /tmp/nexus-docs-polish-20261014/relocated-historical-cache/candidate-archives 的符号链接。历史归档核验 receipt 仍是原执行的证据，但不会使归档字节当前可取得。原索引未被改写。将这些历史归档作为可下载发行资产提供前，须恢复并重新核验逐字节相同的副本。

该基线的完整 72 阶段单次调用、OCI recipe 重建、CP311 离线安装、Windows/macOS 集成和外部示例升级在该记录中仍未执行。边界明确的源码预览版可以保留这些限制。源码／接口变更仍需适用的全新软件检查；旧测试数量不能替代这些检查。
