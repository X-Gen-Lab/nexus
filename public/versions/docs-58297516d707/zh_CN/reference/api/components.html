typedef struct nx_clock_lease nx_clock_lease_t¶

一个稳定、调用者拥有的消费者 token。

备注

Zero-initialize before first acquisition. On SUCCESS the provider borrows this exact object; do not copy, mutate or reclaim it until release succeeds. Internal fields are not application controls.
