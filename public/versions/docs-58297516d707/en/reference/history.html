How old addresses are handled¶

The URL migration table lists legacy RST paths, languages and target pages. Old en/ and zh_CN/ addresses remain separate. Public site root api/index.html is a historical API boundary entry directing readers to confirm the version before choosing migration guidance; it cannot silently mean the current API. Current public APIs live within an immutable version at the site-relative path versions/<release_id>/api/index.html, or at api/index.html under an extracted offline package root. Always identify the enclosing version root when interpreting an address. Legacy HAL/OSAL/Kconfig paths with different semantics enter this page to establish their version boundary before migration. Equivalent entries from the preceding simplified Sphinx site can enter corresponding current pages. Aliases are local HTML with relative links, without JavaScript, CDN or external redirection services.

The page migration and authority map records source pages, authority, reader tasks, actual site destinations and retention rules. Preserve original contract and result paths, linking originals or derived views rather than creating a second status or specification authority. Subsequent path changes update mappings, navigation, aliases and offline checks together.
