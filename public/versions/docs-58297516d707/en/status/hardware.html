First physical-board acceptance sequence¶

  1. Check the exact PCB, option bytes, electrical conditions, safe initial levels and clock; do not guess wiring.

  2. Bind actual probes, serial ports and required waveform/power-cut instruments to the station.

  3. Fix the source, resolved configuration, tools and candidate ELF; use actual budgets.

  4. Acquire raw observations and exercise failure paths for the selected mode, retaining every failure and retry.

  5. Assess qualification for that exact tuple. Controllers, modes or boards not executed remain unexecuted.

Tool source entry points are in the implementation map. Physical scope advances only after execution at a real station, never because of documentation publication, software CI or on-chip capability.
