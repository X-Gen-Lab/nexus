Current design and execution ledgers¶

Current code uses unified physical directories, TOML static assembly, typed factories and shared polymorphic tables. Public C11 faces contain only read-only ops and private context. Each instance owns independent state; callers supply request and block storage. SDKs/provider storage remain private and product projects external. Use these design contracts together with current delivery; historical documents establish no current qualification.

Distinguish development execution, clean software candidates and pending boards

Ledgers retain B0–B6 and original exit conditions, adding implementation_paths/evidence_paths, software_status and hardware_status. Implemented means mechanisms exist, not every exit passed. Development cannot replace clean-source SDKs, formal offline dual builds or candidate sealing. Formal NG028/030 executions update freshly generated evidence. Hardware is disconnected and all applicable physical items are not_executed. Glob denotes explicit directory families of one mechanism, not recursive discovery or default builds; X-Gen-Lab/nexus-examples paths belong to a separate repository.

CPU software covers M0/M0+/M3/M4/M7/M23/M33/M55/M85, selecting atomic backends, ABI, optional FPU/MVE/cache/MPU/SAU and baremetal/FreeRTOS ports through explicit CPU/IRQ facts. External CPU runtime generates no SoC/Board/factory. ThreadX maintains a separate explicit Native/M4 subset and inherits no nine-core FreeRTOS scope. See nine-core support for configurations and outstanding conditions. This does not expand whole-platform chip/board scope.

Launch boards are Qiming STM32F407ZGT6, SkyStar STM32F407VET6 and Liangshan GD32F470ZGT6, with baremetal/FreeRTOS, explicit ThreadX and Native models. New modes and G474/H743/U575 slices use their documented configuration, complete-image and SDK exits; public types do not imply whole-chip integration. G474 adds PA0/PA1 EXTI. H743 supports four HSI 32/64 MHz × Cache off/on startup combinations and finite DMA TX, without runtime reclocking or DMA RX. U575 TZEN0 and independent TZEN1 OS-free synchronous dual-world references remain separate; the latter is not generic dual-world factory, NS RTOS or asynchronous borrowing. SOC-33–35 remain unimplemented; SOC-36 remains partial; SOC-37–55 physical acceptance remains not_executed. Unreviewed physical PCB facts for all three Boards remain unknown; software fixtures are not physical routes. Roles follow the ten-person configuration: TL1, Core/I/O/OS2, BSP2, common applications/communications2, QA/HIL2, build/release1. Codex owns maintenance without named individuals. Remote branch protection needs independent GitHub verification and cannot be inferred from local role files.

Behavior changes follow RED → GREEN → REFACTOR. Host GoogleTest/GoogleMock tests execute real providers, factories and owners; configuration tools use Python unittest. Commit hooks and CI run the same gate; MCU targets link no test frameworks. Build-time resources, actual register models, ARM ELF budgets and physical HIL establish separate evidence; actual linked images measure method-table overhead.
