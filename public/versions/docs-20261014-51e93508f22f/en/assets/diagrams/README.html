FIG-05 Explicit start, stop and failure cleanup¶

Identity: current. Scope: Generated lifecycle skeleton; each SoC retains its own private startup/cleanup contract.

One external executor serializes start/stop. start does not start a scheduler; failures retain primary, cleanup and remaining_effects separately. Owners of acquired effects participate in reverse-order cleanup. Stop can release some instances successfully before returning BUSY/IO. BUSY cannot imply the platform is still fully running, and timeout does not permit storage reclamation. A concrete start_system failure may clean up inside its private path or retain the failed phase. Retry must satisfy that provider contract; the diagram is not a universal recovery API.

Sources: generated start/stop, cold GPIO lease, H743 cold lifecycle, current platform contract. editable DOT; Implementation item: DOC-47.

FIG-06 Core request states and borrows¶

Identity: current. Scope: Transitions and preconditions allowed by Core helpers; no promise of a recovery API for every provider.

REJECTED/ACCEPTED are admission results, not request states. After ACCEPTED, request/buffer borrowing continues; cancel/deadline only starts termination progress. The provider first drains every required reference, then release-publishes SETTLED as its final request access; the caller observes with acquire semantics. Related adapters/observers must exit separately. QUARANTINED to SETTLED is legal only after actual recovery and proof of drain. initialize cannot forcibly reset a borrowed object.

Sources: public request contract, actual Core transitions, final owner publication. editable DOT; Implementation item: DOC-48.

FIG-07 Finite UART and SPI DMA timing¶

Identity: reference. Scope: Exact finite F407 USART1/SPI1 DMA; Task/IRQ/DMA completion and failure paths.

Top-to-bottom order distinguishes Task, DMA IRQ and UART IRQ. UART DMA TC cannot replace TC for the final serial bit; completion of both SPI DMA streams cannot replace BSY=0/TXE=1. Final drain, error observation and reference withdrawal all precede SETTLED. CS nodes describe software commands and do not prove electrical levels or physical timing. Cancel/error paths require the same actual drain conditions; failure retains QUARANTINED borrowing. NDTR is not a reliable wire-byte count, and this view does not extend to GD32 reset semantics.

Sources: F407 UART DMA, F407 SPI DMA, DMA drain contract, multiple-controller contract. editable DOT; Implementation item: DOC-49.

FIG-08 Wait, wake and externally owned shutdown¶

Identity: current. Scope: ready-arm-ready-wait-ready and actual execution/join responsibilities.

nx_wait_until only checks a predicate and waits for hints; it neither services hardware nor creates a worker. Rechecking after arm prevents a lost wake. After TIMEOUT, a final true predicate still returns SUCCESS. The notification port requires one waiter. External shutdown first closes admission and requests cancel while keeping owner/IRQ drain progress alive. Join producers after their loans settle; confirm owner idle includes publication exit, then stop and join the executor. Next stop hardware RX/IRQ publishers, detach wake and join other publishers; only then destroy OS synchronization storage. Related observers need their final access to exit independently. A running kernel must retain its clock/Tick, and failed storage remains retained.

Sources: wait contract, production wait algorithm, owner interface, OS lifecycle. editable DOT; Implementation item: DOC-50.

FIG-09 H743 memory, DMA and cache¶

Identity: reference. Scope: Finite H743ZIT6 USART3 TX; complete 32-byte AXI SRAM lines.

Selected TX DMA authorizes only 512 KiB AXI SRAM; other physical domains and dma_engines reachability facts do not automatically authorize placement or power. Cache-on requires exclusive complete 32-byte lines, with a maximum of 65504 bytes; Cache-off accepts 1..65535 bytes. PREPARING establishes the borrow first; clean executes under the caller’s normal masks, and cancellation cannot reclaim storage before it finishes. This diagram neither implements nor claims H743 RX DMA; future RX needs separate pre- and post-drain maintenance contracts. Trusted reset or a prior successful owned clean/disable establishes cold caches; clear CCR bits cannot claim responsibility for foreign dirty state.

Sources: exact physical domains, H743 provider scope, TX DMA implementation, cache range contract, cold-cache contract. editable DOT; Implementation item: DOC-51.

FIG-14 U575 synchronous dual-domain reference¶

Identity: reference. Scope: Independent TZEN1 synchronous GPIO without OS; the default TZEN0 provider is unchanged.

FIG-15 Continuous RX and observable block loss¶

Identity: reference. Scope: Continuous F407 USART1 RX; preposted FIFO loans, loss and stop responsibilities.

Do not mix preposted and ordinary producers. Publish an old block in FIFO order only after it disappears completely from both hardware targets and CT/EN/new flags prove withdrawal. On failure, withdraw sources and release future loans in LIFO order; BORROWED consumer blocks must not be overwritten. Missing spare blocks, IDLE and recovery can cause gaps. lost_blocks counts observed boundaries, not exact missing wire bytes. A TC flag cannot count arbitrary coalesced wraps; actual IRQ/address-replacement latency must be shorter than one block fill time. stop closes admission and preserves drain. outstanding=0 still requires caller/observer exit. First-release ADC trigger blocks are explicitly rearmed by service and have gaps between blocks; this view does not claim continuous ADC.

Sources: UART DMA/continuous-loan contract, stream state contract, capacity and observation contract, F407 RX DMA implementation, explicit ADC rearm. editable DOT; Implementation item: DOC-57.
