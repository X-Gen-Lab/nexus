Configuration, development and evidence tools¶

Tools preserve actual process exits and input identities. A prepared plan is not execution evidence; a model pass is not physical qualification. Run maintained commands from the repository root with the selected tools on PATH.

Use the fixed source checkout guide before executing these tools; a default-branch clone may not contain the documented entry.
