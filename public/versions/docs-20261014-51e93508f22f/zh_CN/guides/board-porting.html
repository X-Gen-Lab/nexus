接入复核的 Board 包¶

精确 SoC 已有维护提供者时使用本指南。Board 增加 PCB 事实与复核绑定，不复制厂商 SDK，也不授权每一条硅片路由。实际未观察的 PCB 版本、焊桥和电压保持未知。

使用下面的解析器或构建命令前，先准备固定源码与递归依赖。

收集最小事实¶

记录完整料号、封装、来源文档版本和保留来源依据。记录晶振值、供电条件、SWD 预留、引脚、有效电平、跳线条件和安全初始输出。区分文档默认与这块实际板卡的观察。先接入一个 LED 和一条控制台路由。

通过实际解析器验证¶

从 Nexus 仓库根目录执行，编写前先检查已知合法参考：

python tools/configure/configure.py list-bindings     --assembly tools/configure/assemblies/qiming-baremetal-uart.toml
python tools/configure/configure.py check     --assembly tools/configure/assemblies/qiming-baremetal-uart.toml
python tools/configure/configure.py explain     --assembly tools/configure/assemblies/qiming-baremetal-uart.toml

自己的包在外部完整 assembly 中选择 board_package，以绝对 assembly 路径运行同样命令。相对包路径从人工编写的 assembly 定位。仅 JSON 语法检查不能证明 SoC 身份、时钟、路由或资源兼容。未知字段与未复核路由必须拒绝。

构建并记录选定范围¶

通过自己的 assembly 和锁定 ARM 工具链配置外部消费工程。裸机与 FreeRTOS 使用独立输出根。检查 resolved claim、向量表/startup、强符号处理函数、ELF/BIN/map 及每个物理 RAM/Flash 预算。Factory 在启动前查找必须纯净，实例状态必须独立。模型/链接测试使用软件 Board 夹具，并准确标注其接线性质。

无设备时准备 HIL 计划。物理资格要求独立复核工位、实际 Board/part/UID/探针/接线、精确镜像和真实原始测量。来源复核的焊盘不建立连接器连通、抗扰或安全电气行为。
