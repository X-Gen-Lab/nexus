配置、开发与证据工具¶

工具保留真实进程退出码与输入身份。准备计划不是执行证据；模型通过不是物理资格。从仓库根目录运行维护命令，并将所选工具放在 PATH 上。

执行这些工具前使用固定源码取得指南；默认分支克隆可能没有文档中的入口。
