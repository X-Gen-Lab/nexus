nx_adc_observer_t * observer )

Attach optional observer storage before acquisition starts.

Parameters
[in]portInitialized continuous provider, one task owner.
[in,out]observerInitialized stable caller storage, or NULL to detach. Provider validates exact stream count at start.
Returns
Success or BUSY/CONTEXT/UNSUPPORTED.
Note
Stop and join before detach/reclaim. No hidden allocation; polling and finite modes need no observation storage.

[in]wakeImmutable borrowed target or NULL to detach.

◆ nx_adc_port_stream_service()

nx_result_t nx_adc_port_stream_service ( const nx_adc_port_t * port)

Explicitly resume discrete block acquisition after consumer drain.

Parameters
[in]portSame single task executor as start and stop.
Returns
Success when an engine is armed, BUSY during source drain or free-block backpressure, STATE after acquisition stops.
Note
No task, retry or hidden rearm is created. Block modes state their trigger gaps; continuous zero-gap capture requires a separately declared hardware capability and qualification.

Start selected trigger/block acquisition with caller storage.

Parameters
[in]portTrigger/block-capable provider, one task executor.
[in,out]streamInitialized immutable-consumer block mechanism.
[in]trigger_hzPositive requested complete-scan rate; provider rejects rates outside its declared timer/ADC capability.
Returns
Success or INVALID/BUSY/UNSUPPORTED before buffer admission.
Note
Blocks contain native uint16_t raw counts in channel order. Capacities and lengths are multiples of a complete scan; DMA domains/alignment and physical rate require separate evidence.
