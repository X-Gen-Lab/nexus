Parameters
[in]portLive single-waiter notification port

[in]deadline_usAbsolute deadline in port's clock domain, or NX_DEADLINE_NEVER; no wall-clock or relative values
Returns
NX_SUCCESS when predicate is observed true, including a final observation after TIMEOUT; otherwise port error
Note
Task context. No service, queue, callback dispatch or task creation is implicit. A shared-bus client must not use ready to service the controller; its execution owner must remain running during stop/drain.
