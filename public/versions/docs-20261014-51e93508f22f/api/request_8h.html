◆ nx_request_admit()

nx_result_t nx_request_admit ( nx_request_t * request,
nx_request_state_t state )

Establish the chain's unique admission and provider borrow.

Parameters
[in,out]requestREADY request; caller owns storage until SETTLED.
[in]stateQUEUED for adapter or ACTIVE for direct provider.
Returns
NX_SUCCESS means ACCEPTED. Any failure means REJECTED with zero retained references, payload access or residual effects.
Note
One serialized execution owner; validate hardware/buffers first. Multi-producer adapters hold their metadata guard across admission; concurrent admissions are unsupported.

◆ nx_request_settle()

void nx_request_settle ( nx_request_t * request,
nx_result_t result,
size_t transferred )

Release-publish SETTLED as the final provider access.

Parameters
[in,out]requestBorrowed storage after all sources have drained.
[in]resultFinal transfer result, not admission status.
[in]transferredValid transferred bytes/samples.
Note
Detach active/queued references and capture any static wake target first. No hardware/IRQ/deferred observer may access request or payload afterwards. Cancel/timeout alone do not satisfy this requirement. A failed drain stays QUARANTINED.
