◆ nx_log_stop()

nx_result_t nx_log_stop ( nx_log_t * logger)

Reject new writes and test whether the sink has exited.

Parameters
[in,out]loggerLive instance; external users must eventually join
Returns
SUCCESS when no sink call is active, BUSY while draining
Note
Task context. A stop caller may retry; no active sink call is forcibly cancelled. Join publishers before reclaiming logger/sink storage.

nx_log_level_t level,
const void * bytes,
size_t length,
nx_time_us_t deadline )

Write caller bytes, with no implicit allocation/formatting.

Parameters
[in,out]loggerLive instance
[in]levelMessage severity
[in]bytesMessage bytes, borrowed only during this call
[in]lengthByte count; zero permits NULL
[in]deadlineAbsolute deadline understood by sink
Returns
SUCCESS for filtered/sent bytes, BUSY for concurrent/recursive writes, STATE after stop, otherwise sink error
Note
Task multi-producer entry with nonblocking serialization. M0/M0+ use CPU-local saved-PRIMASK metadata exclusion and require privileged callers on one CPU. Sink calls run after restoring the incoming mask. This does not make NMI/HardFault or cross-security-domain writers valid. IRQ use is prohibited. Drop/retry policy remains with the external caller.
