Detailed Description

Caller-owned optional sidecar, fresh zero storage before bind.

Note
One serialized observer; no Arch/OS/SoC dependency or lock. Caller excludes slot bind/release, request prepare/reuse and concurrent observer calls during sample. Stable slot stays alive until detach; observing never acquires/releases a loan.
