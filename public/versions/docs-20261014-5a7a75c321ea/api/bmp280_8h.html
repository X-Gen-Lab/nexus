Poll conversion without an implicit worker or blocking delay.

Parameters
[in,out]deviceInstance with a previously started conversion
[out]sampleWritten only on SUCCESS
Returns
SUCCESS, BUSY while converting, TIMEOUT or transport error
Note
Task-only. Every port call releases temporary buffers before return. BUSY retains device conversion state, never stack or caller buffers. After terminal failure, begin may retry; the external owner chooses policy.
