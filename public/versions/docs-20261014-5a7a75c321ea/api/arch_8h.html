◆ nx_arch_cycle_snapshot()

bool nx_arch_cycle_snapshot ( uint32_t * cycles)

Snapshot an already enabled free-running cycle counter.

Parameters
[out]cyclesDWT CYCCNT snapshot, unchanged when unavailable.
Returns
True when a maintained CPU counter is enabled; false on Native, an unreviewed/disabled/unavailable DWT, or an unprivileged caller. Does not enable/reset it. Only a reviewed CPU profile may read the optional DWT registers.
Note
Counter frequency follows CPU clock. Use unsigned snapshot subtraction only for intervals shorter than 2^32 cycles; this counter is neither shared monotonic time nor a deadline.

Query the exact current CPU exception identity.

Returns
IPSR exception number, zero for Thread mode or Native.
Note
Bounded read-only task/IRQ query. The identity belongs to the current CPU/security state; it is not a portable SoC IRQ number or evidence that a kernel ISR call is allowed.

◆ nx_arch_irq_is_masked()

bool nx_arch_irq_is_masked ( void )

Test masks that could prevent required completion progress.

Returns
True for PRIMASK, implemented BASEPRI/FAULTMASK, or Native thread nesting. Baseline Cortex-M cores query PRIMASK only.
Note
Bounded privileged task/IRQ query, no state change. ARM unprivileged reads do not establish the actual mask state.

◆ nx_arch_irq_save()

nx_arch_irq_state_t nx_arch_irq_save ( void )

Save incoming local mask and mask configurable exceptions.

Returns
Token to restore exactly once in reverse nesting order.
Note
Privileged Task/configurable-IRQ short metadata sections only; do not block, allocate, call OS functions, copy large buffers or invoke callbacks. NMI/HardFault remain unmasked. Native uses a recursive host exclusion model, not physical IRQ timing or signal safety. NMI/HardFault must not access shared metadata protected by this mask. ARM unprivileged callers need an explicit privileged gateway owned by their OS.

◆ nx_arch_is_privileged()

bool nx_arch_is_privileged ( void )

Query privilege in the current CPU execution context.

Returns
True in Handler mode or privileged Thread mode. Native always returns true because it has no CPU privilege model.
Note
Bounded read-only task/IRQ query. Handler privilege does not depend on the interrupted Thread's CONTROL.nPRIV. This query does not establish Secure-world ownership.
