Copy one event under a bounded saved interrupt mask.

Parameters
[in,out]ringInitialized ring.
[in]eventStable record until this call returns.
Returns
SUCCESS, BUSY when full, INVALID or CONTEXT.
Note
Privileged Thread/configurable IRQ on one CPU only. NMI/HardFault, unprivileged, SMP, DMA and other security worlds are excluded. Full rings retain older records and saturate the lost-record counter. No clock callback, OS operation, heap, string formatting or transport is used.
