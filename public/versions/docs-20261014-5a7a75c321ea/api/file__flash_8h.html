Open an exclusively locked persistent host Flash model.

Parameters

[in]pathRegular-file path; symlink traversal rejected
[in]sizeExact persistent byte size
[in]erase_sizeUniform erase block bytes
[in]program_sizeAligned program bytes, 1..256

OK or INVALID/IO; failed open retains no file descriptor
Note
Task-only POSIX model. Does not qualify MCU Flash or actual power loss; existing file size mismatch is rejected without truncation.
