Start explicit negotiation or fixed mode, never wait for fake link.

Parameters
[in,out]phyProved identity, kept live through operations.
[in]modeExplicit fixed mode or negotiation advertisement.
[in]deadlineFinite absolute MDIO clock deadline.
Returns
Success means configured registers; otherwise no configured truth.
Note
Task-only; identity must be proved. SUCCESS means registers configured, not autonegotiation complete. Failures retain configured=false.

Observe latch-low BMSR twice and DP83848 PHYSTS speed/duplex truth.

Parameters
[in,out]phyProbed and configured caller-owned component.
[out]linkObserved value, separate from component storage.
[in]deadlineFinite absolute MDIO clock deadline.
Returns
Success copies observed link; other results preserve output.
Note
Task-only; output changes only on SUCCESS. up requires actual link and complete autonegotiation when selected. Protocol or remote fault does not invent speed/link. MAC application remains an external action.
