Nexus platform documentation¶

Complete one task using the current reusable C11 platform. Product applications, scheduling policy, private PCB data and recovery policy belong in external consumer repositories. Source documentation, executed software evidence and physical board qualification remain separate.

The current implementation uses generated typed factories and immutable C interface faces. Factory lookup returns an existing static object; ordinary I/O goes directly through its operations table. Startup does not start a scheduler.
