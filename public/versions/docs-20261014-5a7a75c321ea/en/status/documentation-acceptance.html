在线阅读、离线包和长期证据¶

在线入口选择当前发布版本。不可变 versions/<release_id>/ 保留原字节；根目录旧书签显示准确的历史或当前合同说明。 旧 HAL／OSAL API 不会静默映射为当前接口。

文档发行说明 提供离线 HTML、完整文档工具缓存和执行证据的固定 commit 取得入口。实际长期 存储使用独立 Git 资产提交；Release 附件接口曾返回 401，未把 Git 文件写成已上传 附件。证据索引记录真实上传、重新下载及成员验真的结果，原失败尝试同时保留。

取得归档先核对 bytes／SHA-256。分片归档按记录顺序取得，每片不超过 32 MiB， 逐片验证后重组，再验证整包和 inventory 中的每个成员。归档中的 receipt 保留原 命令、退出码和原主机路径；portable locator 负责将这些路径映射到相对成员。 已单独保留的工具归档及文档包不在证据包中重复存储，明确的 exclusion 表逐文件 记录其摘要、不可变下载位置和归档成员，原执行记录完整保留。

原版本和资产 commit 由保留标签及后续提交保持可达；新版本新增身份，不替换同名 归档。维护者按发行说明保存独立副本。摘要用于检测字节偏离，不是数字签名。 具体拒绝规则见 文档交付合同。
