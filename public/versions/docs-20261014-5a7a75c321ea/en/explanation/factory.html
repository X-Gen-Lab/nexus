Typed factory, static instances and polymorphic faces¶

The current platform keeps typed factory lookup and C polymorphism. Configuration generates the exact instances; factory lookup returns them without constructing, initializing, locking or discovering anything. Hardware startup and request execution are separate explicit actions.

FIG-04 shows the current identity structure. A controller and a child endpoint have different interfaces and IDs even when their implementation shares a physical bus.

What generation owns¶

One schema-2 TOML selects instance names, bindings, modes and exact capacities. The strict resolver produces typed IR; emitters publish readonly faces, shared ops references, private independent contexts, fixed IRQ wiring and compact getters. Native assemblies receive independent model state too; a test singleton is not the production instance-generation mechanism.

nexus_factory.h is generated for each assembly, so its IDs are not a universal header or persistent numbering scheme. Default IDs are compact uint16_t aliases with named constants. COUNT, invalid and unselected entries return NULL. Optional nominal strong IDs and capability records are explicit configuration choices; a chip capability record does not grant Board routing or physical qualification.

What a call does¶

Action

Work performed

nx_factory_uart(id)

Select and return an existing readonly UART face

nx_platform_start()

Execute selected setup and retain cleanup outcomes

Public I/O operation

Validate face, then dispatch ops(context, ...)

IRQ entry

Access the fixed concrete provider and its owned hardware

Explicit service/wait

Advance or observe the selected lifecycle

Stop

Close/drain according to contract; cannot revoke outstanding storage

Products may retain a face for the provider-storage lifetime. Stopping hardware does not revoke a pointer or synchronize callers. The application must quiesce callers and publishers before reclaiming external adapter storage. No getter changes mode or silently acquires execution ownership.
