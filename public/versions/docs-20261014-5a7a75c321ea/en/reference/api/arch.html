atomic.h¶

Inline naturally aligned 32-bit publication and RMW ports.

Author

Nexus Team

Note

Storage is a live, naturally aligned uint32_t; all concurrent accesses use these helpers or compatible compiler atomics. Initialize before publishing storage. Load/store use compiler acquire/release operations on all maintained CPUs and never mask interrupts. Other than ARMv6-M, RMW uses compiler lock-free operations; exclusive instruction retries do not establish a fixed cycle bound.

Note

ARMv6-M RMW is CPU-local, bounded saved-PRIMASK exclusion. Only privileged Thread/configurable-IRQ contexts on one CPU may access this domain. NMI/HardFault, unprivileged callers, another core, DMA and another security domain must not access its storage concurrently. It is not an SMP or bus atomic operation. No callback, allocation, blocking call or payload copy occurs while masked.

nx_arch_result_t nx_arch_dcache_clean(uintptr_t address, size_t bytes)¶

Publish dirty data cache lines to the point of coherency.

Note

Privileged task/configurable-IRQ context in the current security domain only. The caller excludes other CPU, security-world and DMA users of every complete line until return, and keeps cache configuration stable. No hidden IRQ mask, allocation or cache enable occurs. Supported geometry is an explicitly reviewed 32-byte line; range rounding is forbidden. Work is bounded by bytes/32 and is not a DMA drain, device completion or transfer of ownership.

Parameters:

  • address – [in] First byte of exclusively owned complete lines.

  • bytes – [in] Nonzero whole-line length in the CPU address space.

Returns:

OK after maintenance and barriers; INVALID for partial lines or an overflowing/non-32-bit range; CONTEXT for an unprivileged caller; UNSUPPORTED for an absent or disabled reviewed cache. Rejection performs no maintenance writes.

nx_arch_result_t nx_arch_dcache_invalidate(uintptr_t address, size_t bytes)¶

Discard complete data cache lines without writing them.

Note

The caller permits all dirty data in these lines to be discarded and satisfies clean’s exclusion/context contract. No adjacent line is touched or rounded into the range. For DMA receive, providers coordinate both pre-DMA and post-drain maintenance; this call does not establish idle.

Parameters:

  • address – [in] First byte of exclusively owned complete lines.

  • bytes – [in] Nonzero whole-line length in the CPU address space.

Returns:

The same context, range and capability results as clean.

nx_arch_result_t nx_arch_dcache_clean_invalidate(uintptr_t address, size_t bytes)¶

Publish dirty data and discard the complete cache lines.

Note

Satisfies clean’s exclusion/context contract. Distinct from invalidate: dirty contents are written before discard.

Parameters:

  • address – [in] First byte of exclusively owned complete lines.

  • bytes – [in] Nonzero whole-line length in the CPU address space.

Returns:

The same context, range and capability results as clean.

nx_arch_result_t nx_arch_instruction_sync(uintptr_t address, size_t bytes)¶

Make a complete owned range coherent for CPU instructions.

Note

Satisfies clean’s exclusion/context contract. All present caches are checked before any maintenance. With only one reviewed cache, only that cache is maintained. The caller prevents execution from the changing range, including other security-world users. This is not code validation, an MPU policy change or a global cache/branch-predictor flush.

Parameters:

  • address – [in] First byte of exclusively owned complete lines.

  • bytes – [in] Nonzero whole-line length in the CPU address space.

Returns:

OK after data clean, instruction invalidate and execution barriers; INVALID/CONTEXT as above; UNSUPPORTED when both reviewed caches are absent or a present cache is disabled.

nx_arch_cache_control_result_t nx_arch_cache_cold_enable(nx_arch_cache_control_t *control, uint32_t mask)¶

Admit cold caches and enable the explicitly selected ones.

Note

Reviewed M7 only. Requires privileged Thread, PRIMASK=1, BASEPRI=FAULTMASK=0 and known-clean caches from a trusted reset or prior successful owned clean/disable. CCR bits being zero alone do not prove clean foreign state; never adopt an unknown bootloader state. Caller excludes all other cache users, DMA, NMI and HardFault access to affected memory throughout the transition. It owns memory attributes, execution and coherency policy; enabling a cache does not establish DMA coherence. No IRQ mask changes, allocation or cache adoption occur. Rejected initial admission has no retained responsibility. An IO failure can retain owned_mask/selector_pending; call cold_disable and retain storage until it succeeds.

Parameters:

  • control – [inout] Exclusively owned, initially empty control object.

  • mask – [in] Nonzero combination of DATA and INSTRUCTION bits.

Returns:

OK after verified enable and selector restoration; INVALID for arguments; CONTEXT for unsafe context; UNSUPPORTED for an unreviewed CPU/geometry; STATE for live/foreign caches; IO when a register write is not confirmed by readback.

nx_arch_cache_control_result_t nx_arch_cache_cold_disable(nx_arch_cache_control_t *control)¶

Clean and disable caches owned by this control object.

Note

Satisfies enable’s exclusion and context contract after every DMA/provider has drained. Rejects enabled caches outside owned_mask. The data clean/disable transition uses a stack-free leaf so no local dirty line can appear between the final clean and CCR update. Its bounded work is four ways times the verified set count, not constant latency. Failed operations remain retryable without adopting a new cache or forgetting the original selector. A zero object is an idempotent no-op on a supported CPU profile.

Parameters:

  • control – [inout] Same live object passed to cold_enable.

Returns:

OK only after cache disable and selector restoration; INVALID, CONTEXT, UNSUPPORTED, STATE or IO retain ownership.

nx_arch_result_t nx_arch_nonsecure_check(const void *address, size_t bytes, nx_arch_nonsecure_access_t access)¶

Check current NonSecure unprivileged access to a full span.

Note

Allocation-free permission observation only. Hardware CMSE checks both security attribution and NonSecure MPU rights as an unprivileged caller. Adjacent permitted regions may be conservatively rejected. No memory is copied, pinned or borrowed. Success neither authenticates a gateway caller nor proves RAM, DMA reachability, lifetime or fault safety. The integrating owner must exclude MMIO through its SoC RAM policy and prevent attribution/mapping changes through the subsequent access. Interrupts, another world, DMA and faults are not excluded here; no masks or hardware policy are changed. A gateway must separately snapshot its input and validate output before any irreversible operation.

Parameters:

  • address – [in] Non-null start; never dereferenced by this API.

  • bytes – [in] Positive length with a representable inclusive end.

  • access – [in] Exact READ or READWRITE access, never a bit mask.

Returns:

OK for complete current access; INVALID for malformed or denied spans; CONTEXT outside privileged Secure Thread; UNSUPPORTED in Native, single-state or NonSecure images.

nx_arch_result_t nx_arch_wait_for_interrupt(void)¶

Wait once with configurable exceptions already masked.

Note

Privileged Thread mode, incoming PRIMASK=1, BASEPRI and FAULTMASK clear. SCR.SLEEPDEEP must be clear. The caller owns the final readiness check and timer/wake source. WFI wakes for a pending enabled interrupt despite PRIMASK; the interrupt runs after the caller restores its saved mask. No register, mask, clock or pending interrupt is changed. Current CPU/security state only; no physical HIL claim.

Returns:

OK after wake, CONTEXT or UNSUPPORTED without sleeping.

nx_arch_result_t nx_arch_idle_if_unchanged(const uint32_t *sequence, uint32_t expected, bool *slept)¶

Atomically recheck a published sequence before WFI.

Note

Privileged Thread mode with all incoming masks clear. Saves PRIMASK, performs acquire observation under that mask, optionally sleeps, and restores the exact mask. Publishers must be same-CPU configurable IRQs or Threads; NMI/HardFault, DMA, SMP and other security-world publishers are excluded. The caller keeps storage alive, owns an enabled IRQ timer for finite deadlines, and retries the authoritative predicate after wake. Native is unsupported.

Parameters:

  • sequence – [in] Naturally aligned, shared 32-bit wake sequence.

  • expected – [in] Snapshot before the caller’s readiness check.

  • slept – [out] True only when WFI was executed.

Returns:

OK, INVALID, CONTEXT or UNSUPPORTED.
