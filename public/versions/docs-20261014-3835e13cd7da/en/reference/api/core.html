void nx_fault_observe(nx_fault_domain_t domain, nx_result_t reason, const char *file, unsigned line)¶

Observe a terminal fault before the caller retains effects.

Note

The weak default returns and has no state or side effects. A product may supply one strong implementation, bounded and allocation-free in every calling task/ISR/masked context. No functioning kernel, clock, stack, transport or peripheral may be assumed after corruption. This is best-effort observation, not stack repair, safe outputs or reset proof. The hook must not acquire OS locks, reenter the provider, change incoming masks, mutate accepted requests or release retained storage. If it returns, the terminal caller still parks. A product may perform a separately reviewed non-returning recovery action. No retained event, registry or worker is implicit.

Parameters:

  • domain – [in] Actual reporting path, not a severity assessment.

  • reason – [in] Observed failure, never permission to reclaim loans.

  • file – [in] Static source literal or NULL; do not retain or read untrusted dynamic memory. No task name is dereferenced.

  • line – [in] Diagnostic location, zero when unavailable.

NX_CORE_MEMORY_STRING_DETAIL(value)¶

Place static storage in an authored optional memory region.

Note

Use these attributes on variable definitions, before the type, one variable per declaration. They are not function or instruction attributes. Each use has an independent input section for garbage collection of unused storage. DATA copies its initializer from Flash at reset. BSS is zeroed at reset. NOINIT is neither copied nor cleared; initialize it before reading. Power-loss retention is not promised. BSS/NOINIT reject nonzero initializers. Storage is word aligned and subject to explicit ELF budgets. Unselected use is a compile error. TCM is CPU-only data: never DMA or executable storage. CCM is also CPU-only data; placement never grants bus-master access. ADDSRAM DMA requires provider address, alignment and ownership validation. Ordinary storage, the main MSP and unselected images keep their existing layout.

nx_result_t nx_stack_observe(const void *base, size_t bytes, uint8_t paint, nx_stack_observation_t *out)¶

Read a bounded low-address paint prefix without mutation.

Note

Caller ensures this region is quiescent and painting had no live frames. No Arch/OS dependency or internal mask occurs. Work is at most bytes reads. Unwritten reservations or writes equal to paint can hide usage; this is not overflow detection. MSP qualification needs independently established boot paint and a quiescent sampling point. The span excludes current SP, all active frames and exception-stack reservation. It never paints or claims to read the physical MSP register.

Parameters:

  • base – [in] Live downward-growing stack region, caller-provenance.

  • bytes – [in] Original positive painted region capacity in bytes.

  • paint – [in] Exact fill used before the region became active.

  • out – [out] Distinct output, unchanged on invalid span or alias.

Returns:

SUCCESS or INVALID, without allocation or retained pointers.

typedef uint64_t nx_time_us_t¶

Microseconds in one boot/clock domain; no wall-clock semantics.

Functions

nx_time_us_t nx_time_now_us(void)¶

Read the selected provider’s monotonic clock.

Note

Physical providers require successful platform startup and a privileged task/configurable IRQ; NMI/HardFault callers are unsupported. No OS, allocation or wait. Physical clocks return zero outside a successfully started live epoch; zero alone cannot prove readiness. Startup status is authoritative. All consumers join before clock withdrawal. Stop/restart or a clock change invalidates every old deadline, even if a new epoch has the same numerical value. UINT64_MAX is reserved; clock exhaustion requires controlled restart. An observed hardware overflow acknowledgement failure ends the live epoch and is terminal, even when finite source isolation succeeds. The provider retains ownership, masks interrupts, calls nx_fault_observe and parks if the observer returns. It never resumes deadline consumers with invalid zero time. Observation neither releases loans nor proves safe outputs; products own separately reviewed non-returning recovery. Ordinary shutdown still requires every consumer and optional low-power owner joined first.

Returns:

Microseconds since domain initialization.
