旧地址如何处理¶

URL 迁移表列出旧 RST 对应路径、语言和目标页。 en/、zh_CN/ 旧地址分别保留；根 api/index.html 已用于当前公共 API，不能覆盖。 旧 HAL／OSAL／Kconfig 等不同语义的路径进入本页，明确版本边界后再选迁移指南。 当前上一轮简版 Sphinx 同义入口可进入对应新页。alias 是本地 HTML 和相对链接， 不依赖 JavaScript、CDN 或外部跳转服务。

页面迁移与权威映射记录源页面、权威、读者任务、 实际站点去向与保留规则。原合同和结果路径保留，链接原文或派生视图，避免建立第二份 状态和规范。后续路径变化应同步映射、导航、alias 和离线检查。
