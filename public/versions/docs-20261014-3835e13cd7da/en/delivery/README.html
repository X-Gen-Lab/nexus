当前平台交付¶

默认实现统一为 Core / Arch / SoC / Board / 静态 factory / 多态 I/O / 可选 OS / 可选组件。一份 TOML 经严格校验和不可变 IR 生成精确实例；factory 返回稳定的 只读接口对象，共享只读操作表，独立状态留在 provider 内部。获取接口不启动硬件。 应用、产品任务、私有 PCB、Flash 分区、恢复与安全策略由外部工程维护。

文档系统的后续整理见 架构与交付规划。 对应文档工具、正文和图册已实现，实际文档验收与固件资格分别记录；当前资料总入口为 文档入口。

CPU 软件层覆盖 M0/M0+/M3/M4/M7/M23/M33/M55/M85。外部工程可通过一份 严格 CPU runtime TOML/事实包使用 nexus_add_runtime 或安装包的 Runtime component，复用 Core/Arch/I/O face 与选定裸机/FreeRTOS adapter。运行时装配 不生成 SoC、Board、启动或 factory，具体硬件、产品任务和安全策略仍由外部工程 负责。F407/F470 三板维护首发模式，G474/H743/U575 增加精确 GPIO／IRQ UART／ timebase 参考装配。G474 另有 selected EXTI，H743 另有固定 Cache 配置与有限 TX DMA，U575 另有独立无 OS 的同步双域参考；这些纵切片不代表全外设或完整 安全域接入，物理 HIL 全部未执行。

历史 SoC 扩展基线固定源码 98270512 已完成全部 Native 契约、工具和配置测试、121 个 ARM 镜像、104 个 CPU runtime 变体、SDK 独立消费及完整 GitHub CI。八个 H743/U575 公开参考配置分别完成两次独立断网构建，ELF/BIN 逐字节一致，并封存为无签名软件 候选；具体范围和原始证据见结果索引。后续文档提交只记录该源码，不继承为新的 代码执行资格。实板未接入，物理 HIL 均为 not_executed；运行态交接、DVFS 和 深 STOP 连续计时尚未实现，55 项原始退出条件保持不变。

本次构建系统交付绑定 cc6a065c，完整结果单独记录在构建结果索引，不能继承 上面的历史 SoC 执行身份。八个当前候选使用 H743 HSI64／Cache off 和 U575 MSIS4／TZEN=0 的 empty／UART、裸机／FreeRTOS 参考组合；这不扩大实板支持。 72 阶段软件总计划未作为一次完整 plan invocation 执行，OCI recipe 重建、 CP311 离线安装和物理 HIL 仍未执行。后续文档提交只记录其精确代码源码。

docs/archive/ 保留历史设计、结果和旧 Sphinx 教程，不能继承为当前支持或验收。 当前公共 API 文档只从现有公开 include 树生成；代码格式和反斜杠 Doxygen 风格保持 根 .clang-format、.editorconfig 与现有规范。

行为变更遵循 TDD。GoogleTest／GoogleMock 只进入 host 测试目标，生产固件保持 C11。commit hooks 实际执行完整 testing／configure／ci／workflows 四域工具测试 和全部 GoogleTest 契约，拒绝未完成、过滤或跳过的报告。执行结果证明当前合同；真实 RED→GREEN 过程由 PR 和原始日志记录。
