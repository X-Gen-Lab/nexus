Migrate legacy configuration and interface access¶

Use this guide to migrate an older HAL/OSAL/Kconfig consumer to the current Source SDK generation. Keep a fixed source revision while migrating. The platform retains typed factory plus C polymorphic interfaces; it changes instance generation and ownership rather than replacing interfaces with a runtime service registry. The compatibility contract owns version and interface epoch behavior.

From the repository root, execute the actual parser and generation path:

python tools/configure/configure.py check     --assembly tools/configure/assemblies/native-uart.toml
python tools/configure/configure.py generate     --assembly tools/configure/assemblies/native-uart.toml     --output /tmp/nexus-migration-config

Use a new output path you own. Check resolved.json and generated headers; never author the resolved output or reuse stale generated files after a failure. Legacy schema-1 JSON exists only for explicit migration fixtures. A failed TOML does not fall back to JSON, Kconfig, old headers or cache values.

Move access and lifecycle together¶

Use compact typed IDs from the current assembly and check getter NULL results. Getter names and ID constants are generated from authored instance names; IDs are not persistent IDs or a binary ABI. Optional nominal strong IDs and capability records require their explicit configuration. Start hardware through nx_platform_start() and inspect both primary and cleanup results. After successful startup, ordinary I/O uses the returned face directly.

Convert synchronous and asynchronous calls according to their actual mode. For accepted requests, migrate storage lifetime, service/wait progress, cancellation, settlement and shutdown together. The async tutorial executes these failure paths; replacing a function spelling alone is insufficient.

Build an independent relocated SDK consumer, then link the exact MCU configuration with the locked compiler. Retain evidence for the migrated source and configuration. Old HAL/OSAL documentation remains historical; a redirect does not make an old API contract equivalent to a new one.
