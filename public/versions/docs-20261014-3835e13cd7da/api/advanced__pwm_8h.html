nx_result_t nx_advanced_pwm_set_duty ( const nx_advanced_pwm_t * port,
uint32_t duty_ticks )

Stage duty against the fixed declared PSC/ARR and complementary pair.

Parameters
[in]portOne serialized privileged task owner.
[in]duty_ticksZero through the maintained period, inclusive.
Returns
SUCCESS or INVALID/STATE/CONTEXT; no base-clock reconfiguration.
Note
Shadow duty becomes effective at the next update. Hardware deadtime encoding must exactly represent the cold-configured tDTS count; PSC does not scale deadtime. This API does not certify pin timing.

Enable outputs only with inactive break and no latched fault.

Parameters
[in]portPrivileged task owner of reviewed pin/clock/vector leases.
Returns
SUCCESS or BUSY/STATE/IO/CONTEXT; failure retains ownership.
Note
Automatic output reenabling and irreversible hardware LOCK are prohibited. A break never silently starts outputs again.

nx_result_t nx_advanced_pwm_stop ( const nx_advanced_pwm_t * port)

Disable/read back master output and both channel sources.

Parameters
[in]portPrivileged task owner, no concurrent duty/lifecycle calls.
Returns
SUCCESS proves output source detachment; BUSY retains responsibility.
Note
Cold assembly keeps the reviewed inactive-pin and shared-vector leases until success and IRQ quiescence. A latched break survives stop.
