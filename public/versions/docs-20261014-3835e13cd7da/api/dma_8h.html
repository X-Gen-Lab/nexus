size_t count,

nx_dma_direction_t direction )

Validate an entire buffer within one explicit memory domain.

Parameters
[in]regionsImmutable SoC domains kept alive for this call.
[in]countPositive number of domains.
[in]dataNonempty caller buffer; never borrowed by this helper.
[in]lengthPositive byte length, including all DMA accesses.
[in]alignmentNonzero power-of-two transfer alignment.
[in]directionDevice reads or writes the supplied memory.
Returns
Success, INVALID for malformed ranges/alignment or PERMISSION for a range outside the required DMA domain.
Note
Bounded task/IRQ check, no MMIO, allocation or side effects.

◆ nx_dma_drain_check()

nx_result_t nx_dma_drain_check ( const nx_dma_drain_facts_t * facts)

Require engine, IRQ and peripheral drain independently.

Parameters
[in]factsProvider observations; not retained.
Returns
Success only when all sources are detached and idle, BUSY while any source remains, INVALID for impossible counters.
Note
The provider must observe actual registers and ordering before setting these facts. This helper does not stop hardware.

size_t count )

Reject duplicate physical streams in an assembled resource set.

Parameters
[in]resourcesImmutable resource list, not retained.
[in]countResource count; zero allows a NULL list.
Returns
Success, INVALID for a NULL nonempty list or reserved zero controller, BUSY for a duplicate physical engine.
Note
Cold conflict check; the selected SoC must validate all identities against its actual topology before using them. This helper does not infer silicon support or allocate.
