nx_storage_status_t nx_storage_open ( nx_storage_t * storage,
const nx_storage_port_t * port,
size_t offset,
size_t bank_size,
void * workspace,
size_t workspace_bytes )

Open/recover two externally supplied uniform erase banks.

Parameters
[out]storageUnused or quiesced instance, no concurrent calls
[in]portPersistent settled port, may be storage's existing port
[in]offsetErase-aligned start within port region
[in]bank_sizeEach bank's erase-aligned byte size
[in]workspaceCaller buffer, disjoint from instance/payload
[in]workspace_bytesAt least max(32, port.program_size)
Returns
OK for recovered/empty store, CORRUPT for ambiguous or only invalid committed generations, IO/INVALID for port/geometry failures
Note
Task-only bounded scan over both bank payloads. Workspace remains borrowed by the instance through every subsequent load/save call.
