◆ nx_timer_capture_start()

nx_result_t nx_timer_capture_start ( const nx_timer_capture_t * port,
nx_timer_capture_event_t * events,
size_t capacity )

Borrow an exact event ring and enable the fixed capture channel.

Parameters
[in]portOne privileged task owner, serialized with stop/read.
[in,out]eventsAligned writable ring, capacity positive.
[in]capacityNumber of events; no hidden buffer or worker.
Returns
SUCCESS transfers the ring borrow; rejection retains nothing.
Note
Ring remains borrowed until successful stop. ISR access is confined to this ring. Caller must not modify it or its provider while borrowed. Counter wrap is modulo the reported width; observation time is not an absolute edge timestamp or a clock accuracy qualification.

◆ nx_timer_capture_stop()

nx_result_t nx_timer_capture_stop ( const nx_timer_capture_t * port)

Disable and read back channel/IRQ sources before returning storage.

Parameters
[in]portPrivileged task owner, with generated IRQ owner retained.
Returns
SUCCESS is the final access to the ring; BUSY retains the borrow while queued events or failed hardware detachment remain.
Note
Read drains events after capture stops. Failed detach never frees storage. Board pins, timer clock and shared vector leases are released by cold assembly only after successful stop and publisher quiescence.
