Detailed Description

Task has its own TCB; stack is supplied with its actual word count.

Note
Control fields are adapter-owned. The caller zero-initializes storage before first use and does not modify live fields. Entry is consumed as the wrapper begins execution; context remains borrowed until successful join or prestart discard.
