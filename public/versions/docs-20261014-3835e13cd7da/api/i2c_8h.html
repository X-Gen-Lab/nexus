nx_result_t nx_i2c_endpoint_submit ( const nx_i2c_endpoint_t * endpoint,
nx_i2c_request_t * request )

Admit one finite asynchronous repeated-START transaction.

Parameters
[in]endpointInitialized fixed address and single executor
[in,out]requestREADY descriptor and all referenced storage
Returns
SUCCESS means ACCEPTED; rejection retains no references
Note
Selected modes declare DMA domains. DMA completion alone never establishes wire/STOP drain or borrow release. Any admitted abort requires explicit local recover before reuse; recovery never replays or pulses Board GPIO lines.

◆ nx_i2c_endpoint_transaction()

nx_result_t nx_i2c_endpoint_transaction ( const nx_i2c_endpoint_t * endpoint,
nx_i2c_message_t * messages,
size_t count,
nx_time_us_t deadline,
size_t * transferred )

Execute a polling 7-bit-address message transaction.

Parameters
[in]endpointFixed address/controller binding.
[in,out]messagesMessage buffers; write data are not modified.
[in]countOne through NX_I2C_MAX_MESSAGES.
[in]deadlineFinite absolute provider-clock deadline.
[out]transferredCompleted byte prefix across messages, including error returns.
Returns
Success or INVALID/UNSUPPORTED/CONTEXT/STATE/BUSY/TIMEOUT/ NACK/ARBITRATION/IO. Each message has 1..NX_I2C_MAX_MESSAGE_BYTES bytes; any message may read or write. Return releases buffers after STOP/abort drain. Controller settlement does not establish bus recovery.
Note
Task-only, one executor. No hidden scan or GPIO recovery. Failed bus recovery is never reported as transfer success.
