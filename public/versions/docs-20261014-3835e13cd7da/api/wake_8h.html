Deliver one bounded hint after authoritative state is latched.

Parameters

Returns

nx_result_t nx_irq_wake_validate ( const nx_irq_wake_t * wake,
const nx_irq_policy_t * policy,
const nx_irq_source_t * source )

Validate actual IRQ facts against an explicit kernel policy.

Parameters
[in]wakeOptional immutable target; NULL disables notification.
[in]policyImmutable validated CPU and kernel configuration.
[in]sourceExternal IRQ number, unshifted priority and group.
Returns
Success, INVALID for malformed facts/target, PERMISSION for a kernel-calling target in an unsafe interrupt domain.
Note
Cold check without attachment or callback effects. No kernel target is accepted by NONE. PRIMASK permits every valid configurable IRQ with its fixed zero priority group. Kernel-calling BASEPRI targets require the maintained preemption grouping and a numerical priority at least the ceiling. Nonkernel hints do not impose kernel grouping. Binding does not authorize future CPU-context violations.
