类型化 factory、静态实例与多态 face¶

当前平台保留 typed factory 查找和 C 多态。配置生成精确实例；factory 查找只返回它们，不构造、初始化、加锁或探测。硬件启动和请求执行是各自显式动作。

FIG-04 表示当前身份结构。Controller 与 child endpoint 有不同接口和 ID，即使实现共享同一物理总线。

生成器拥有的责任¶

一份 schema-2 TOML 选择实例名、binding、模式和精确容量。严格 resolver 产生 typed IR；emitter 发布只读 face、共享 ops 引用、独立私有 context、固定 IRQ 接线和紧凑 getter。Native 装配同样取得独立模型状态；测试单例不是生产实例生成机制。

每次装配生成自己的 nexus_factory.h，其 ID 不是通用 header 或持久编号。默认 ID 是紧凑 uint16_t alias 和具名常量。COUNT、无效和未选择项返回 NULL。可选 nominal strong ID 与 capability record 必须明确配置；芯片能力记录不授予 Board route 或物理资格。

产品可在 provider 存储生命周期内保留 face。停止硬件不会撤销指针，也不会同步调用方。应用必须确保调用方与 publisher 停止访问并完成必要同步，才能回收外部 adapter 存储。Getter 不改变模式或悄悄取得执行所有权。
