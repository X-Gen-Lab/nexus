Nexus 平台文档¶

使用当前可复用的 C11 平台完成一项具体任务。产品应用、调度策略、私有 PCB 数据和恢复策略由外部消费工程维护。源码文档、已执行的软件证据和实板资格分别记录。

当前实现使用生成的 typed factory 和不可变的 C 接口 face。factory 查找返回已有静态对象；日常 I/O 直接通过对象的操作表调用。平台启动不启动调度器。
