SoC refinement and physical acceptance¶

Nexus maintains exact silicon mechanisms. SoC facts and routes, private provider implementations, generated static instances, Board connections and observed physical behavior have separate responsibilities. The existing typed factory and shared readonly operations tables remain the runtime interface; no new registry, worker, allocator, lock or product configuration authority is introduced.

The 55-item execution ledger separates existing correction and optimization (SOC-01–27), conditional target extensions (SOC-28–36), and physical acceptance (SOC-37–55). Codex owns all maintenance. Implementation status, executed software evidence and physical status are recorded independently. An authored plan, a synthetic parser test or an ARM link cannot complete a physical exit condition.

Current software boundaries¶

STM32F407VET6/ZGT6 and GD32F470ZGT6 maintain reviewed fixed clock, startup, monotonic timer and selected controller modes. The derived capability matrix enumerates exact facts, routes, selected production sources and software fixtures. Exact F103RB/GD303RC references add legacy channel-DMA UART, IRQ-message I2C and physical Flash, single-shot ADC and fixed PWM. G474 adds selected bulb ADC shots/finite TIM6 DMA, polling I2C and ECC Flash to its GPIO/UART/SPI/PWM/EXTI/watchdog baseline. The non-M4 references are STM32H743ZIT6 and STM32U575ZIT6Q. H743 maintains fixed clock/cache profiles, finite UART DMA TX or RX-IDLE, optional initialized D2 SRAM1 and selected finite peripherals. Separate V/HSI64 baremetal selections add AXI-SRAM continuous USART3 RX and explicit duplex DMA. U575 keeps its TZEN0 finite peripherals separate from an independent copied GPIO dual-world reference. CPU ABI/runtime support for other Cortex-M profiles does not imply a full SoC, Board or peripheral implementation.

The five bounded I/O increments add common mapped ownership with coherent Native NOR, an AMP epoch/cache core, exact F407 masked Flash handoff, U575 prepared-LSE RTC RUN polling and frame contracts with an optional exact H743 RGB565 DMA2D component. Their public targets do not establish unselected hardware providers, full original exits or physical qualification.

The U575 retained-clock and Stop2 reference adds an independent RTC elapsed domain and an explicit masked WUT/Stop2 owner, with closed/joined RUN owners, verified MSIS4/MSIK4 access restoration and real cleanup. The same owner has a separately selected finite SRAM4/LPDMA1 channel-0 copy, using AlarmA trigger 14 and independent WUT escape. These are exact TZEN0 baremetal software subsets. Default Core TIM2 deadlines remain invalid after stop. General peripheral LPBAM, physical copy/retention/accuracy/current/wake acceptance and the full IO-32/SOC-35 exits remain open.

A further single-tuple LPTIM1 LPBAM selection uses the same concrete Stop2 owner as a compile-time alternative to WUT-only and SRAM4-copy modes. It updates one fixed SRAM4 CCR1/RCR=0/ARR tuple through LPDMA1 channel0 request13/BREQ1/DREQ0, with explicit start/stop and retained partial-failure effects. RUN LPTIM2 must be disabled and joined; it is not the Stop2 producer. No pin route or physical result is established, and the original IO-32/SOC-35 exits remain open.

These are source-reviewed Board references. Their physical PCB revisions, silicon revisions, solder bridges, electrical connections and option bytes have not been observed. Reference-only HIL admission fails closed; selecting a matching chip name cannot promote a reference into a qualified physical Board. The extension execution record distinguishes normal commit gates, development ARM observations and final qualification. The earlier baseline retains its original source identity and evidence. Reference software status in the ledger records bounded host/ARM evidence; it does not establish a clean candidate, physical acceptance or every original exit condition.

The G474 contract describes independent EXTI0/PA0 and EXTI1/PA1 rings, pending-bit acknowledgement, mux/gate ownership and source withdrawal. Its test Board is an explicit software fixture, with no inferred connector, button or electrical bias. The H743 contract defines all four HSI 32/64 MHz and Cache off/on combinations. Fixed cold profile selection does not implement a running frequency transition.

H743 USART3 DMA TX owns DMA1 Stream0, DMAMUX1 Channel0 request46 and its separate vector; the alternative RX-IDLE selection owns DMA1 Stream1/channel1 request45 and keeps TX IRQ-driven. Finite RX needs owner service and rearm gaps; it is not continuous or implicit duplex. Cache-on buffers occupy exclusively owned complete 32-byte lines in selected initialized AXI/SRAM1, with no outward rounding or hidden bounce buffer. Cache cleaning follows borrow admission, runs outside the long interrupt mask, and cannot settle storage while preparation is active. DMA completion, wire TC and source withdrawal remain distinct. Failed withdrawal quarantines the loan; the provider must drain before cache and timer shutdown.

The U575 dual-world contract is an independent no-OS integration fixture. Its cold owner observes provisioned option bytes, checks actual physical permissions, clears future shared RAM, then configures and seals attribution. A real SG gateway authenticates the NS world rather than an untrusted task identity, checks CMSE permissions and copies a bounded request through the existing GPIO broker. The layout and GPIO grant belong to the reference fixture, not to reusable platform policy. A separate copied job entry admits up to eight PC7 commands into one Secure slot, advances one command per SERVICE and uses nonwrapping tickets; no NS pointer survives return. No option-byte programming, RTOS isolation, general factory integration or asynchronous transport is claimed.

Clock bootstrap uses finite poll work bounds before the final clock exists; polls are not measured elapsed milliseconds. Cleanup must distinguish remaining recovery obligations from conservative settings allowed to remain. The monotonic timer belongs to one successfully started boot domain. The 32-bit references and GD303 hardware cascade require high-overflow service within 2^32 nominal microseconds; F103’s 16-bit TIM2 requires 65.536 ms. Old deadlines cannot be carried across stop/restart. NMI/HardFault, paused timers, dynamic PLL changes and deep STOP require their own exact contract rather than assumptions from ordinary task execution.

Cold admission rejects observable foreign selected owners before global clock mutation. Generated pin admission observes all required GPIO gates and validates all selected pin modes and locks before capturing or changing any pin. This includes controller routes and hidden endpoint CS pins; an unrelated shared-bank pin does not become owned. An initialization failure includes its partially initialized object in reverse cleanup. Failed readback preserves exactly the remaining cleanup responsibility instead of returning a successful release.

The timer start transaction clears stale UIF, observes a fresh UG update, clears that flag and verifies CNT before publishing the epoch. Runtime overflow advances the epoch only after acknowledged UIF. A refused ACK invalidates public time, records the private timer fault and attempts finite source/clocked-counter/NVIC withdrawal. This loss of the deadline domain is always terminal, including successful source isolation: the CPU preserves a terminal interrupt mask, invokes the existing bounded fault observer and parks if that observer returns. No invalid zero timestamp resumes a deadline consumer, and no request or low-power loan is released. Products may provide separately reviewed non-returning recovery. Ordinary stop/restart and cleanup retry belong to normal lifecycle control; they do not resume this terminal path. A snapshot rechecks epoch validity under the same saved interrupt mask used to read both counter words.

.noinit means startup neither copies nor clears those bytes. It does not prove retention through a particular reset, power event or sleep mode. CPU reachability, DMA reachability, linker placement and physical retention are separate facts. Factory access does not initialize or reacquire any of these resources.

IRQ and DMA routines have finite work contracts. The selected execution owner must continue required service/cancel/drain progress. DMA completion, wire completion and withdrawal of every request reference precede SETTLED. Failed withdrawal retains QUARANTINED storage; cancellation is not permission to reclaim it. Continuous block providers stop on exhausted replacement storage and never write consumer-owned blocks or invent exact missed-event counts.

Public typed I/O contracts belong under io/include; cross-chip controller algorithms have private headers and implementation targets. SoC wrappers own silicon layout/bit assertions and physical IRQ/DMA/clock bindings. Shared code placement follows those dependencies. CMake owns source selection, and resolver facts own configuration identity; moving a file does not create a second graph.

Physical preparation and execution¶

tools/hil/soc_acceptance.py plan prepares all nineteen physical obligations without touching equipment. Each case contains required hardware, stimulation, raw observations, assertions, safety actions, metric units, unreviewed null limits and an exit condition. Selection gaps and unsupported OS cases remain explicit. The result is always prepared_unbound / not_executed.

A real station supplies observed PCB revision, part/UID, probe, supply, wiring, exact ELF, resolved configuration, recomputed resources and reviewed workload. Existing admit.py establishes that admission. A station-authored SoC protocol binds one case, selected controller IDs, required instruments/calibration bytes, stimulation and numeric limits. Invariant failure counts must remain exactly zero; actual work counts/durations require a positive reviewed lower bound. Nothing in the repository supplies product acceptance numbers or fabricates pin wiring.

capture delegates to the maintained acquisition runner. The existing six operations retain exact tool/input identities, exclusive station ownership, whole-argument argv without a shell, timeout/output bounds, cleanup and quarantine. The serial/instrument adapter must receive and content-pin the SoC protocol and all instrument records. This runner does not implement automatic waveform, CAN/USB/Ethernet peers or power interruption; station-owned adapters provide those operations. A successful capture is only executed_unqualified.

validate rebuilds unchanged admission and recipe, verifies actual operation records, protocol, instrument bytes, session, firmware/configuration, acquisition context, raw observations and sample files. It derives every result from finite, contiguous nonempty samples against the reviewed limits. Rehashed opaque protocols, null limits, missing/failed/skipped operations, stale records, changed bytes and wrong scopes fail closed. A result qualifies only the named case, selected modes and recorded conditions; it does not establish WCET, unobserved loads, certification or product release.

Flash power-loss cases additionally require a content-pinned external product layout. The test region must use the exact part’s erase boundaries, remain within physical Flash, avoid every protected region and avoid all actual firmware LOAD bytes. The external layout must protect every admitted firmware LOAD. Products own the region, protected data, power-cut safety and recovery policy. The platform reserves no default test partition and performs no destructive action during preparation, validation or commit checks.

Implementing rejection of an unsupported configuration is a valid defensive contract; it is not implementation of the rejected feature. Additional features need exact controller/mode ownership and acceptance evidence before these ledger entries can close. Current first-release devices retain their declared fixed profiles.

The remaining software work for SOC-33–35 requires coordinated ownership rather than another profile label. The exact F407 masked handoff now implements outgoing owner/state admission and the terminal transfer. Incoming-image integration, current-source qualification and physical execution remain separate; broader running-state adoption still needs its own image/resource and FP/IRQ/cache/RAM contract. External products retain loader authentication, partition and recovery policy. Dynamic frequency changes need actual consumer quiescence, ordered electrical changes, bounded rollback, OS timing adaptation and an explicit continuous time contract. Deep STOP additionally needs an exact RTC/LPTIM reference, wake/retention admission, elapsed-time reconstruction and consumer restoration; ordinary shallow-sleep preparation does not establish it.

SOC-36 still needs a separately reviewed dual-world configuration/factory path, trusted OS task identity and mutable-map/copy-fault contracts before general userspace support. Async and DMA extensions must preserve borrow, cancel, drain and final-publication rules across the security boundary. These are additional mechanisms, not consequences of the current synchronous GPIO reference.

Physical equipment is currently disconnected. SOC-37–55 have executable tooling and station-binding obligations; their physical exit status remains not_executed. See HIL authoring and commands.
