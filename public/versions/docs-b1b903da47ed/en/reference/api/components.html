struct nx_owner_executor_port_t¶
#include <bus_owner.h>

One real execution owner, injected without OS dependency.

start SUCCESS borrows operation until service SUCCESS. BUSY or any start error retains zero operation references/hardware effects; an error after partial start must instead accept and report through service. service SUCCESS proves all hardware/IRQ/deferred accesses stopped, writes final result/count, and releases the operation. BUSY still borrows. Other service errors retain ownership and require continued recovery/service. cancel requests drain; it never by itself releases operation. Callbacks run only in the externally scheduled executor, outside adapter metadata guard.

Note

terminal_authority selects providers that observe deadlines and latch their first terminal hardware fact themselves. Their final result survives late cancellation/publication. Other executors use adapter deadline/cancellation results. Queued deadlines always belong to the adapter.

Bind an explicit writable uniform-erase physical region.

Note

Task-only, serialized caller. No region is reserved by the platform. Mixed sector geometries require another explicit storage adapter; this one rejects them. IO pulse settlement guarantees sync durability; no caller buffer survives a port call. Physical power-loss remains unqualified. Cancel/drain/quarantine retain descriptor bytes and outer context. OUT0 quarantine exposes NEEDS_DEVICE_STOP; only the external controller owner may authorize stop. This adapter never stops the shared controller automatically. One SETTLED packet is folded before observing newer controller epochs.

Parameters:

  • control – [inout] Same serialized executor and lifetime as begin.

Returns:

Success or provider error; an error never revokes accepted storage.

nx_result_t nx_usb_control_cancel(nx_usb_control_t *control, nx_usb_control_request_t *request, uint64_t epoch)¶

Request cancellation without revoking the old packet or outer loan.

Note

An already acquired STATUS ACK wins. The next step issues at most one packet cancel; continue polling and retain quarantine until actual source withdrawal. OUT0 recovery may need explicit device-owner stop.

Parameters:

  • control – [inout] Same serialized privileged task executor.

  • request – [inout] Exact active outer request, kept alive until SETTLED.

  • epoch – [in] Exact active SETUP identity; no cross-task raw pointer use.

Returns:

Success requests drain; STATE rejects stale identity without effects.

Inspect completed OUT DATA before the external policy approves STATUS.

Note

The view expires at the next same-owner adapter call. No mutation, free, cross-task access or implicit status acknowledgement is allowed.

Parameters:

  • control – [in] DATA_READY with no provider packet references.

  • view – [out] Disjoint value output, unchanged on rejection.

nx_result_t nx_usb_control_approve(nx_usb_control_t *control, uint64_t epoch, bool accepted)¶

Approve OUT policy before STATUS IN, or reject with a bounded STALL.

Note

Bytes, class dispatch, configuration readiness and recovery policy are external. No CDC/HID stack is supplied. A guarded decision excludes an already software-published replacement SETUP. Physical bus packets not yet collected by IRQ are outside that software epoch boundary. Cancellation drains before the outer loan ends.

Parameters:

  • control – [inout] DATA_READY same-owner adapter.

  • epoch – [in] Exact active SETUP epoch, checked against fresh state.

  • accepted – [in] True permits status; false stalls the old transaction.

Returns:

Success changes policy only; the next step performs packet/STALL.

nx_result_t nx_usb_descriptor_validate(const nx_usb_device_profile_t *profile, const nx_usb_descriptor_view_t *descriptor)¶

Validate complete device, configuration or string descriptor bytes.

Note

Configuration views require alternate zero, endpoint plans matching selected bulk or interrupt IN ports, consistent totals and unique interface numbers. Interrupt bInterval is a nonzero linear count of full-speed 1 ms frames in external descriptor bytes. Bulk bInterval is not interpreted; no polling is scheduled. Class-specific subordinate bytes are bounds-checked but not decoded. Class dispatch, VID/PID, strings, policy, CDC/HID and descriptor lookup remain external. Success is structural validation, not enumeration or physical qualification. To send bytes, preserve their lifetime through the control adapter’s acquire-observed outer SETTLED. The view struct requires natural C alignment; rejection is not an arbitrary address probe. Descriptor bytes need only byte alignment and remain externally readable.

Parameters:

  • profile – [in] Immutable exact selected FS endpoint facts.

  • descriptor – [in] Complete external descriptor; never copied/retained.

Returns:

Success, INVALID or UNSUPPORTED, with no hardware or output effects.
