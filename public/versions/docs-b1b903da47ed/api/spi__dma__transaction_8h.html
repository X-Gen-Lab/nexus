Prepare unborrowed storage after validating every span.

Parameters
[in,out]requestInitialized READY or consumed SETTLED storage.
[in]segmentsImmutable caller-owned array, at most MAX_SEGMENTS.
[in]countPositive segment count; every words count is positive.
[in]word_bitsCommon hardware width of 8 or 16 bits.
[in]deadlineAbsolute monotonic deadline for the complete chain.
Returns
SUCCESS, INVALID/UNSUPPORTED/STATE; no borrow on failure.
Note
Descriptors and payload never overlap request storage. RX cannot overwrite any TX or descriptor. Repeated RX alias is allowed only for the exact same explicit FIXED discard cell. Provider-specific domains are checked at admission.

◆ nx_spi_dma_transaction_service()

void nx_spi_dma_transaction_service ( const nx_spi_dma_transaction_port_t * port)

Advance a bounded phase boundary, completion or drain.

Parameters
[in]portTask-only enhanced controller; continue during stop.
Note
No wait, allocation, payload copy, hidden task or OS lock. Failed drain/release retains QUARANTINED storage. SETTLED follows final hardware detach and CS release and is the provider's final access to caller request and descriptors.

◆ nx_spi_dma_transaction_stop()

nx_result_t nx_spi_dma_transaction_stop ( const nx_spi_dma_transaction_port_t * port)

Close admission and stop after complete source withdrawal.

Parameters
[in]portStable single-executor state, producers quiesced.
Returns
SUCCESS proves stop; BUSY needs further service and retains all outstanding storage, including quarantined requests.
Note
Repeated successful stop never touches hardware again; another owner may already have acquired the controller.

nx_result_t nx_spi_dma_transaction_submit ( const nx_spi_dma_transaction_endpoint_t * endpoint,
nx_spi_dma_transaction_request_t * request )

Admit one finite chain on a task-only single executor.

Parameters
[in]endpointStable enhanced DMA endpoint and provider state.
[in,out]requestREADY descriptor, retained only on SUCCESS.
Returns
SUCCESS means ACCEPTED, possibly already SETTLED. Rejection retains no references and creates no hardware effects.
Note
All domains and segments are validated before admission. One CS interval spans the chain; SCK gaps between segments are permitted. DMA TC alone never establishes wire idle.
