Detailed Description

Caller-selected immutable software review policy.

Note
Rules have strictly increasing revision IDs. Nonempty rules require a nonzero SHA256 identifying their reviewed source record. This helper does not authenticate that record or infer that required workarounds were implemented; reviewed build/configuration facts supply the applied mask. allow_unreviewed permits an explicitly observed unknown revision only. It cannot override blocked revisions, a missing observation, mismatched density/group or required workarounds. Empty rules describe no reviewed revisions. No hardware test status is established by this policy.
