Detailed Description

One immutable assembly binding, in privileged Flash.

Note
Define exactly one nx_freertos_mpu_gpio_binding symbol. Control and task are disjoint privileged RAM; grant is privileged Flash. User arguments never select these objects.
Keep the task epoch after deletion. Initialize only at cold startup.
