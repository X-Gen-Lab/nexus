Detailed Description

Copied raw counter facts; readable does not mean elapsed is known.

Note
A pair is a modulo-2^32 residue, including preemption and probe cost. Neither wrap count, reset, rate nor epoch continuity is established. elapsed_known is always false. No field establishes a passed budget, IRQ arrival latency, exclusive CPU time or a physical WCET bound. attempts includes a currently active attempt; other totals describe completed attempts. Totals saturate rather than wrap.
