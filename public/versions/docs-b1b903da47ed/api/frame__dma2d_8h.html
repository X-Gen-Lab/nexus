nx_result_t nx_h743_frame_dma2d_initialize ( nx_h743_frame_dma2d_storage_t * storage,
const nx_frame_blitter_t * face,
const nx_h743_frame_dma2d_config_t * config )

Acquire cold DMA2D and its dedicated RCC gate/reset bit.

Parameters
[in,out]storageFresh zero storage exclusively owned by caller.
[in]faceStable readonly {&nx_h743_frame_dma2d_ops, storage}.
[in]configExact resource plus positive abort observation bound.
Returns
SUCCESS, INVALID, BUSY for foreign gate/reset/IRQ ownership, UNSUPPORTED for non-V/cache-on, CONTEXT or IO.
Note
Privileged unmasked task, one serialized executor. Caller explicitly excludes every other DMA2D owner, including HAL, IRQ handlers and resource selections outside this component. Never change Cache/RCC/reset/MPU or clock domain before stop. All payloads must be wholly in AXI SRAM [0x24000000, 0x24080000); source/destination overlap is rejected. Only RGB565 M2M or fixed ARGB8888-to-RGB565 PFC is supported. Offsets count each side's pixels (LOM=0), not bytes. CLUT/blending/other formats/IRQ are unsupported. No pins, Board route, scheduler, queue or worker is created. Initialization IO errors retain cleanup ownership; call stop. A successful stop detaches every source then withdraws only its RCC gate. Repeated stop performs no hardware accesses.
