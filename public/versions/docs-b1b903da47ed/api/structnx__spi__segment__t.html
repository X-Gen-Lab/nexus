Detailed Description

One phase within a single CS interval.

Note
Words have the transaction's common width of 8 or 16 bits. NULL TX repeats dummy; NULL RX discards. Both may be NULL for clock-only words. Non-NULL spans contain words elements; 16-bit spans are uint16_t-aligned. Descriptor and TX storage stay immutable until return. RX never overlaps descriptors, TX storage, other RX spans or the completion output. Ordinary byte-span SPI remains a separate unchanged interface.
