Detailed Description

Declared units and modulo counter, not an absolute time estimate.

Note
A complete 65536-tick shot wraps counter to zero. Counter zero alone cannot establish completion, idle, missed wraps or low-power continuity. tick_hz is a fixed declared rate, not physical oscillator accuracy.
