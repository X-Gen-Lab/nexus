◆ nx_lptim_port_stop()

nx_result_t nx_lptim_port_stop ( const nx_lptim_port_t * port)

Close admission; cancelled/expired is never a loan-release proof.

Parameters
[in]portSerialized owner, with all external publishers quiescent.
Returns
SUCCESS after detachment, BUSY retains quarantined storage; INVALID/STATE/UNSUPPORTED may reject dispatch.
Note
Repeated clean stop is safe; it does not reset generation or lifetime. Tick rate/source and backup/Stop/VBAT continuity need separate hardware contracts; this interface establishes none of those qualifications.

nx_result_t nx_lptim_port_submit ( const nx_lptim_port_t * port,
nx_lptim_request_t * request )

Borrow one READY shot after all idle/domain/range checks.

Parameters
[in]portSame serialized owner with a copied external Core clock.
[in,out]requestCaller request; no queue or hidden worker.
Returns
SUCCESS means ACCEPTED; INVALID/STATE/BUSY/TIMEOUT/EXHAUSTED/UNSUPPORTED rejects without retained references or effects.
Note
Expired finite deadline rejects TIMEOUT before source effects. Reserve a final nonwrapping domain increment before acceptance: EXHAUSTED never abandons a previously accepted loan. Clock context lifetime, complete extent/disjointness and non-reentry are assembly responsibilities.
