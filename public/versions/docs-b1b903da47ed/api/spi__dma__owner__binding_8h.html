Attach a borrowed hint to actual validated IRQ publishers.

Parameters
[in]bindingStable selected controller capability.
[in]wakeImmutable sink kept live through publisher join, NULL to detach under the provider's lifecycle contract.
[in]syscall_ceilingActual unshifted kernel threshold.
Returns
SUCCESS, INVALID, CONTEXT, UNSUPPORTED or provider failure.
Note
Task-only. Rejection leaves the previous binding intact. A hint is never completion. Detach alone does not join a publisher that has already captured the sink. Stop and join publishers and waiters before destroying notification data.
