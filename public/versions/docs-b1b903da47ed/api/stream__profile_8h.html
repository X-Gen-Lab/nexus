Validate pool and whole-scan rate before ADC admission.

Parameters
[in]profileStable readonly binding to the selected ADC face.
[in,out]streamInitialized unborrowed exact pool, as for UART.
[in]trigger_hzPositive nominal complete scans per second, no greater than the declared production-rate upper bound.
Returns
Cold-check errors as for UART, or the original info/start result. Provider scan, timer, DMA/cache and alias checks still apply; no rejected operation retains new references.
Note
ADC stopping its trigger creates a sampling gap. No budget makes that pause preserve wall-clock samples or prove the future consumer/IRQ bounds. No observer/queue is created.

nx_result_t nx_uart_stream_profile_start ( const nx_uart_stream_profile_t * profile,
nx_stream_t * stream )

Validate an actual pool before the bound UART may borrow it.

Parameters
[in]profileStable readonly reviewed binding and assumptions.
[in,out]streamInitialized unborrowed pool with exact declared count and equal declared byte capacities, kept live through the original provider's stop and all consumer releases.
Returns
INVALID for mismatched geometry/alias, STATE for stopping metadata, BUSY for existing loans, CONTEXT outside an unmasked task, EXHAUSTED for overflow/insufficient budget, UNSUPPORTED for target latency; otherwise provider result.
Note
Caller joins all pool users before this cold pool check. Failure before provider dispatch creates no borrow, epoch change or hardware effect. Rate, FIFO-frontier hold and IRQ latency remain declared assumptions, never measurements. This creates no external UART flow control or losslessness. Underlying unprofiled APIs retain their explicit contracts.
