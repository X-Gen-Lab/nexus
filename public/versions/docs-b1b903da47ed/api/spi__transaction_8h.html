nx_time_us_t deadline,

Execute all segments under exactly one asserted CS interval.

Parameters
[in]endpointOptional enhanced face with stable private state.
[in]segmentsCaller-owned descriptors and their data spans.
[in]countNumber of phases, all validated before hardware use.
[in]word_bitsCommon hardware frame width, 8 or 16 bits.
[in]deadlineAbsolute monotonic deadline for all phases.
[out]transferredComplete received words, never bytes; separate writable size_t storage, reset before provider execution.
Returns
SUCCESS or INVALID/UNSUPPORTED/CONTEXT/STATE/BUSY/TIMEOUT/IO.
Note
Task-only single executor; polling is CPU-active. Return releases descriptor/payload borrows after wire drain or provider reset and CS release. Deadline cannot preempt an in-flight word. Errors never replay prior segments. No allocation, OS lock, hidden scratch, width changes or CS toggles occur between phases. This is synchronous: existing finite DMA request and cancellation contracts are unchanged.

Validate every descriptor and span without hardware effects.

Parameters
[in]segmentsAligned immutable array, retained by the caller.
[in]countPositive descriptor count, at most MAX_SEGMENTS.
[in]word_bitsExactly 8 or 16; fixed for the whole CS interval.
Returns
SUCCESS, INVALID for malformed/overlapping/overflowing spans, or UNSUPPORTED for excess descriptor count or word width.
Note
No memory is borrowed, copied, allocated or modified. NULL data pointers are legal dummy/discard operations. This does not validate provider-specific controller, rate or limits.
