Detailed Description

Acquired value event, including observed transmitter ESI.

Note
acquired_us is provider acquisition time, never SOF. A disabled hardware counter reports raw0 plus TIMESTAMP_UNAVAILABLE. filter is the hardware index within the frame format's filter list. Hardware loss proves a lower bound; classic DLC9..15 normalizes to8 with a flag.
