◆ nx_pwm_group_commit()

nx_result_t nx_pwm_group_commit ( const nx_pwm_group_t * port,
const nx_pwm_group_frame_t * frame )

Stage a complete channel group and its internal trigger comparison.

Parameters
[in]portOne serialized privileged task/configurable-IRQ owner.
[in]frameComplete readable batch; no pointer is retained on return.
Returns
SUCCESS means one coherent group is staged for a hardware update, not that this update already happened. Invalid input has no effects.
Note
Provider declares exact channel count, trigger range and ISR budget. Duties include zero and period. All channels share one fixed base. A failed partial hardware write must disable output and retain fault responsibility rather than release a mixed group to the next update. Stop is explicit; automatic output recovery after break is prohibited.
