◆ nx_stm32u575_retained_time_initialize()

nx_result_t nx_stm32u575_retained_time_initialize ( nx_stm32u575_retained_time_storage_t * storage,
const nx_stm32u575_retained_time_config_t * config,
nx_clock_t * clock )

Open a separate elapsed clock without reading or changing Core TIM2.

Parameters
[in,out]storageFresh zero or fully stopped, externally joined owner.
[in]configSeparate immutable configuration, copied during this call.
[out]clockSeparate writable face, copied only on success.
Returns
SUCCESS, INVALID, STATE, BUSY, CONTEXT, UNSUPPORTED or EXHAUSTED; rejection leaves owner and output unchanged, with no hardware writes.
Note
Exact U575 TZEN0, privileged unmasked Thread, baremetal integration. External boot owns a valid raw calendar/LSE32768/RTCEN/RTCAPBEN, crystal mode LSEBYP=0 and conservative drive 10/11. ES0499 Rev12 2.2.3/16 affect revision X; this profile does not qualify revision. External boot/Board owners exclude PC13 transitions on the LQFP reference per 2.2.1; reads cannot prove electrical silence.
The selected MSIS4/equal-bus profile is checked before every tuple pair, with no concurrent clock-profile writer. This conservative profile is not a general RTC-write frequency rule. Require PRER127/255, BCD24h BYPSHAD, no shift/calibration/alarms.
Both standalone and delegated construction require quiet RTC IRQ, WUTE/WUTIE clear and no RTC flags. The explicit wake_owner may operate only its WUT/IRQ fields after successful construction. Calendar provenance, including intentional YY00, cannot be inferred from INITS. DBP/WPR need not be unlocked; no hardware writes occur.
This face has a distinct domain from nx_time_now_us(). Old Core deadlines are never translated. Stop/reopen invalidates old faces' numerical deadlines after all consumers and observers have joined.

const nx_stm32u575_retained_time_config_t * config,

Open the fixed AlarmA-copy delegate for the same concrete Stop2 owner.

Parameters
[in,out]storageSame fresh or fully stopped and joined storage.
[in]configSame immutable configuration with non-NULL wake_owner.
[out]clockSeparate writable face, unchanged on every rejection.
Returns
Same initialization results; no hardware writes occur.
Note
All ordinary initialization preconditions remain required. Unlike the WUT-only initializer, this explicitly delegates fixed AlarmA compare registers, ALRAE and ALRAF/CALRAF to the same serialized wake owner. ALRAIE and automatic flag clearing stay forbidden. The fixed profile masks all calendar fields and compares no subseconds, producing its first event on a seconds increment. Both alarm registers start zero. The delegate preserves the calendar/source and owns complete producer withdrawal before any compound copy settlement. No AlarmA factory, arbitrary alarm scheduler or second RTC writer is admitted.

Note

Observe a bounded coherent tuple and extend the independent domain.

Parameters
[in,out]storageSame serialized privileged Thread owner.
[out]snapshotSeparate aligned writable output, unchanged on failure.
Returns
SUCCESS, INVALID, STATE, BUSY, CONTEXT or EXHAUSTED.
Note
Thread may hold PRIMASK; BASEPRI/FAULTMASK and Handler mode are excluded. BUSY means no coherent tuple after eight bounded retries, and changes neither owner nor output. A source/configuration change, backward/out-of-window calendar or time exhaustion permanently taints this live epoch. Later samples return STATE; no stale value is valid.

nx_result_t nx_stm32u575_retained_time_stop ( nx_stm32u575_retained_time_storage_t * storage)

Close clock admission after every external face/deadline user joins.

Returns
SUCCESS, INVALID, CONTEXT or STATE; clean repeated stop is idempotent.
Note
Does not reset generations or alter the source. An explicit reopen starts a new zero-based elapsed domain, including after a tainted one. No scheduler, wake IRQ, WFI, Core restoration, Stop2 or VBAT retention guarantee is established by this read-only source component.
