Acquire one bounded, positive read-only span on a serialized executor.

Returns
SUCCESS or INVALID/UNSUPPORTED/BUSY/EXHAUSTED/STATE. Rejection retains no loan. Live read maps exclude all command/program/erase/cache/DMA writers. CPU/XIP/DMA consumers may run concurrently after successful acquisition.

◆ nx_mapped_storage_service()

void nx_mapped_storage_service ( const nx_mapped_storage_port_t * port)

Advance one bounded backend step or drain attempt without waiting.

Note
Backend/IRQ/data references detach before release-publication of SETTLED, which is the final request access. Failed drain is QUARANTINED; storage remains borrowed and later service may retry source withdrawal.

◆ nx_mapped_storage_stop()

nx_result_t nx_mapped_storage_stop ( const nx_mapped_storage_port_t * port)

Close admission and request writer cancellation.

Returns
SUCCESS only after all map loans and writer sources are gone; BUSY retains storage and needs release/service. Repeated successful stop performs no backend operation. The owner cannot restart or revoke loans.

Admit one exclusive PROGRAM/ERASE request with an absolute deadline.

Returns
SUCCESS is ACCEPTED, possibly settled. Rejection retains no request or payload and produces no hardware effects. No map loan may remain live. Task-only serialized owner; no workers, allocation, locks or queue exist.
