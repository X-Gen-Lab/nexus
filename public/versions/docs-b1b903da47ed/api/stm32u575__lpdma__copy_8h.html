Construct one serialized privileged Thread owner without MMIO writes.

Parameters
[in,out]storageFresh zero or clean stopped and externally joined.
[in]configSeparate immutable clock/owner binding.
[out]copySeparate writable immutable face, unchanged on failure.
Note
Exact STM32U575ZIT6Q TZEN0/MSIS4/MSIK4/equal buses/Range4 and selected SRAM4 only. LPDMA1EN/SRAM4EN and power/retention belong to selected startup; every channel and vector must initially be quiet. The run-gate owner keeps both gates and exclusive hardware configuration stable through stop and joins; no other LPDMA channel may start. This component owns only fixed sleep/autonomous bits and preserves unrelated RTC bits. SRAM4EN and power/retention preconditions belong to startup and the combined sleep owner. This component never repairs lost RAM by changing SRAM4PD/PDS and never disables the caller's SRAM4EN.

◆ nx_stm32u575_lpdma_copy_service()

nx_result_t nx_stm32u575_lpdma_copy_service ( const nx_stm32u575_lpdma_copy_t * copy,
uint32_t poll_limit )

Observe and perform bounded DMA withdrawal; never publish SETTLED.

Parameters
[in]copyImmutable face of the initialized physical receiver.
[in]poll_limitPositive observation budget for each drain phase.
Note
Positive finite per-phase observation budget, not a time estimate. BUSY retains request, both buffers and workspace, even after DMA idle. Only the concrete Stop2 owner can release after the entire RTC/IRQ/ DMA/clock/gate chain is restored. Unknown profile performs no DMA MMIO. An externally asserted LPDMA reset observed while borrowed leaves an uncertain loan permanently quarantined; reset-default IDLE cannot prove earlier master accesses joined. No software force release exists. Preserve incoming masks; while borrowed the concrete Stop2 boundary requires PRIMASK1, BASEPRI/FAULTMASK0 until complete recovery.
