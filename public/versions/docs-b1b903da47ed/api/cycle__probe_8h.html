◆ nx_io_cycle_probe_begin()

nx_result_t nx_io_cycle_probe_begin ( nx_io_cycle_probe_t * probe,
nx_io_cycle_token_t * token )

Start one raw observation without enabling or resetting DWT.

Parameters
[in,out]probeLive, exclusive zero/previously completed sidecar.
[in,out]tokenZero/inactive token distinct from the complete probe.
Returns
SUCCESS even if the counter is unavailable; INVALID/STATE/BUSY rejects before counter access. Same-probe reentry is counted.
Note
Configurable IRQ or unique task executor. Probe failure must never prevent real I/O dispatch, cancellation, service or retained drain.

◆ nx_io_cycle_probe_snapshot()

nx_result_t nx_io_cycle_probe_snapshot ( const nx_io_cycle_probe_t * probe,
nx_io_cycle_observation_t * out )

Copy bounded IRQ statistics under saved local interrupt exclusion.

Parameters
[in]probeStable same-CPU sidecar and live producer binding.
[out]outDistinct aligned copied result, unchanged on rejection.
Returns
SUCCESS, INVALID or CONTEXT for ISR/unprivileged callers.
Note
Privileged task only. Incoming masks are restored. For a task service producer, use its same executor or join it before sampling; IRQ masks do not join a different preempted task. This is not SMP exclusion. No provider, payload, request or counter is accessed under the mask.

◆ nx_uart_word_port_service_observed()

nx_result_t nx_uart_word_port_service_observed ( const nx_uart_word_port_t * port,
nx_io_cycle_probe_t * probe )

Dispatch exactly one word service step with optional raw observation.

Parameters
[in]portOriginal stable face, methods and unique task executor.
[in,out]probeOptional live sidecar, or NULL to omit observation.
Returns
SUCCESS proves dispatch only; INVALID/UNSUPPORTED describes the face.
Note
No additional ops table, worker, request or payload reference. Invalid observation never prevents dispatch. Caller proves complete private state, borrowed descriptors and buffers disjoint from observation storage; this API knows only face/method spans and context identity.
