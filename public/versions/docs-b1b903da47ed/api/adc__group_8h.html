Prepare caller storage without hardware access or retained borrow.

Parameters
[in,out]requestInitialized READY or fully consumed SETTLED storage.
[out]framesAligned nonempty raw output including explicit padding.
[in]bytesPositive nonwrapping span; provider validates exact layout.
[in]frame_countPositive whole-frame count, not a raw rank count.
[in]deadlineFinite absolute deadline in platform monotonic domain.
Returns
SUCCESS or INVALID/STATE, rejected request remains unchanged.
Note
Request and frames are distinct. Preparation reads no sample bytes and does not prove a DMA domain or chip mode. All previous observers must be joined before reuse. NX_DEADLINE_NEVER is rejected.

◆ nx_adc_group_submit()

nx_result_t nx_adc_group_submit ( const nx_adc_group_port_t * port,
nx_adc_group_request_t * request )

Accept and start one selected finite acquisition under a sole owner.

Parameters
[in]portInitialized selected face with immutable retained facts.
[in,out]requestExact READY descriptor and exclusive writable span.
Returns
SUCCESS means ACCEPTED, including immediate SETTLED failure. Other results reject without pointer retention or residual new effects.
Note
Accepted descriptor is caller-immutable; caller cannot access frames until acquire-observed SETTLED. Priming may write this entire span but never publishes prime data as valid. Post-admission arm failure keeps the borrow until actual drain. Without trusted completion timestamps, completion first observed at/after deadline is TIMEOUT. One-frame injected profiles deliberately prevent a second trigger/JDR overwrite.
