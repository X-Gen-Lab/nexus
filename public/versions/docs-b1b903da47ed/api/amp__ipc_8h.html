Join the caller view, then publish its exact ACK.

Note
Valid ticket invocation permanently joins local readers. IO or STATE retains endpoint/slot storage; retry finish or use reset_join after closing. Stale tickets change nothing.

◆ nx_amp_ipc_join()

Join a closed endpoint after all exact ACKs/local returns.

Note

◆ nx_amp_ipc_reset_join()

nx_result_t nx_amp_ipc_reset_join ( nx_amp_close_t control)

Join after an explicit old-peer stop proof.

Note
Closed endpoint required; receiver views must have been consumed by finish first. Failed proof retains ALL sender loans and ownership. Success retires this endpoint; any replacement uses a strictly newer nonzero boot epoch from the external boot owner, never rollover/reuse.

◆ nx_amp_ipc_send()

nx_result_t nx_amp_ipc_send ( nx_amp_ipc_t * ipc,
uint32_t offset,
uint32_t bytes,
nx_amp_ticket_t * ticket )

Publish one complete-cache-line payload span without copying.

Returns
SUCCESS transfers a read-only borrow until exact ACK poll or successful reset_join. Rejection retains nothing and does not publish. EXHAUSTED means no reusable slot identity.
Note
Serialized owner Thread only, same rule for every API below. No waits, allocation, scheduler, ISR or implicit worker. Outputs must not overlap any live instance/lane storage. Producer must finish DMA/other writers before this call.
