Detailed Description

One finite window; transferred counts are raw samples, never bytes.

Note
Initialize base before first preparation. After successful admission, the request and duty array remain live and caller-immutable through acquire-observed SETTLED. The writable sample span belongs exclusively to the provider; the caller neither reads nor writes it while borrowed. Frame metadata is copied at preparation. No later shadow commit, automatic rearm, control algorithm or engineering-unit conversion is part of this finite-window interface. Hardware-specific sample storage and integer encoding are reported by state.format.
