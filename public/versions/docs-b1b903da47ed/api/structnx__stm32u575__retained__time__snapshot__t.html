Detailed Description

A successful sample copied together in this owner's boot lifetime.

Note
Microseconds are floor(ticks*1000000/256); resolution is 3906.25us, with exact carried fractional quarters. Generation changes only on explicit successful initialize/reopen, never natural 99->00 rollover.
