Detailed Description

Immutable uniform-channel integer layout, independent of ADC faces.

Note
storage_bytes is1..4; significant_bits is1..32 within that storage. lsb_bits names discarded low bits, not an arithmetic scaling factor. sample_stride and scan_stride include explicit padding in bytes. channel_count retains the provider's separately declared channel order. Software triggers use identity0; hardware trigger identities are nonzero assembly-local IDs, never addresses or a promise of physical timing. Group/trigger declarations describe an already supported provider mode; validating a layout does not add support to a device or configure it.
