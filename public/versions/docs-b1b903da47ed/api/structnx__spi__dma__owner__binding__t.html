Detailed Description

Selected-only provider capability without changing IO faces.

Note
Stable immutable storage outlives executor and publishers. contains proves actual controller identity; a display name or a caller-assembled pair of pointers is not such proof. attach_wake validates actual IRQ sources before borrowing the sink. A missing hook permits explicit periodic service.
