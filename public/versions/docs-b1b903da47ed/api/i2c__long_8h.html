Execute finite messages without splitting address phases.

Parameters
[in]endpointSelected optional long-message provider
[in,out]messagesDescriptors and buffers borrowed until return
[in]countOne through NX_I2C_MAX_MESSAGES
[in]deadlineFinite absolute provider-clock deadline
[out]transferredRegister byte progress, including failure; TX count does not prove those bytes were ACKed on wire
Returns
SUCCESS or INVALID/UNSUPPORTED/CONTEXT/STATE/BUSY/TIMEOUT/ NACK/ARBITRATION/IO after local controller drain
Note
Task-only, one executor shared with base I2C. Each message issues one START; only a following message issues repeated START. Hardware reload does not split messages. Final STOP and bus-idle observation precede successful return. Failure never replays a prefix. Failed abort drain cannot return and release borrowed storage. No implicit bus recovery occurs.
