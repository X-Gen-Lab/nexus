Detailed Description

Selected-only operations; no growth to ordinary PWM/ADC tables.

Note
Each callback implements its corresponding public function contract. One privileged task serializes submit/cancel/service/stop/state; IRQs only latch bounded physical facts into the same private owner. Missing callbacks return UNSUPPORTED. There is no allocating or hidden worker.
