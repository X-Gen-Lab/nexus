当前平台交付¶

默认实现统一为 Core / Arch / SoC / Board / 静态 factory / 多态 I/O / 可选 OS / 可选组件。一份 TOML 经严格校验和不可变 IR 生成精确实例；factory 返回稳定的 只读接口对象，共享只读操作表，独立状态留在 provider 内部。获取接口不启动硬件。 应用、产品任务、私有 PCB、Flash 分区、恢复与安全策略由外部工程维护。

最新封存基线是 7590b2d4。完整软件计划、SDK、八个精确配置候选和远程恢复 结果见最终冷态生命周期交付。 该入口区分公开平台证据、需授权的私有示例证据及仍开放的物理、环境和发布退出； 下列旧索引保留其原始源码和历史状态，不覆盖后续封存观察。

文档系统的后续整理见 架构与交付规划。 对应文档工具、正文和图册已实现，实际文档验收与固件资格分别记录；当前资料总入口为 文档入口。

CPU 软件层覆盖 M0/M0+/M3/M4/M7/M23/M33/M55/M85。外部工程可通过一份 严格 CPU runtime TOML/事实包使用 nexus_add_runtime 或安装包的 Runtime component，复用 Core/Arch/I/O face 与选定裸机/FreeRTOS adapter。运行时装配 不生成 SoC、Board、启动或 factory，具体硬件、产品任务和安全策略仍由外部工程 负责。F407/F470 三板维护首发模式；F103/GD303 增加精确 legacy channel-DMA UART、I2C IRQ、Flash／ADC／PWM 等有限选择；G474 增加 bulb ADC 的单次／有限 TIM6-DMA、I2C 和 ECC Flash。H743 的固定 Cache 与有限 UART DMA 保留独立合同， 另有显式 D2 SRAM1 初始化及 SPI/I2C/ADC/PWM/EXTI/IWDG/Flash 软件夹具；U575 TZEN0 增加六类有限外设，独立 TZEN1 参考只维护同步 GPIO 与最多八项复制命令的 cooperative job。静态 factory 按模式保留精确状态和资源，不生成产品任务。 这些源实现不代表全系列、全外设或完整安全域资格，物理 HIL 全部未执行。

本轮工业外设迭代的当前合同以 精确支持、各 SoC README 和 主流 MCU 接入 为准。源码实现、定向开发 结果与最终冻结源码的软件资格分别记录；下列已绑定版本的历史结果不覆盖新代码， 也不为本轮补写未执行的测试计数、SDK、离线复现或候选状态。

历史 SoC 扩展基线固定源码 98270512 已完成全部 Native 契约、工具和配置测试、121 个 ARM 镜像、104 个 CPU runtime 变体、SDK 独立消费及完整 GitHub CI。八个 H743/U575 公开参考配置分别完成两次独立断网构建，ELF/BIN 逐字节一致，并封存为无签名软件 候选；具体范围和原始证据见结果索引。后续文档提交只记录该源码，不继承为新的 代码执行资格。实板未接入，物理 HIL 均为 not_executed。当前有限 F407 屏蔽 Flash 尾跳不代表通用运行态接管；SOC-34 的 DVFS 仍未实现。SOC-35 已增加 U575 保留时钟与 Stop2的有界软件子集，使用独立 RTC 时间域与显式 WUT/Stop2 owner；另有同一 owner 的选定 SRAM4/LPDMA 有限复制。通用外设 LPBAM 尚未实现， 物理复制、保留、精度、功耗及唤醒验收仍未执行。SOC-35 完整退出仍开放；全部 55 项原始退出条件保持不变。

另有独立选定的 LPTIM1 单组 LPBAM 软件参考， 由同一 concrete Stop2 owner 管理固定 SRAM4 CCR1/RCR=0/ARR 更新及显式 start/stop 的部分失败恢复。它不建立引脚路线、完整波形播放或实板资格；物理 HIL 仍为 not_executed，原 IO-32/SOC-35 退出条件不变。完整 SDK 消费计划由 维护的 transport policy 定义；历史 v7/v8 执行记录 不能覆盖新增选择。本页不宣称新增选择已取得完整 SDK、离线复现或软件候选资格。

既有构建系统交付绑定 cc6a065c，完整结果单独记录在构建结果索引，不能继承 上面的历史 SoC 执行身份。该版本的八个候选使用 H743 HSI64／Cache off 和 U575 MSIS4／TZEN=0 的 empty／UART、裸机／FreeRTOS 参考组合；这不扩大实板支持。 72 阶段软件总计划未作为一次完整 plan invocation 执行，OCI recipe 重建、 CP311 离线安装和物理 HIL 仍未执行。后续文档提交只记录其精确代码源码。
