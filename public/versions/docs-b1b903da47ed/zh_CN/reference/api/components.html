nx_result_t nx_clock_domain_acquire(nx_clock_domain_t *domain, nx_clock_lease_t *lease)¶

无等待地取得一个允许准入的时钟消费者。

备注

nx_result_t nx_clock_domain_close(nx_clock_domain_t *domain, nx_clock_barrier_t *control)¶

nx_result_t nx_clock_domain_quiescent(nx_clock_barrier_t control)¶

验证准入已关闭且保留消费者为零。

备注

同一 CPU 上的特权 Thread。该证明仅涵盖显式登记的消费者。不授权重新配置 PLL、暂停内核 Tick 或改变 Core 截止时间域。

返回:

SUCCESS；消费者仍存在时为 BUSY；控制身份过期或处于开放状态时为 STATE；也可能为 INVALID 或 CONTEXT，均不改变状态

nx_result_t nx_clock_domain_reopen(nx_clock_barrier_t control)¶

在新的准入 epoch 下重新开放已排空的时钟域。

备注

串行的特权 Thread。不重启时钟，也不重新解释现有截止时间。真正的冷态时钟变更还要求停止全部 Tick/时间提供者，并显式建立新的截止时间域；本 API 不执行这两项操作。

推进 USBControl 一步，仅归并已 acquire 观察到的完成。

备注

  • request – [inout] READY 元数据及与其不重叠的 payload。OUT 容量必须覆盖 wLength；IN 发送 min(length,wLength)，包含必要的 ZLP。

返回:

成功表示 ACCEPTED；任何失败均不保留 request 或 payload。

nx_result_t nx_usb_control_step(nx_usb_control_t *control)¶

推进一个有界步骤，至多进行一次 poll 和一次 packet 动作。

备注

不使用队列或 worker。所有 packet deadline 均使用 outer 独立的绝对单调 deadline。借用期间须持续 poll，即使已发生 cancel、reset、SETUP 替代或 device stop。cancel／drain／quarantine 均保留 descriptor 字节与 outer context。OUT0 quarantine 暴露 NEEDS_DEVICE_STOP；仅外部 controller owner 能授权 stop。该 adapter 绝不会自动停止共享 controller。在观察更新的 controller epoch 前，先折叠一个已 SETTLED 的 packet。

参数:

  • control – [inout] 同一个串行化执行者；沿用 begin 的生命周期要求。

返回:

成功或 provider 错误；错误绝不撤销已接受的存储借用。

nx_result_t nx_usb_control_cancel(nx_usb_control_t *control, nx_usb_control_request_t *request, uint64_t epoch)¶

请求取消，但不撤销旧 packet 或 outer 借用。

备注

已以 acquire 语义获取的 STATUS ACK 优先。下一步至多发出一次 packet cancel；须继续 poll，并保留 quarantine，直到实际撤回源。OUT0 恢复可能需要 device owner 显式执行 stop。

参数:

  • control – [inout] 同一个串行化特权 Task 执行者。

  • request – [inout] 精确的活动 outer request，保持有效直至 SETTLED。

  • epoch – [in] 精确的活动 SETUP 身份；不得跨 Task 使用原始指针。

返回:

成功时请求排空；STATE 无效果地拒绝过期身份。

nx_result_t nx_usb_control_out_view(const nx_usb_control_t *control, nx_usb_control_out_view_t *view)¶

备注

视图在同一 owner 下一次调用 adapter 时失效。不得修改、释放或跨 Task 访问，也不隐含 status 确认。

参数:

  • control – [in] 处于 DATA_READY，且不存在 provider packet 引用。

  • view – [out] 不重叠的值输出；拒绝时保持原值。

返回:

成功仅授予 const 检查视图；outer 借用继续。

nx_result_t nx_usb_control_approve(nx_usb_control_t *control, uint64_t epoch, bool accepted)¶

在 STATUS IN 前批准 OUT 策略，或以有界 STALL 拒绝。

备注

字节、class 分派、configuration 就绪条件及恢复策略由外部负责。不提供 CDC／HID 栈。guard 保护的决定排除已由软件发布的替代 SETUP；尚未被 IRQ 采集的物理总线包不属于该软件 epoch 边界。取消须先排空，再结束 outer 借用。

参数:

  • control – [inout] 处于 DATA_READY、由同一 owner 管理的 adapter。

  • epoch – [in] 精确的活动 SETUP epoch，须根据新获取的状态检查。

  • accepted – [in] true 允许 status；false 对旧事务执行 STALL。

返回:

成功仅改变策略；下一次 step 才执行 packet／STALL。

nx_result_t nx_usb_control_snapshot(const nx_usb_control_t *control, nx_usb_control_snapshot_t *snapshot)¶

返回:

成功、INVALID 或 CONTEXT。

nx_result_t nx_usb_descriptor_validate(const nx_usb_device_profile_t *profile, const nx_usb_descriptor_view_t *descriptor)¶

校验完整的 device、configuration 或 string 描述符字节。

备注

configuration 视图要求 alternate zero、与选定 bulk 或 interrupt IN 端口匹配的 endpoint 计划、一致的总长度及唯一的 interface 编号。interrupt bInterval 是外部 descriptor 字节中 full-speed 1 ms frame 的非零线性计数。bulk bInterval 不作解析，也不调度轮询。class-specific 从属字节仅检查边界，不作解码。class 分派、VID/PID、字符串、策略、CDC/HID 及 descriptor 查找仍由外部负责。成功仅表示结构校验通过，不表示枚举或物理资格。发送字节时，必须保持其有效，直到以 acquire 语义观察到 control adapter 的 outer SETTLED。view 结构体须按 C 类型自然对齐；拒绝机制不能用于探测任意地址。descriptor 字节仅需 byte alignment，且须保持外部可读。

参数:

  • profile – [in] 选定 FS endpoint 的不可变精确事实。

  • descriptor – [in] 完整的外部 descriptor；绝不复制或保留。

返回:

成功、INVALID 或 UNSUPPORTED；不产生硬件或输出效果。
