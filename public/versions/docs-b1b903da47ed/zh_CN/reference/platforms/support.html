理解精确平台支持¶

支持分为五个独立维度：芯片事实、维护的提供者/模式、复核 Board 路由、实际软件执行范围和物理工位范围。派生能力矩阵拥有模式/路由/夹具/源码关联。支持记录拥有当前详细限制；本页说明如何选择。

平台

维护选择与关键边界

Native

独立主机模型、POSIX 行为和实际选定 RTOS 主机测试；不建立 MCU 资格

F407ZG 启明 / F407VE 天空星

精确 M4F 料号和各自 Board 事实；明确选择广泛 F407 模式、裸机/FreeRTOS 与复核 ThreadX M4 子集

F470ZG 梁山派

精确 GD32 M4F 提供者与 Board；明确选择广泛模式、裸机/FreeRTOS 与复核 ThreadX M4 子集

F103RB / GD303RC 参考

精确 legacy GPIO/UART/SPI，加有限 channel-DMA UART、IRQ 消息 I2C、物理 Flash、单次 ADC 和固定 PWM；有限 RX 有 rearm 间隙，I2C priority0 IRQ 不能调用内核通知

G474RE 来源参考

GPIO、六个 IRQ UART、轮询 SPI、固定 PWM、IWDG 和 EXTI；所选 ADC1 bulb 采样单次转换和有限 TIM6 DMA 块、轮询 I2C1 与 ECC Flash；不提供连续 ADC，也不继承 F407 其他模式

H743ZI 参考选择

固定 HSI32/HSI64 与 Cache off/on；基础选择提供有限 USART3 TX DMA 或 RX DMA-IDLE、可选已初始化 D2 SRAM1 和所选 SPI/I2C/ADC/PWM/EXTI/IWDG/Flash；独立 V 修订／HSI64／裸机／AXI SRAM 选择提供 USART3 连续 RX，或有限 TX DMA 与连续 RX 的双向模式；Flash 要求 Cache off；不提供运行态交接

U575ZI-Q 默认参考

外部已建立 TZEN=0/SWAP_BANK=0 与 MSIS4；默认 IRQ-byte UART，加 GPIO/IWDG 和所选有限 SPI/I2C/ADC/PWM/EXTI/Flash；独立 USART1 选择提供有限 SRAM1 GPDMA TX 或有界硬件 TX 链，RX 保持 IRQ bytes；ADC 供电由外部准入；不提供 RX DMA 或双域 factory

U575 独立双域参考

TZEN=1、无 OS；同步 scalar gateway 与最多八条 PC7 命令复制到 Secure 存储的 cooperative job；不保留 NS 指针，不提供通用异步跨域 transport

CPU-only Runtime

M0/M0+/M3/M4/M7/M23/M33/M55/M85 Core/Arch 及选定裸机/FreeRTOS 软件配置；不生成 SoC/Board/factory

F407 dma-tx 在一个私有静态 owner 内选择官方 HAL 有限 TX 和分离的 LL IRQ byte/event 接收器。它保留既有公共 mode、共享 ops、取消和 drain 合同；其他 F407 UART 模式保留既有引擎。私有 UART/DMA/RCC 源码选择不会启动 HAL SysTick，也不建立整库支持。选择前阅读精确 transport 合同和当前源码证据。精确链接成本、最终源码证据和物理 HIL 仍须分别验收。

F103 来源边界 将 CPU 可读的 128 KiB Flash 密度检查与配置声明的完整料号分开。ES096 第 2.2.2 节说明，正常固件不能观测仅调试模式可读的设备组和修订。独立启动不要求连接调试器，也不能凭不可用的零读取值建立已审硅片修订。

ThreadX 当前维护 Native Linux GNU 与 M4 GNU 配置；不继承 FreeRTOS Cortex-M、MPU、分裂安全状态或 tickless 矩阵。平台启动不进入任何内核。应用拥有调度器启动。

FIG-13 分开 CPU 软件覆盖、精确 SoC 接入和物理验收。FPU、DSP、缓存、MVE、SAU 和 IRQ 优先级位宽必须作为明确事实；CPU 名称绝不自动启用可选能力。

使用前核对选择¶

  1. 确认精确完整料号与 Board 包，包括未知物理事实。

  2. 在能力矩阵核对选定控制器路由与模式。

  3. 解析实际完整 assembly；不支持模式和冲突会拒绝。

  4. 核对精确源码/配置的软件证据，不能使用近似组合。

  5. 声明物理行为前核对实际工位记录。

当前记录中全部维护 MCU 的物理 HIL 均未执行。默认 Board binding 不覆盖每个 connector、transceiver 或外部器件。有限 block 模式有 rearm 间隙；连续模式也需显式替换存储与 service 预算，不保证任意负载下无丢失。Flash geometry 是物理事实，产品分区和升级策略由外部负责。ECC program_flags 可以要求每个编程单元有可证明的新擦除；全 FF 读回不能证明 ECC 擦除历史。每个已启动脉冲先排空再返回，deadline 只阻止后续脉冲。这些源机制及开发测试不继承历史结果的最终资格；精确当前源码的软件执行另行记录。
