采用显式整数帧的有限 ADC 序列¶

通过 nx_adc_group_port_t，由同一物理 owner 采集完整、有序的 ADC 帧。当前参考选择 STM32G474RET6、HSE24/PLL170 与 baremetal，使用 regular 普通 DMA 或一个 injected 帧。整数布局、触发来源、芯片期待与存储所有权均显式定义。控制算法、经校准的工程量与产品采样策略由外部工程负责。实板 HIL 为 not_executed。

选择一个静态 owner¶

FIG-16 描述共用的装配和所有权机制，不是 ADC 时序测量。 此处生成的接口为 nx_adc_group_port_t；其私有 context 拥有选定的 ADC1 序列以及可选的 DMA/TIM6 资源。应用拥有请求和完整的原始帧数组。生成、查找和运行时调用箭头保持各自不同的含义。factory 查找不会执行转换、校准、资源取得或任务调度。

四份维护中的完整输入分别选择regular 软件触发、regular TIM6、injected 软件触发或injected TIM6。其纯软件 Board 提供 PA0/PA1 模拟路由与电压假设，不建立已安装模拟电路、源阻抗或连接器可达性的事实。解析器在发布一个原子 bundle 前拒绝 ADC/common、DMA、定时器、向量与引脚资源冲突。

精确硬件配置与布局¶

所有选择均使用 ADC12 SYSCLK/8 = 21.25 MHz、HCLK 170 MHz、单端无符号 12 位普通采样。regular 最多 16 个物理 rank，injected 最多四个。regular 拥有 DMA1 channel1、DMAMUX1 channel0/request5 与向量 11/18。injected 拥有向量 18，不进行 DMA 通道准入或访问。软件触发不租用 TIM6；TIM6 触发另行独占整个定时器，计数 tick 为 1 MHz。所有向量采用逻辑优先级 5，不调用内核。

维护中的输入选择通道 [2, 1]、采样码 [0, 0] 与标称 3300 mV。通道 1 为 PA0，通道 2 为 PA1。provider 还准入经审查的内部通道 16/17/18，分别对应温度、VBAT 和 VREF。每个物理通道只有一个 SMPR 字段，因此同一通道重复出现于逻辑序列时，不能选择不同采样码。

nx_adc_group_info 报告实际不可变通道顺序、采样码查表、物理 rank 数和整数格式。存储采用小端、两字节无符号 12 位，LSB 偏移为零。普通布局的样本步幅为 2；Z 布局每个逻辑 rank 占用两个物理槽，因此步幅为 4。扫描步幅等于逻辑通道数乘样本步幅。消费者在 SETTLED 后使用 nx_adc_format_decode，忽略被丢弃的填充槽。原始数组不是浮点电压数组。

regular 请求包含 1 至 floor(65535 / physical_ranks) 个完整帧，并受实际 DMA 可达内存范围限制。injected 请求恰好包含一帧。四个参考 bundle 选择可写 SRAM1/2 域，不授权 CCM 别名。精确字节长度必须等于 frame_count * scan_stride，包含所有填充并按半字对齐。部分 rank、EOC、JEOC 或 DMA 前缀均不能建立有效帧结果。

软件触发的身份为零，TIM6 的身份为非零装配来源。该值不是计数器、孔径时间戳、物理线路身份或实测相位关系。period_us 描述所选定时器周期，不描述瞬时 ADC 孔径。

观察芯片并执行真实算法¶

g474-adc-group-x、g474-adc-group-y 与 g474-adc-group-z 命名配置分别期待修订 0x2003、0x2002 与 0x2001。配置是不可变期待，不是实读硬件。Platform 准入与独立私有构造函数使用既有 nx_stm32_identity_read source 和共享 core 芯片策略，对比实际 IDCODE 与 Flash 大小寄存器。错误 group/密度、密度不可用、未知 cut 或与期待不符的 cut 均拒绝。普通重新启动会再次观察，不缓存准入结果。四个规范输入均选择 X 布局；Y/Z 选择必须观察到匹配 cut，并取得各自独立的资格记录。一次 X factory 执行不能为这些配置建立资格。

经审查的模式记录 是 cut 规则及所需 workaround mask 的唯一来源。provider 不维护第二份修订允许列表或 reader。group 和密度本身不能识别精确封装或可订购料号；选定的 SoC 与 Board 仍必须授权各自的精确路由。

Z 配置将每个物理通道 rank 重复两次，保留每对的第一个槽。因此最多允许八个逻辑 regular rank 或两个逻辑 injected rank。显式原始步幅保留额外槽，没有隐藏打包缓冲区。每种配置均丢弃一次真实预转换扫描，并在每次有效采样前后实际禁用/重新启用 ADC。这些是实际寄存器算法，不能由 workaround 元数据推定已经执行。

固定 HCLK/ADC 比值为 8，避开 ES0430 第 2.7.5 节大于 10 的条件。JQDIS1、单个 ADC 组、无双重转换、无自动 injected 转换、无抢占等约束排除另外的动态 context 情况。这些模式限制不为未选择的连续 injected 队列或其他时钟比值建立资格。

采样时间与真实预转换¶

八个采样码分别代表 2.5、6.5、12.5、24.5、47.5、92.5、247.5 和 640.5 个 ADC 周期。每个物理 rank 另需 12.5 个转换周期。报告的半周期查表及展开扫描预算包含所有丢弃 rank。在所选 ADC 时钟下，内部 VREF 至少需 code 5，温度至少需 code 6，VBAT 至少需 code 7。冷态初始化只启用选定的内部源；选择温度时等待 122 us，否则等待 22 us；执行校准后再等待至少四个 ADC 周期。这些未屏蔽中断的等待不建立模拟精度或校准电压。

校准没有独立的新完成标志。短保护区围绕 ADCAL 命令、屏障和紧随的 busy 观察，保存并恢复进入时的中断屏蔽状态；等待完成时不屏蔽中断。初始化要求先观察 ADCAL1，再观察硬件清为 ADCAL0。首次观察为零具有歧义：命令可能被拒绝，也可能在读取前已经完成校准。此时保守报告 IO，保留部分效果，供完成退出的清理和冷态重试。未变化的 CALFACT 或标称 116 周期时长均不能证明新完成；不会写入因子哨兵值。

每个已接受请求取得有效采样前，provider 执行并丢弃一次完整软件扫描。regular 预转换暂时使用已借用的原始输出范围作为 DMA 存储，injected 使用 JDR 寄存器组。调用者不能将其作为有效样本读取。预转换期间禁用看门狗与周期触发源。空闲时禁用 ADC；任务延迟后必须真实重新预转换，不能只更新时间戳。

硬件触发的精确周期必须容纳完整展开扫描和异步触发裕量。必要冷态新鲜度预算为 period_us + ceil(scan_halfcycles * 4 / 170) < 1000；较慢采样码因此降低可准入的最大周期。配置与私有构造函数采用相同物理单位，拒绝不可能满足的预算，不进行舍入。运行时新鲜度检查仍需覆盖实际任务/装载延迟。陈旧装载保留借用，合法撤离进行中的硬件，再丢弃一次真实扫描后才发布有效帧。

可选模拟看门狗将原始上下阈值应用于选定组。丢弃预转换期间禁用看门狗，有效窗口中锁存终止 IO 故障。它不提供产品跳闸策略、比较器 break 路由、安全输出或保证的反应时间。

准入、推进与消费¶

  1. 取得静态定型接口并显式启动 Platform。启动会校准冷态 owner，但不启动采样或隐藏任务。

  2. 初始化请求，取得当前不可变 info，为独立完整原始数组准备有限的绝对单调 deadline。prepare 不借用、不触碰样本字节，本身不验证芯片或 DMA 域。

  3. 通过唯一的特权、未屏蔽中断的任务执行者提交。拒绝不保留指针或新效果。NX_SUCCESS 表示 ACCEPTED，包括装载失败后可能已通过实际撤离而 SETTLED 的情况。

  4. 保持描述符与数组有效。IRQ 只记录有界的所属事实；同一任务显式调用 service，推进预转换、采样与排空。应用停止调用 service 后，没有 worker 代为推进。

  5. acquire 观察 NX_REQUEST_SETTLED 后检查结果并解码有效帧。在重新 prepare 同一存储前，另行等待所有外部观察者退出。普通成功不会自动重装。

provider 在准入前拒绝回绕、重叠、控制别名和不完整范围；已知控制描述符在首次读取字段前即拒绝。没有可信完成时间戳时，首次在 deadline 或之后观察到完成则报告 TIMEOUT。deadline 前已观察的完成允许稍后结束必要撤离。该观察规则不是物理执行时间或 service 延迟保证。

归还借用前先撤离¶

FIG-06 提供共享请求状态合同。 ACCEPTED 和 REJECTED 是准入结果，不是新增请求状态。在本 provider 中，SETTLED 必须具备下述硬件与引用证明。

  1. 对于 TIM6，先证明 CEN0，再选择基于 enable 的静默 MMS 路由。冷态/重装 UG 位于该静默路由后，并要求新 UIF 及其确认；stop 不发出 UG，也不产生额外更新触发。

  2. 只请求匹配的 regular 或 injected stop，观察所属 START/STOP 撤离，然后合法禁用 ADC 并观察 ADEN/ADDIS0。只有 JADSTART0 后才能改变 JEXTEN；ADDIS 不能替代组排空。

  3. 对于 regular DMA，证明 EN0，撤离地址、剩余计数和 DMAMUX。TC 与 CNDTR0 本身不会停止 CONT1 扫描或硬件触发。

  4. 在 W1C 前保留已捕获的 TE/OVR/看门狗故障，只确认已观察的所属标志，并在排空与最终发布期间复查。

  5. 禁用并等待选定向量及活跃发布者退出。最终元数据保护区先分离请求，再以 release 发布 SETTLED，作为 provider 的最后一次访问。injected JDR 值只在完整的新 JEOS 与排空后复制。

成功恰好报告所请求帧数。错误、取消和超时报告的保证有效帧数为零，即使原始存储看起来具有部分或完整前缀。首次终止原因保持锁存。计数器、ADC、DMA 或向量拒绝撤离时，保留 QUARANTINED 存储及恢复责任，service 可以重试同一真实排空。已退出前任的重复 stop 不能撤离后继 owner 的控制器。

公共 stop 关闭新准入并排空已接受请求，其成功不释放引脚、内部源使能或时钟租约。最终 Platform close 只有在完整请求/源/向量撤离后才恢复逻辑优先级和公共配置，随后释放外层资源。close 失败保留未完成租约，供重试。故障恢复必须显式完成退出的冷态 close 与 restart，不会自动重放。

来源与软件证据¶

权威 API 为公共组合同。私有 provider 实现真实序列、定时器、看门狗与 DMA 迁移。选定的官方 ADC/DMAMUX 定义保持私有，由 STM32G4 依赖记录 锁定。RM0440 Rev9、DS12288 Rev6 与 ES0430 Rev9 建立经审查的硬件事实；模式记录绑定其来源身份与算法范围。

公共 GoogleTest/GoogleMock 合同、外部寄存器/事件测试及正常生成 factory 测试执行真实 common/provider 代码，覆盖完整 rank 边界、整数解码、丢弃预转换、真实连续 regular 扫描、OPM、别名、deadline/迟到故障、拒绝撤离、实例交接及保留清理。独立准入用例使用真实 IDCODE/Flash 大小存储和同一生成策略，不替换 reader 或比较函数。

当前开发验证通过八项公共 API 用例、55 项真实 provider 用例，以及四个正常生成 factory 程序各 16 项用例，共 127 项，无失败或跳过。四个规范 X 配置也均通过正常 ARM 配置/构建、资源预算，以及一个接口、一张方法表和五个方法槽的保留检查。这些是模型及固件链接结果，不代表已经完成模拟信号实测、正常 Y/Z 配置的资格或干净且可复现的软件候选。

实际模型结果和 ARM ELF/资源检查属于其精确来源、配置与执行记录。链接不会执行 ADC，也不证明模拟波形。干净且可复现的软件候选、已安装 SDK 组合与实板 station 验收分别具有独立证据。模型、框图或策略 mask 均不建立 PCB 接线、实测精度、孔径时序、物理 HIL 或经过安全资格认定的控制系统。
