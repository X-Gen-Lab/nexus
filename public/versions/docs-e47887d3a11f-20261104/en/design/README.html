Current design and execution ledgers¶

Current code uses unified physical directories, TOML static assembly, typed factories and shared polymorphic tables. Public C11 faces contain only read-only ops and private context. Each instance owns independent state; callers supply request and block storage. SDKs/provider storage remain private and product projects external. Use these design contracts together with current delivery; historical documents establish no current qualification.

For assembly, borrow and recovery responsibilities of five bounded software increments, see mapped storage, AMP, image handoff, RTC and frame boundaries. The complete original exit conditions and hardware status remain unchanged.

New F103RBT6/GD32F303RCT6 references and G474/H743/U575 increments follow each contract’s exact configuration, complete-image and SDK exits; public types do not imply whole-family or all-peripheral support. F103/GD303 add finite UART channel-DMA, IRQ I2C, physical Flash, single-shot ADC and fixed PWM. GD303 also maintains EXTI and a hardware-cascaded timebase. G474 adds bulb ADC shots/finite TIM6 DMA, I2C1 and ECC Flash beside GPIO/UART/SPI/PWM/IWDG/EXTI. H743 fixed HSI/Cache supports finite TX DMA or RX blocks with rearm gaps and explicitly initialized D2 SRAM1. Separate V/HSI64/baremetal references add finite SPI4 DMA and continuous double-buffered USART3 RX with Cache off/on. rx-dma-continuous retains independent IRQ TX; only the separately selected dma-duplex-continuous adds finite TX DMA. The new duplex mode admits only AXI SRAM, with at least three equal RX blocks; it does not imply FreeRTOS, PLL384 or D2 SRAM support. Seven other finite peripheral classes have software fixtures. U575 TZEN0 adds SPI/I2C/ADC/PWM/EXTI/Flash with external supply and security-state admission.
