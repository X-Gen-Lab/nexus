FIG-18 Target RAM maintenance settlement design¶

Identity: target. Scope: selected V/cache-off synchronous physical pulse; these are protocol stages, not a new public request enum or a bounded return-time proof.

Each edge is guarded control flow. Assembly entry, the C phase and the assembly return gate share one embedded selector-effect ledger: record before an RNR write; clear only after exact restoration and readback. Independent MPU captures stay in r8-r11, which the C phase must not modify. Pre-trigger rejection after temporary effects must first prove rollback. After trigger, TIMEOUT latches a result; it neither cancels the pulse nor returns to a Flash handler. The C phase actually drains both banks under a valid TIM2 epoch, proves LOCK and restores MPU while retaining private VTOR and private MSP. Every returning C path must pass the independent assembly gate: read back both-bank idle, zero retained effects and the exact saved target-control value with LOCK; prove MPU against protected captures; then restore linker-known g_pfnVectors, execute barriers and prove VTOR readback. Only then does the assembly bridge restore CPU state and return. Permanent busy stays in the RAM drain loop. Unproved capture, cleanup or return conditions enter the nonreturning RAM terminal, without implying automatic reset or watchdog service.
