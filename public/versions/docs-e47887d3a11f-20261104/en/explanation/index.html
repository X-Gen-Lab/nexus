Architecture explanations¶

Understand boundaries, static assembly and retained storage before changing a provider. The linked design contracts remain authoritative.

The I/O evolution design explains resource plans, optional traits and enhanced data contracts; its execution ledger keeps current and pending work separate.

The H743 Flash RAM design explains the selected V/cache-off maintenance boundary: a private CPU bridge, RAM vector owner, temporary MPU protection and real drain before return. The source is integrated; the target diagrams retain open production-ELF and complete software exits.

The RTC/LPTIM explanation separates raw calendar, finite counter and Core deadline domains. It covers current Native typed assembly, ownership, drain and explicit lifecycle; physical RTC/LPTIM and low-power support remain separate targets.

The GPIO pin-state explanation separates explicit GPIO images from factory identity, cold pad/gate ownership and checked cleanup. Its current G474 reference does not provide wake, retention or hardware low-power qualification.
