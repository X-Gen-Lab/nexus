架构解释¶

修改提供者前，先理解边界、静态装配和必须保留的存储。链接的设计合同仍是规范依据。

I/O 增量架构说明资源计划、可选 traits 与增强数据合同；对应台账分别保留当前实现和待完成工作。

H743 Flash RAM 设计说明选定 V／Cache off 的维护边界：私有 CPU bridge、RAM 向量 owner、临时 MPU 保护，以及返回前的真实排空。源代码已接入；目标图所要求的生产 ELF 与完整软件退出仍未完成。

RTC/LPTIM 说明区分原始日历、有限计数与 Core deadline 域。本文解释当前 Native 类型化装配、所有权、排空和显式生命周期；物理 RTC/LPTIM 与低功耗支持仍是独立目标。

GPIO 引脚状态说明将显式 GPIO 图像与 factory 身份、冷态 pad/gate 所有权及受检查的清理分开解释。其当前 G474 参考范围不提供 wake、retention 或硬件低功耗资格。
