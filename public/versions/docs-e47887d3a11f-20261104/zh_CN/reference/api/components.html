字节传输、TLS 与 MQTT 装配¶

byte_stream.h 定义了带有限绝对截止时间的即时部分读取和复制写入。SUCCESS 表示本地字节准入，不表示已交付对端；BUSY 且字节数为零时，需要所有者显式推进。字节流操作返回后，不再借用调用者的缓冲区。可选的 Nexus::LwIPTCP 客户端在锁定的 NO_SYS IPv4 协议栈之上实现此接口。执行器、对端选择、可信时间、熵源以及停机和重连策略仍由产品负责。

装配代码仅初始化一次 lwIP，并提供有效的网络适配器、调用者拥有的存储以及正数接收帧预算。全部原始协议栈 API、回调、网络推进和客户端由同一串行 NO_SYS 执行器负责。接口的数据和控制调用必须位于原始回调之外；跨接口的嵌套修改以 BUSY 拒绝。组件不创建 socket 层、worker、调度器、锁、名称注册表或最大尺寸不透明对象池。TCP start 成功只表示准入 CONNECTING，不表示连接已经建立。首次有限连接截止时间不能延长。既有字节接口是带状态的句柄，不是就绪证明。

TCP 写入使用官方复制准入：正数部分写入计数表示调用者可立即复用输入，已排队数据仍保存在协议栈的有界存储中。之后的输出失败不能撤销该准入。诊断持续报告该失败，后续数据／推进调用在显式 abort 之前仍保持失败。RX 最多持有一条已接受的 pbuf 链；被拒收的链仍归 lwIP 所有。只对实际消费的字节返还接收额度。缓冲数据先于有序 FIN 交付，对端半关闭后仍允许写入。帧预算限制取得的帧数，不限制任意原始回调的总耗时。每次非零字节尝试最多可以执行一轮显式预算的网络推进。

官方 PCB 分配共享有界协议栈池及其回收策略。它可能推进待关闭连接，或回收 TIME_WAIT、LAST_ACK、CLOSING 及较低优先级的活动连接；即使新的 start 随后失败，也可能调用其他客户端的错误回调。本地拒绝表示该客户端不保留新的引用，不承诺整个协议栈未发生变化。

生产者完成 join 后，所有者消费缓冲 RX，并在首次有限关闭截止时间内遇到 BUSY 时显式推进和重试 close。该截止时间不能延长。超时后必须显式 abort，存储在此期间仍须有效；abort 丢弃本地数据并撤除回调引用。close 成功仅证明此客户端上下文已完成最后一次协议栈访问。官方协议栈仍可能保留待后续处理的 FIN 及 TIME_WAIT 状态。在产品的完整协议栈停机／重启流程允许撤回之前，网络适配器、全局存储池、定时器和未改变的时钟域都必须保持有效。客户端上下文脱离回调引用不证明全局协议栈停机或 MAC／PHY 已排空。

普通 TLS／MQTT 调用者包含 tls.h 或 client.h，并链接 Nexus::TLS 或 Nexus::CoreMQTT。公共会话类型是不透明类型，不暴露厂商头文件或配置宏。只有静态装配翻译单元选择 Nexus::TLSStorage 与 nexus/tls/storage.h，或 Nexus::CoreMQTTStorage 与 nexus/mqtt/core_mqtt_storage.h，以分配锁定后端的精确布局。显式存储目标必须局限于装配代码；字段是实现状态，不是业务控制 API 或二进制 ABI 承诺。产品显式调用 nexus_add_tls() 或 nexus_add_coremqtt() 创建选定目标。

TLS 配置是单一串行 TLS 1.2 客户端／PSA 域，使用 ECDHE-ECDSA P-256 和 AES-128-GCM/SHA-256。它要求显式 DER 信任材料、可信 UTC 和经过审查的熵质量声明。调用者提供的 64 KiB 内存区和 512 B TX 暂存区不包含会话元数据、传输存储和栈。先 join 全部接口使用者，再 abort 会话，然后停止 runtime；失败或 BUSY 的清理仍保留资源。MQTT 3.1.1 配置提供 clean session 和 QoS0/1；回调仅在返回前借用传入视图。显式 DISCONNECT 和 TLS close 表示本地推进，不替代下层排空或对端确认。网络、TLS 和 MQTT 组件合同详细规定所有权及固定配置限制。

对于两种 Ethernet adapter 配置，link output 成功表示帧已被接纳。失败的 SETTLED TX 结果会保留，并通过 nx_lwip_adapter_service 报告一次；在该次观察之前，另一次 link output 不得覆盖或复用 TX 缓冲区。观察错误只会清除已经结清且不再被借用的请求。此机制不新增错误队列或实例存储，也不复位 MAC、重放数据包或选择产品恢复策略。ACTIVE 或 QUARANTINED 的借用仍被保留。TCP 字节 facade 保留其既有的连接失败策略；观察到帧错误不承诺恢复。

每个镜像选择一个单例 NO_SYS 协议栈配置。默认 Nexus::LwIP 和 Nexus::LwIPTCP 配置保留复制式 RX 及其既有存储布局。下列显式目标选择 RX 负载借用；CMake 拒绝在同一镜像中组合复制式与借用式配置，也拒绝将复制式 TCP 目标与借用式 adapter 存储组合。这些目标不创建第二个协议栈、netif、执行器、worker 或分配器。

每个帧槽最多将 136 B 复制到自身可写的 PBUF_REF 前缀。该前缀覆盖 14 B Ethernet 头、最大 60 B IPv4 头和最大 60 B TCP 头，包括官方 TCP 输入路径会原地更新的字段。前缀可能包含负载；不超过 136 B 的帧会被完整复制。只有前缀之后的字节通过 PBUF_ROM 尾部引用原始、不可变的 MAC 片段。raw 消费方必须将这些尾部视为只读，并在写入前克隆。这是 RX 负载尾部零复制；不提供整帧或 TX 零复制。ICMP echo 使用官方的复制后回复路径。VLAN 交付、IPv6、DHCP、DNS 和 IP 重组仍未选用。

保留的头部或尾部 pbuf 引用会使其帧槽及精确 MAC 借用持续存活。custom-pbuf 的最终释放只标记片段已归还；它从不调用 provider，也不重新武装 DMA。在每个片段的最后一个引用都结束后，后续 owner service 或 stop 才释放精确借用。释放失败会保留令牌与存储，并关闭后续 adapter 接纳。产品须先关闭 PCB，并等待 raw 用户、回调、队列和观察者退出。只要仍有任何 pbuf 引用，stop 就返回 BUSY；只有精确 RX 释放及既有 MAC／TX 撤离义务均已完成后才解除挂接。排空失败绝不撤销借用。

槽数是元数据容量，不是 provider 能力，也不是 ACK 推进承诺。并发获取还要求 provider 支持独立借用，并为实际帧提供足够描述符。维护中的 enhanced F407 和 GD470 MAC 引擎在软件模型中支持独立持有 RX 头及逆序释放；该事实不建立通用容量、无损运行或任意保留流量下的推进保证。产品须针对所选帧布局和工作负载预算并释放借用。

选定的借用式配置保留两个备用的 512 B PBUF_POOL 载荷块；复制式配置仍使用既有的 24 块。16 KiB arena 和其他固定协议池保持不变。RX custom-pbuf 元数据、136 B 前缀、MAC 缓冲区和复制式 TX 缓冲区仍需调用方另行提供存储。TX 和 ICMP 回复回退可使用既有的有界 RAM 分配器。该池容量需要维护的组织 fork，仅让显式 custom-RX／custom-pbuf 配置豁免原版 PBUF_POOL／TCP_WND 容量启发式检查。其他协议栈 sanity 检查全部保留。此豁免不能证明原版上游也准入该配置，或证明完整 SRAM 可容纳。标称池计数不是完整 SRAM 测量。

C11 仅链接的外部开发配置探针使用两个帧槽、四个 piece、2048 B 主栈且无 libc heap。选定镜像通过 32 KiB SRAM 预算。对于两款参考芯片，复制式配置的 BIN 字节和调用方存储均与同一源码、包含公共 TX 结果可观察性改进的基线一致。

nx_result_t nx_lwip_adapter_service(nx_lwip_adapter_t *adapter, size_t receive_budget)¶

推进 MAC、有界数量的完整 RX 帧以及协议栈定时器回调。

备注

与所有 lwIP raw API／回调共用同一任务 owner。定时器回调开销由固定协议栈配置和应用回调决定；这不构成整个调用的硬性时间上界。复制式配置在精确归还令牌前复制 RX 字节。显式借用式 RX 配置保留不可变载荷尾部，直到 custom-pbuf 引用结束。release 失败会保留令牌并关闭后续接收推进；stop 重试 release，不会将重复字节送入协议栈。inline 和延后结清的 TX 失败在请求复用前均保持可观察；尚未观察时，新 link output 返回 ERR_IF，不接纳字节。inline SUCCESS 仍可立即复用。消费已结清的失败会将 TX 请求置为 READY，不会自动复位、重放、关闭 adapter 或强制重启。产品决定 provider 恢复策略；实际尚未结束的借用绝不会被撤销。

参数:

  • adapter – [inout] 仍有效且包含所有未结束借用的存储。

  • receive_budget – [in] 此次调用最多取得的帧数，必须为正数。

返回:

成功、一个待观察的已结清 TX 失败，或 provider／release／状态错误。已结清的 TX 失败会在继续推进前消费一次。

将本次可立即接受的部分写入复制到有界栈存储。

备注

关闭准入，并在显式局部排空后脱离。

TMP117 单次采样合同¶

在固件目标的 LIBRARIES 中选择 Nexus::TMP117 器件协议与 Nexus::TMP117I2C 已结清 I2C 适配器。这些可选 CMake 目标不新增生成式器件类别或另一套配置入口。产品提供已配置的固定地址端点、单调时钟、非零时钟域与 epoch，以及预期的现有数字偏移。ADD0 接线、电源、总线调度和物理恢复由外部负责。I/O 所有权架构 继续适用；不引入传感器工作线程、堆、地址扫描或额外的 owner 框架。

已审查器件限定为完整标识 0x0117 的 TI TMP117，采用单次模式、一次转换并禁用平均。初始化检查标识、EEPROM 就绪和锁定状态，核对现有偏移，再请求并读回 shutdown 状态，保留无关配置位。一旦发出 shutdown 写入，写入或核验失败即保留相同端口、配置及时钟，将实例标记为未初始化且状态不确定；清理使用独立 deadline。更早的失败不会取得新绑定。begin 先清除过期就绪状态再请求一次转换；poll 读取就绪状态后再读取温度。每次寄存器读取先写指针，再以重复 START 读取两个高字节在前的字节。仅接受同步端点事务：每次返回，包括错误，均结束对描述符和 TX/RX 存储区的使用。不能用仅支持异步的端点替代这一已结清合同。

仅 SUCCESS 发布包含独立数值的样本。BUSY 和错误均保持整个输出不变。有符号原始值与现有偏移均以 1/128 摄氏度为一个 LSB。micro_celsius 舍入至最近的微摄氏度，恰好位于中点时远离零；完整有符号格式的换算不会超出 int32_t。已审查输出范围为芯片应用现有偏移之后的 -55 至 150 摄氏度。POR、饱和及超出该范围的值返回 IO。芯片已经应用偏移：驱动仅核对并报告，不会重复相加、编程校准或修改 EEPROM。

observed 复用 nx_io_timestamp_t，采用微秒速率、显式时钟域与 epoch、SERVICE_OBSERVATION 来源，以及未知的物理不确定度。它表示成功读取寄存器的完成时间。转换发生于 conversion_started_at 与 observed.ticks 之间；两者均非硬件转换时间戳。需要保守限制最大样本年龄时，先校验时钟域、epoch 和速率，再将当前时间与转换开始下界比较。最近读取寄存器本身不能证明数据新鲜。样本副本在器件 stop 后仍有效，不保留器件、传输或样本缓冲区引用；消费者仍须遵守时钟连续性假设。

所有调用由一个串行任务执行器执行，并使用有限绝对 deadline。Poll 在交换前后检查转换 deadline。成功读取到未就绪状态时返回 BUSY 并保留转换元数据。任何传输错误，包括传输 BUSY，都会结束采样并要求显式重新同步；读取 CONFIG 会清除就绪标志，因此随后温度读取失败时，不能将其重试为缓存零值或无限未就绪转换。一次样本成功后再次 poll 返回 STATE。已知控制与输出存储区重叠会被拒绝；由于通用驱动无法推断不透明上下文及借用总线存储的范围，调用者必须保证这些存储不重叠。

cancel 使用独立的有限清理 deadline，只有读回 shutdown 状态后才成功。它不能抢占正在执行的同步交换。清理失败保留绑定及外部物理恢复责任；timeout 或错误从不证明物理停止。应重试取消或执行外部恢复，然后显式重新初始化已经关闭的实例。仅在调用和外层 owner 用户均已 join 后，stop 才可解除软件绑定。Stop 不执行 I/O，不关闭器件电源，不释放 Board 资源，也不消除尚未解决的物理恢复责任。Owner 不能把同步栈事务排到自身执行器之后。

协议遵循 TI SNOSD82D，2018 年 6 月发布、2022 年 9 月修订，第 6.5 和 7.3–7.6 节（官方数据手册）。AVG=00 时单次转换最小、典型、最大耗时分别为 13/15.5/17.5 ms；调用者还需计入总线和调度余量。上电就绪需要 1.5 ms，通过总线及 EEPROM 状态报告，不使用隐藏 sleep。审查参考的 Zephyr 实现为提交 413b789deb391d3a37d06b463288a5fe765ee57e 的 drivers/sensor/ti/tmp11x；未复制驱动源码。

软件模型测试覆盖有符号换算、舍入、现有偏移、就绪状态、失败切点、deadline、取消、独立实例及已结清通用 owner 组合。ARM 链接探针采用维护中的 F407 与 GD470 空装配，并显式使用未接线的软件端点；仅证明 C11 链接和资源成本。器件精度、PCB 接线、I2C 波形、上电行为、真实转换延迟及取消仍需物理 HIL，目前尚未执行。工位必须记录精确器件标识、ADD0 地址、供电与上电时序、上拉、总线频率、已知温度参考、偏移、时钟身份、失败注入及已 join 的停机结果。

在 STATUS 前授权暂存意图，或拒绝此 epoch。

备注

参数:

  • acm – [inout] 同一个活动适配器及串行 Task 执行者。

参数:
