选定 I/O 与时钟扩展交付¶

本页记录选定 H743、U575 和 G474 软件扩展的开发观察，以及针对它们实际执行的检查。当前工作源码尚未最终冻结。下列专项模型结果不能为后续提交、ARM 镜像、电气连接或软件候选建立资格。

结果索引 标识精确夹具、原始命令回执与新生成的 XML。I/O 架构合同 及其 FIG-16 说明静态装配与直接运行时派发；请求生命周期图 定义借用与撤离转换。这些既有图示不建立新增装配的资格。

STM32H743

hsi64-pll384-cache-off、已审 V 修订、裸机参考

显式冷态时钟计划，标称 CPU 384 MHz／HCLK 192 MHz／APB 96 MHz，并带明确编写的 HSI 边界；外设内核与定时器时钟域仍分别定义。这是选定参考，不是 DVFS，也不是实测时钟。

STM32U575

USART1 dma-tx, TZEN=0, MSIS 4 MHz, 8N1

一个选定状态与 const ops 表；GPDMA1/channel0/request25，有限 1–65535 字节 TX 全部位于非安全 SRAM1 [0x20000000,0x20030000)。IRQ 字节 RX 仍可用；该模式不包含 RX DMA、链表或 TrustZone broker。

STM32G474

can_fd / iso-fd-normal 或 iso-fd-loopback，FDCAN1

一个固定 212 word 消息 RAM 区间与三个物理 TX 元素；HSE24 下标称仲裁速率 500 kbit/s、数据速率 2 Mbit/s。正常模式与内部环回模型测试不为收发器、带终端电阻的总线或对端建立资格。

STM32G474

pwm_adc / finite-regular-dma

一个完整 TIM1/ADC1/ADC12/DMA1-channel1/DMAMUX/COMP1 参考 owner；1 MHz 计数器、100 刻度周期、50 刻度触发与 170 内核刻度死区。有限半字采样与 PWM 帧持续借用，直到撤离得到证明。

明确编写的夹具选择精确 SoC 事实与 Board 路线。应用、控制策略、网络协议、工作任务、私有 PCB 数据及恢复策略仍位于外部仓库。平台不会从软件夹具推断电气阈值或可接受的执行器行为。

Typed factory 查询返回既有不可变接口，不访问硬件、不分配，也没有隐藏工作线程。装配选择可选状态与私有官方头文件。仅源码选择不是实测 Flash/RAM 或延迟结果；最终 ARM 成本需要匹配的 ELF/BIN/map 与检查。

完成与失败¶

U575 DMA 传输完成不代表 USART 线上完成。选定模式依据已审 U5 勘误，跨请求与取消保留 DMAT。最终结清需要新鲜的通道撤离／复位证明、独立 USART TC 与引用排空。排空失败时，请求保留在 QUARANTINED；超时不会撤销对源缓冲的借用。

G474 CAN FD 将待处理 TX 添加／请求位与新鲜的逐元素发送或取消结果分开。接收队列容量不会掩盖锁存协议状态。G474 PWM/ADC 汇合定时器、ADC、DMA 与 IRQ 引用，并在发布最终请求状态前锁存晚到故障。撤离失败时，产品必须继续服务并保留存储。选定调用上下文与物理参考假设见公共 API 和有限 PWM/ADC 合同。

构建与依赖交付¶

私有官方输入精确新增两个 U5 LL 头文件（dma、usart）与三个 G4 FDCAN 定义头文件，包含它们的传递定义。版本锁定、许可与 CMSIS 配对仍被检查。选定闭包不链接 HAL handle、厂商 tick、厂商 IRQ 回调或第二个传输 owner。

源码 SDK 现在要求新的公共／私有 I/O 模块、联合配置代码与显式系列载荷。verify_consumers --parallel N 为每个消费者构建接受严格正整数并行任务数。省略时保留既有基础消费者 4 任务、现代消费者 2 任务的默认值。其 Python 回归借助外部子进程替身检查全部 13 个消费者根目录与 16 个镜像目标，不构成新真实 SDK 消费者包的执行。
