I/O 增量架构：静态资源与明确的数据合同¶

本文说明如何扩展 I/O 模式，同时避免隐藏执行、单位含混或增加第二个资源 owner。内容记录当前迭代的软件机制及其边界。42 项实施台账是实现、软件和硬件状态的权威记录；本文不替代台账，也不宣布本轮迭代完成。当前 GPIO 引脚状态说明解释精确选定的 G474 图像、保留的冷态租约以及独立的 provider/Platform 清理；wake 和 retention 仍是单独工作。已封存的 c4249e98 候选保留原有范围。新增代码必须建立自身执行证据。

装配与执行承担不同责任¶

一份 authored TOML 装配选择已审 SoC 模式与 Board 路线。严格解析器在发布不可变 typed IR 和原子生成 bundle 之前检查字段、容量及资源约束。CMake 仍是唯一的软件目标图。非法输入不会触发便利的回退选择，也不会留下可使用的部分配置。

生成的 factory 按 typed 身份返回已有静态 face。查找不分配、不初始化硬件、不读取硅片身份、不加锁，也不启动任务。显式启动后，日常 I/O 通过共享只读方法表和实例私有 context 调用实现。应用负责执行推进、调度与停机。可选增强 face 与其控制器共享预定的所有者；第二个 face 不会取得第二个硬件执行者。

将声明的流预算绑定到实际缓冲池¶

可选的流 profile将不可变的容量假设绑定到一个已选连续 UART 或 ADC face。解析器仅在装配显式编写 profile 时生成该常量。factory 查找返回已有 profile，既不创建缓冲池，也不启动采集。未使用 profile 的入口保持各自合同，不会隐式执行这一 profile 的约束。

当前 F407/F470 双缓冲模式需要两个硬件目标、一个替换块，以及足以覆盖所声明 FIFO 前沿归还延迟的额外块。计算将保留块数向上取整，并检查整数溢出、32 位地址范围和 16 位 DMA 计数器。目标替换延迟必须严格短于声明的单块填满时间。UART 的单位是字节；ADC 的单位是完整扫描，每个所选通道存储一个 uint16_t。ADC 分辨率位数不会改变这个存储宽度。

profile 的冷准入在调用原 provider 前检查调用方的实际块数、相同容量、已有借用、状态以及 payload 与控制元数据不重叠。缓冲池使用者必须已经退出并完成 join。别名检查由已配置池大小限定，复杂度为二次方；它不向 IRQ 或稳定数据路径增加检查。应用仍负责池存储、consumer 归还顺序和执行推进。速率、归还延迟和 IRQ 延迟都是 authored 假设，标记为 physical_qualified = false。耗尽时停止并报告间隙，不会建立 UART 背压、无损传输，也不会保存在触发停止期间本来应发生的 ADC 采样。

可选 traits 描述选定行为¶

已有 factory.capabilities 开关控制生成只读 trait 对象。选定 I/O traits描述已审 provider 与模式，包括格式、限制、取消范围、连续性、时间戳来源与 DMA 策略。关闭开关不生成新增 trait 对象，不改变双指针 base face，也不增加可变设备状态。

double_buffer 或 rearm_gap 等连续性值描述机制，不代表已经验证吞吐。Cache 行要求描述选定 provider 的策略，不证明某个时钟 profile 已启用 Cache。CAN 邮箱数是 provider 专属事实。Traits 不授予 Board 接线权限或物理资格，也不能覆盖准入检查。

Controller 和 endpoint 记录分别描述各自接口。不能把父控制器的 byte-SPI 或普通 I2C 限制套到增强 endpoint。按请求确定 word 宽度的标记不代表长度无限。分配调用者存储前，先核对选定 face、计数单位和 provider 限制。

冷态硅片准入是显式步骤¶

硅片 preflight在调用者串行化的冷态 Thread 上下文中读取一次显式、有界的来源，复制 device group、revision 与 Flash 容量观测并比较不可变策略。它不探测设备、不启用时钟、不改 option bytes，也不保留借用。默认平台不会自动调用这个可选 helper。

Device group 与 Flash 容量不能证明完整可订购物料号、封装或 PCB。Revision 规则绑定已审来源摘要和必需的 workaround mask；helper 不认证来源，也不证明 workaround 已经实现。未知 revision 必须拒绝或采用显式 unreviewed 策略。该策略不能绕过被阻止的 revision、缺失的观测、设备或容量不匹配，以及缺少必需 workaround 的情况。

准入后仍由调用者决定是否启动硬件。读取 revision 不建立电气行为、全部模式的 errata 覆盖或 HIL 资格。

只读 capabilities.py --assembly 视图通过 silicon_admission，分别投影系统时钟 owner 与各选定控制器的复核策略。它使用既有 policy 与 typed IR。endpoint 或 companion 不继承其 owner 的复核；没有适用记录的 owner 报告 null。H743 所选时钟与 SPI DMA 记录保持各自 revision／profile 范围，G474 ADC 则保留 device、density、workaround 与复核摘要字段。这些是经复核的准入规则，不是已观察的芯片身份、更广勘误覆盖或物理资格。

UART word 请求保持从 ACCEPTED 到 SETTLED 的原有借用规则。取消或 deadline 不会提前归还请求或 payload。所有者必须继续 service，推进线上完成与排空；不能证明排空时保留 QUARANTINED 存储。Byte UART 缓冲区和状态不会隐式变成九位缓冲区。

F407 和 F470 的仅 RX DMA 模式现在使用紧凑的接收所有者，并保留普通 IRQ TX。只有双向 DMA 模式嵌入独立的 TX-DMA 扩展。两者复用相同的接收借用算法和共享只读公共方法表布局，不保存可选实现指针，也不在运行时选择 TX provider。仅 RX 操作不会取得或撤回无关的 TX-DMA 执行通道。双向模式的向量按真实外层所有者及其独立部件解码。接收池排除完整双向对象，包括它的扩展。

RX 与 TX 两种准入顺序都会从每个未来 RX 目标中排除 TX payload 和完整 TX 请求描述符。停止先关闭准入并排空 RX producer 与 consumer 借用，再排空所选 TX 内存及线上活动，最后撤回 UART 和 RX 向量。排空失败保留相应存储和责任。Flash 与 RAM 节省由实际链接 ELF 对比确定；仅主机 sizeof 预期不能建立 MCU 成本或指令路径未变化的结论。

独立选择的 H743 dma-duplex-continuous 在一个 USART3 owner 内组合连续 RX 与有限 TX DMA。其精确 V／HSI64／裸机参考使用 AXI SRAM，支持 Cache 关闭或开启；请求与完整 RX pool 必须互不重叠，并分别保持借用直到对应排空完成。既有 rx-dma-continuous 仍使用 IRQ TX。三个向量、冷态重启及保留生命周期 taint 的边界见 H743 provider 合同。两种选择均不扩展到 RTOS、PLL384 或 D2 RAM。

同步整段 CS 接口在使用硬件前验证每个 segment 和数据范围。TX 指针为空表示重复 dummy 字，RX 指针为空表示丢弃，两者都为空可以表示仅产生时钟的阶段。所有 segment 共享一次 CS 有效区间。只有在 CS 已释放，并且已确认（线上排空或 provider 已复位）后，轮询返回才结束同步借用；超时不能抢占正在传输的字。错误不会重放之前的命令阶段。异步分段接口有独立的准入、描述符和取消合同。

STM32F407/GD32F470 分段 DMA 机制是由 service 推进的有限链。硬件 DMA 搬运一段后，所有者先证明该段排空，再由 service 装入下一段。跨段保持 CS，但允许 SCK 间隙；这不是硬件链表 DMA，也不保证无间隙传输。请求、全部描述符、全部跨度及显式 fixed dummy/discard cell 持续借用，直到 acquire 观察到 SETTLED。中间段完成、取消和 timeout 都不释放这些存储。调用者仍须推动 service，不能从 base SPI port 推断附加唤醒或恢复能力。

可选的分段 SPI owner将该增强 face 接入既有有界 BusOwner 队列。调用方提供的 slot 和 epoch 仍是队列权威，不增加 worker、payload 复制或第二个控制器所有者。一个独立调度的唯一执行器推进内部请求。只有 acquire 观察内部 SETTLED 后，它才移除私有描述符引用并允许外部请求结束。排队时间计入外部 deadline。排空失败保留内外借用，晚到的取消不能替换更早的终态结果。

owner binding 必须证明端点实际 provider 控制器与所选增强控制器一致。仅匹配通用 sequence 方法表及逻辑父指针并不充分。Native 字模型提供独立 backend 并核对其实际模型控制器身份；它建模 8/16 位字、固定单元、所选 CS、故障和保留排空，而不是转发到字节 SPI 实现。模型控制器身份是软件身份，不是观测到的硅片。各系列 hook、生成的 owner binding、发布者交接和各目标执行证据仍需分别检查。回收存储前必须 join 发布者和观察者；队列为空或传输停止本身并不代表发布者已退出。

I2C 硬件 reload 推进同一长消息，不插入新的地址阶段。成功返回前必须完成 STOP 并观察总线空闲。失败时，返回的字节数记录 provider 进度，其中可能包含已交给 TXDR、但尚不知道线上 ACK 结果的写入。该计数不能授权重放。取消或失败不允许重放已确认前缀，也不允许静默执行总线恢复。增强 face 与 base I2C 接口共用一个执行者。时序输入必须给出已审时钟和电气边界；计算结果不是上升时间或 clock stretching 的实测值。 在证明物理 STOP 已完成且总线空闲后，如果 STOP 标志或 CR2 的清理被拒绝，则返回 IO，并保留实际进度计数。控制器继续承担故障处理责任，在显式恢复前拒绝新请求准入；已完成排空的调用者存储可以归还。

ADC 解码只读取消费者拥有或已经 acquire、且生产者已脱离的存储。它处理一至四字节整数采样，不分配、不保留指针，也不进行校准电压换算。消费者必须先 join 生产者/DMA 访问。声明的 regular/injected group 与 trigger 身份描述已受支持的模式，不会启动转换，也不会将软件观测变成采样孔径时间戳。

G474 的 shared-fixed-pwm 选择让两个普通 PWM factory 接口共用一个物理 TIM3 owner：CH1/PA6 和 CH2/PA7 AF2，使用共同的固定 170 MHz 内核时钟、tick 和周期。两个既有声明派生一个冷态构造、两个只读通道引用、兼容的基准资源声明，以及独占的通道／引脚声明。没有作者填写的共享标志、运行时注册表、定时器 IRQ 或 DMA。每次 set 只修改本通道的 CCR 预装载值。后启动的通道加入正在运行的另一通道时沿用当前相位，不发出 UG，也不重启计数器；独立调用不提供多通道同步启动或完整首脉冲。通道 stop 不改变另一通道，并建立自身声明的不活动 GPIO 电平；只有最后一个通道停止 CEN。生命周期调用方须在最终 Platform stop 前确保两个通道的使用者均已停止访问。物理 close 先于外层引脚／时钟释放；若复位、不活动电平或恢复状态无法得到证明，则保留清理责任。规范软件参考要求完整通道对，并排除其他整个 TIM3 或 PA6/PA7 owner。其 Board 选择不证明 PCB 布线、电气安全或 HIL。

PWM group commit 暂存一个一致的影子批次；SUCCESS 不证明定时器已经应用该批次。部分硬件写入失败必须撤离输出并保留故障责任。清除刹车不会启用输出。普通 G474 PWM-group 提供者不提供 PCB 引脚选择、模拟阈值测量或功率级，也不自行建立同步 ADC 会话。选定的软件参考现生成独占 TIM1/COMP1 构造，固定 PA8/PA9/PA10 PWM 引脚和 PA1/PA4 比较器引脚。其冷生命周期拥有选定时钟／复位、安全电平、比较器设置和稳定等待、共享刹车向量以及逆序清理。部分清理失败时保留责任。独立的有限 PWM/ADC 联合所有者现绑定一个固定 TIM1/ADC1/COMP1/DMA 窗口，不暴露可独立启动的 PWM-group 或 ADC 子接口。任一选择都不证明实际装配的 PCB 布线或模拟准确度。

独立的具体 G474 provider 实现 PA0 上的 TIM5 CH1 捕获，以及 PA6/PA7 上的 TIM3 双输入正交计数。捕获按照有界 ring 合同发布原始 32 位计数器事实，并明确报告 overcapture 和 loss。编码器报告原始 16 位计数，不扩展回绕、不提供 index 输入，也不估算速度。独立的捕获与编码器软件参考现在分别生成静态 face、typed getter 及冷引脚/时钟/向量生命周期，保持整定时器所有权与 source/vector 排空责任。平台启动既不启动捕获会话，也不启动编码器计数。应用提供捕获 ring，并显式启动和停止各会话。source/vector 或存储排空失败保留清理责任。这些精确选择不继承 PWM-group 能力，不同步 ADC 采样孔径，也不建立外部接线。产品控制与恢复策略保持外置。

保持 H743 Flash 时序的唯一所有者¶

所选固定 HSI32/64 Flash 路径在编程或擦除脉冲前检查实际时钟、请求和观测到的电压等级、Cache 状态以及 Flash 编程延迟字段。读取等待周期本身不满足编程合同。可选的冷时序所有者仅在两个 bank 都空闲时修改已审 Flash 字段，验证读回，并保留已保存状态，直到逆序清理安全恢复它。生成的 Flash 装配选择这一所有者；不含 Flash 的构建不会取得它。产品擦除区域与恢复策略仍不属于本仓库。

这是针对选定既有时钟配置的有界编程时序修正。该修正本身不会启用新的高速时钟、修改选项字节、认定全部硅片修订合格或建立物理 Flash 耐久性。独立选定的仅限 V 修订 HSI/PLL384 参考现已实现独立的 CPU／总线／内核时钟域和冷态时钟／电压／Flash 生命周期。该高速配置以联合所有者替代固定 HSI Flash 时序所有者；支持范围不扩展到未经审查的修订、启用 Cache 的执行或物理资格。

选定 V／Cache off 的 Flash 实现现在要求私有 RAM 维护边界：冷态复制／就绪、单个选定工作区、仅负责 CPU 的栈 bridge、RAM 拥有的 VTOR 和临时 MPU guard。触发后 deadline 到期只锁存结果；任何返回前都必须完成实际双 Bank 排空、LOCK 以及保护／向量恢复。生产 ELF 闭包和完整软件退出仍未完成，因此 IO-24 保持 in_progress。

观测时间，不虚构时序保证¶

时间戳事实区分硬件事件、IRQ 观测、service 观测与 acquire 观测。调用者提供扩展 ticks、domain、epoch、准确声明的 tick rate，以及显式的不确定度已知状态。Domain 所有者扩展计数器 wrap，并在不连续、复位或变频后改变 epoch。

时间差比较要求 domain、epoch 与 rate 一致，ticks 有序且不确定度边界可表示。它不做时钟同步、跨域换算或硬件时钟访问，也不证明两条事实具有因果配对关系。未知不确定度不同于已知为零的边界。

可选时间戳预算评估器以 O(1) 工作量处理同一组事实。只有完整误差区间落在包含边界的上限内，才报告 WITHIN；只有下界严格超过该上限，才报告 EXCEEDED；其他情况报告 UNKNOWN。比较成功本身不表示满足预算。精确单位和错误条件由公共时间戳合同规定。

Checked UART/SPI/I2C service 可以报告非法 face 或缺少 service 方法。SUCCESS 只说明完成一次派发，不证明有进展、健康、SETTLED、线上完成或可以回收存储。普通 service 的上下文、串行化和生命周期规则仍适用，没有隐藏 worker。

可选的原始周期探针使用真实 Arch 计数器快照，包围一个所选向量或一次显式 typed service 调用。首条生成路径只在已审 F407/F470 IRQ-word UART 选择的 [uart.NAME.irq] 中接受 probe = true。它为每个物理向量增加一个 sidecar，以及该 sidecar 的纯 typed getter。未选宏不求值任何参数、不创建 sidecar，也不增加 provider 状态或方法表字段。只有显式选择才链接可选库；链接 ELF 检查确定默认及选配的实际成本。

精确的 F407 启明 USART1 和 GD470 梁山派 USART0 word 参考现有 probe 关闭／开启的链接证据。OFF 不保留可选 observer 的 sidecar、probe／counter helpers、probe getter 或 observed-service 符号；ON 在恰好一次原 provider IRQ 分派前后采样。原 provider 状态大小保持不变。这些链接还保留显式 service wrapper，并不是运行时 I/O 采集。

一对可读计数器值给出原始模 2^32 差值，包含探针成本和抢占。多次回绕、复位以及时钟 epoch 连续性都未知；elapsed_known 始终为 false。探针既不使能也不复位 DWT。不可用样本和同一 sidecar 重入被计数，诊断总数饱和而不回绕。不同嵌套向量需要不同 sidecar。这既不是经过时间验证，也不是 IRQ 到达延迟、独占执行时间或预算通过结论。

特权 Task 快照保存并恢复进入时的本地中断屏蔽状态，仅在有界统计复制期间屏蔽中断。任务 producer 必须使用同一执行器，或在读取前退出并完成 join；屏蔽本地 IRQ 不会 join 另一个被抢占的 Task、其他核或安全状态。回收前需 join 所有 token、producer 和 reader。typed UART-word 和分段 SPI service 包装即使观测不可用，也只派发一次原 service。观测失败不会停止排空或释放 QUARANTINED 借用。consumer 必须证明私有状态及被借用存储与可选 observer 不重叠。缺少独立连续性证明时，不得将原始探针样本提升为已验证时序预算。

HIL 测量协议 的测量 run、context 和 trace 使用 schema 2。周期测量需要真实 DWT 端点、有效 owner／epoch、已准入的独立采集时钟事实，以及覆盖该计数器 epoch 和采集区间的 CPU 频率包络。包络必须包含实际振荡器公差、校准和漂移。名义频率或手写的回绕上限不能替代它。这不改变独立的 SoC、OS 或选定模式原始协议。IO-05 在该选定软件范围内已实现；物理执行仍为 not_executed。

仍需单独实现的工作¶

台账保留更广泛链表 DMA、H743 高吞吐配置、U575 通用外设 LPBAM、更广泛或连续的同步控制组、高级 Ethernet/USB、外部存储、TrustZone 服务、多核传输、音频与帧设备的退出条件。公共类型、已验证拓扑或模型不完成这些退出。每种模式都需要自己的 provider、已审路由、失败与所有权测试、ARM/SDK 检查、资源成本，以及适用的物理证据。有限 U575 UART GPDMA TX、其独立硬件链 TX 选择、PWM/ADC 联合窗口、选定 G474 CAN FD 模式，以及另行选入的有限 SRAM4/LPDMA1 通道 0 Stop2 复制现已有具体软件路径；这些选择不完成更广泛退出，也不建立外部接线、实测性能或 HIL。有限 GPDMA 链为一个连续 SRAM1 源实现真实硬件节点获取和描述符／payload 排空。该 GPDMA 选择不选入非连续 scatter/gather、循环链、RX DMA 或自主低功耗执行。独立 SRAM4 复制由同一具体 Stop2 owner 控制 AlarmA14、独立 WUT 逃逸和复合 RTC/DMA/IRQ/门控／clock 最终释放；通用外设 LPBAM 及完整 IO-32/SOC-35 退出仍开放。

专用的 LPTIM1 单组 LPBAM 参考 在同一 concrete Stop2 owner 下增加一次有限 SRAM4 CCR1/RCR=0/ARR 更新。首字使用硬件 request13、BREQ1 和保留位 DREQ0；两个固定 continuation LLI 依次写 RCR，最后写 ARR。显式 start/stop 保留部分准备和排空失败后的责任。成功必须取得 fresh write-OK 和全部最终访问证明；成功表示寄存器写入已同步，不代表完整波形播放。该参考没有 GPIO 路线或实板 HIL 结果，通用外设 LPBAM 和原 IO-32/SOC-35 退出仍开放。
