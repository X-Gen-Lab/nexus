当前设计与实施台账¶

当前代码采用统一物理目录、TOML 静态装配、typed factory 和共享多态方法表。 公共 C11 face 只保存 readonly ops 与私有 context；每个实例拥有独立状态，request 和 block storage 由调用者提供。SDK 和 provider storage 私有，应用产品工程独立。 这里的设计合同与 当前交付 一起使用，历史文档不建立当前资格。

五项有界软件增量的装配、借用与恢复责任见映射存储、AMP、镜像交接、RTC 与帧边界。完整原始退出条件与实板状态保持不变。

台账保留B0–B6和原始退出条件，新增implementation_paths/evidence_paths、software_status、 hardware_status。implemented表示机制已经存在，不表示所有退出条件已passed；开发验证 不能替代clean-source SDK、正式离线双构建和候选封存。NG028/030的正式执行以新生成 证据更新，硬件未接入，全部适用物理项not_executed。Glob表示同一机制的明确目录族， 不代表递归发现或缺省构建；X-Gen-Lab/nexus-examples路径是独立外部仓库。

CPU 软件层覆盖 M0/M0+/M3/M4/M7/M23/M33/M55/M85，通过显式 CPU/IRQ facts 选择原子后端、ABI、可选 FPU/MVE/cache/MPU/SAU 与裸机/FreeRTOS port。外部 CPU runtime 不生成 SoC/Board/factory；ThreadX 另有明确的 Native/M4 子集，不能继承 九核 FreeRTOS port 范围。配置示例与剩余条件见 九核支持说明。这不扩大完整平台的芯片/板卡范围。

首发为启明STM32F407ZGT6、天空星STM32F407VET6和梁山派GD32F470ZGT6，裸机/ FreeRTOS、显式 ThreadX 及 Native 模型。新增 F103RBT6／GD32F303RCT6 参考及 G474／H743／U575 增量按各文档的精确配置、完整镜像与 SDK 退出条件验收，不从公共 类型推断完整系列或全部外设。F103/GD303 增加有限 UART channel-DMA、I2C IRQ、 物理 Flash、单次 ADC 与固定 PWM；GD303 另维护 EXTI 和硬件级联 timebase。 G474 的既有 GPIO/UART/SPI/PWM/IWDG/EXTI 之外，选入 bulb ADC 单次／有限 TIM6 DMA、I2C1 和 ECC Flash。H743 的固定 HSI/cache 支持有限 TX DMA 或有 rearm 间隙的 RX block，可显式初始化 D2 SRAM1；独立 V／HSI64／裸机参考在 Cache off/on 下增加 SPI4 有限 DMA 和 USART3 连续双缓冲 RX。rx-dma-continuous 保留独立 IRQ TX；另选 dma-duplex-continuous 才增加有限 TX DMA。新双向模式只接入 AXI SRAM， RX 使用至少三个等长 block，不能推导为 FreeRTOS、PLL384 或 D2 SRAM 支持；另有 七类有限外设的软件夹具。U575 TZEN0 增加 SPI/I2C/ADC/PWM/EXTI/Flash，外部电源与安全状态准入仍适用。 独立无 OS 的 TZEN1 GPIO 参考可复制最多八条命令到 Secure slot，再由调用者逐步 推进；不保留 NS 指针，不代表通用双域 factory、NS RTOS 或异步借用。 ECC program_flags、fresh-erase 来源与逐脉冲完成责任见公共 Flash 合同；当前源 实现和最终集成资格分别记录，不继承历史执行计数。 SOC-33 的有限软件增量见上述边界页，完整退出仍开放；SOC-34 运行态变频仍未实现。 SOC-35 新增 U575 保留时间参考的有界软件子集：独立 RTC 时间域、显式 WUT/Stop2 owner 与失败保留排空；默认 Core TIM2 停止后旧 deadline 失效。另有同一 owner 的选定 SRAM4/LPDMA 有限复制；通用外设 LPBAM、物理复制/保留/精度/功耗/唤醒验收及完整退出仍开放； SOC-36 保留 partial，SOC-37–55 的物理验收仍为 not_executed。 三Board未审实物PCB事实仍标unknown；软件测试夹具不升格真实 Board路线。角色沿用十人配置：TL1、Core/I/O/OS2、BSP2、通用应用/通信2、QA/HIL2、 构建发布1；维护责任由Codex全部承担，无需实名人员。远程branch protection状态 须通过GitHub独立核实，不能从本地角色文件推断。

另有独立选定的 LPTIM1 单组 LPBAM：一组 SRAM4 CCR1/RCR=0/ARR 经 LPDMA1 channel0 更新专用 LPTIM1。它沿用同一 concrete Stop2 owner，公开 start/stop 保留部分启动失败的归还责任；通用 LPBAM、引脚路线与 实板验收不由该软件切片建立，原 IO-32/SOC-35 退出条件不变。

行为变更采用 RED → GREEN → REFACTOR；主机 GoogleTest/GoogleMock 测试真实生产 provider、factory 与 owner，配置工具用 Python unittest。commit hook 和 CI 执行同一 门禁，生产 MCU target 不链接测试框架。构建期资源验证、实际寄存器模型、ARM ELF 预算与物理 HIL 分别建立证据，方法表开销由实际 linked image 测量。
