Prepare unused metadata without retaining its payload.

Note
Serialized owner Thread. DISCOVER has no payload or target. PRIVATE permits 1..65535 bytes. CCC permits only ENEC/DISEC broadcast/direct writes and direct GETMWL/GETMRL/GETPID/ GETBCR/GETDCR/GETSTATUS reads, with exact defined lengths. GETMRL uses two bytes, or three when confirmed BCR bit2 advertises an IBI payload. Address-changing, HDR and controller-handoff CCCs reject. All APIs require one serialized executor. Port and clock callbacks must not reenter the core, invoke application code or mutate retained state. No ISR, allocation, OS lock or worker. Absolute deadlines use the injected clock.

◆ nx_i3c_reset()

nx_result_t nx_i3c_reset ( nx_i3c_controller_t * controller)

Prove a whole-bus reset before invalidating dynamic addresses.

Note
Requires closed admission. Hardware proof covers real wire, FIFO and IRQ quiescence AND every target's dynamic address invalidated. Peripheral reset or FIFO flush alone is never this proof. Failure preserves all loans and address records. Success settles outstanding work and invalidates endpoints; retained events preserve their old epochs for the caller.

◆ nx_i3c_service()

nx_result_t nx_i3c_service ( nx_i3c_controller_t * controller)

Perform one bounded FIFO/event phase or one drain proof.

Note
Partial DAA, malformed observations and errors fault admission while retaining every known/tentative assigned address. Cancel/timeout/failed drain never release a loan. Failed quiescence stays QUARANTINED; continued service may recover. An event overflow returns OVERFLOW and latches its counter, without discarding an already retained queued event.

◆ nx_i3c_stop()

nx_result_t nx_i3c_stop ( nx_i3c_controller_t * controller)

Close, withdraw and finally relinquish the unique controller.

Note
Active work or queued events return BUSY. Caller continues service, consumes events and retries. Assigned/tentative addresses or a fault return STATE until whole-bus reset proof invalidates them. Successful final wire/ FIFO/IRQ quiescence releases ownership, never reconstructing this object. Storage outlives copied endpoints and tickets.
