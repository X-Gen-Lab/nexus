Detailed Description

Immutable methods for a serialized nonblocking byte stream.

Note
Every call has a finite absolute monotonic deadline in the transport's explicit clock domain. Calls do not wait, create workers or retain input/output buffers after return. An accepted write copies bytes into the transport's own bounded storage; it does not promise peer delivery. SUCCESS writes 1..requested bytes for a nonempty write, or reads 1..requested bytes. SUCCESS with read count zero means orderly EOF. BUSY has count zero and means retry after explicit owner progress. Other results are errors, never alternate encodings of would-block. Zero-byte calls return SUCCESS/count zero without underlying I/O. Output count is disjoint from all buffers and live transport storage. Transport, table and context outlive every consumer and its shutdown.
