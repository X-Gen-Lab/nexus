nx_result_t nx_lwip_tcp_close ( nx_lwip_tcp_t * client,
nx_time_us_t deadline )

Close admission and detach after explicit local drain.

Parameters
[in,out]clientProducers joined; reads may drain retained RX.
[in]deadlineFirst finite close deadline; never implicitly extended.
Returns
SUCCESS detaches this context. BUSY retains held/refused RX, unacknowledged TX or a failed close. TIMEOUT retains all ownership.
Note
CONNECTING may close before establishment. Callbacks detach before successful tcp_close; its PCB must never be accessed afterwards. The pinned stack can defer FIN allocation while returning success. FIN/TIME_WAIT belong to the still-live stack/network. This operation does not prove global or PHY drain. Timeout requires explicit abort.

◆ nx_lwip_tcp_start()

nx_result_t nx_lwip_tcp_start ( nx_lwip_tcp_t * client,
const nx_lwip_tcp_config_t * config,
nx_time_us_t deadline )

Admit one asynchronous connect with a copied configuration.

Parameters
[in,out]clientZeroed exact storage with all former users joined.
[in]configLive adapter, copied IPv4 peer, nonzero port/budget.
[in]deadlineFirst finite absolute connect deadline.
Returns
SUCCESS admits CONNECTING. BUSY rejects an occupied domain. INVALID rejects configuration; EXHAUSTED/IO report stack admission.
Note
Initialize lwIP once. SUCCESS never proves ESTABLISHED. Rejection retains no new PCB/pbuf/config reference for this client. An admitted client requires explicit close or abort.
PCBs share the official stack pool and its reclamation policy. Allocation may progress pending closes and reclaim TIME_WAIT, LAST_ACK, CLOSING or lower-priority active PCBs. This can invoke other connections' error callbacks, even if this start later fails. Local rejection does not promise a globally unchanged stack.
