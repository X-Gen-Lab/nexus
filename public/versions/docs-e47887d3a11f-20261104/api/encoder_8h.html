nx_encoder_sample_t * sample )

Read one modulo position without inferring travel across wraps.

Parameters
[in]portSerialized privileged Thread-mode owner.
[out]sampleAligned separate output, unchanged on rejection.
Returns
SUCCESS or INVALID/STATE/CONTEXT/UNSUPPORTED.
Note
observed_at is software observation time, not a sensor edge aperture. Direction, speed, mechanical zero and unbounded signed position need external sampling bounds and product policy. A read cannot reconstruct missed full wraps. No separately read DIR bit is an atomic edge history.
