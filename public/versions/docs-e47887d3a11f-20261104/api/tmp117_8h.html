nx_tmp117_transport_port_t transport,

Validate ID 0117h, locked EEPROM, offset and shutdown.

Parameters
[in,out]deviceFresh zero/stopped or same-binding uncertain storage
[in]transportCopied on success or uncertain shutdown write
[in]configStable explicit facts, not overlapping device
[in]deadlineFinite absolute deadline, shared across accesses
Returns
SUCCESS, BUSY for power-up/EEPROM, or exact transport error; unsupported identity, offset mismatch and unlocked EEPROM reject without writes. Pre-write failure keeps no new binding. Once shutdown write is issued, failure retains the same port/config/clock as uncertain and uninitialized.
Note
No scan, reset, sleep, EEPROM write, worker or Board action. Use a separate cleanup deadline to cancel, or retry init on that same binding. A different binding requires joined software stop; external uncertain-state recovery remains the owner's duty. Failed write is not a device reset.

◆ nx_tmp117_poll()

nx_result_t nx_tmp117_poll ( nx_tmp117_t * device,
nx_tmp117_sample_t * sample )

Observe readiness and publish one complete fresh sample.

Parameters
[in,out]devicePreviously begun conversion, same task executor
[out]sampleAligned separate output, unchanged on every error
Returns
SUCCESS, INVALID, BUSY before ready, STATE or transport/IO
Note
Reads CONFIG clear readiness. A later temperature-read failure is terminal and requires resync, never cached zero or endless ready retry. Any transport error, including BUSY, closes sampling until resync; only a successful not-ready read retains the conversion. Repeated poll after success is STATE. Output is disjoint from device, opaque port/clock context storage and borrowed bus storage; only known spans can be checked. POR/saturation and values outside the reviewed range return IO.
