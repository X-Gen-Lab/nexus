Detailed Description

One serialized crypto owner, caller arena and finite entropy source.

Note
Arena is max_align_t-aligned and exactly NX_TLS_ARENA_BYTES. All faces and opaque contexts outlive every session. FULL_SOURCE explicitly declares 8 bits/byte to the selected PSA entropy-driver API; software health checks and this enum do not establish physical qualification. The profile disables operating-system entropy and seed fallbacks. Clock advances in one unchanged monotonic domain throughout callbacks.
