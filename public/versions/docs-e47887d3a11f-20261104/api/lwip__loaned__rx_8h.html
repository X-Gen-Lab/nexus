nx_result_t nx_lwip_loaned_adapter_start ( nx_lwip_adapter_t * adapter,
const nx_lwip_loaned_config_t * config )

Attach the explicitly selected payload-zero-copy RX profile.

Parameters
[in,out]adapterZero-initialized selected backend storage.
[in]configDisjoint stable storage description; copied on success.
Returns
Success, invalid configuration, or an already attached owner.
Note
Task-only, same serialized nonreentrant NO_SYS owner as all raw calls. Select only the loaned profile and its storage target in this image. Ethernet/ARP/max IPv4/max TCP headers are copied; immutable payload tails are loaned. This is not whole-frame or TX zero-copy. No VLAN, IPv6, DHCP, DNS, reassembly, worker, heap or physical link is added. MAC payload spans must be disjoint from the adapter, TX/view storage and all selected slot/piece metadata; admission releases invalid loans. Final custom-pbuf frees only mark a slot ready. Subsequent service or stop performs exact provider release. Failed release preserves the token and closes admission. Stop returns BUSY while references remain. Products close PCBs and all raw observers before adapter withdrawal.
