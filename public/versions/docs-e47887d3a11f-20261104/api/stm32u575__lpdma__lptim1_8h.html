Bind one pure owner; no MMIO writes, allocation or worker.

Note
Exact STM32U575ZIT6Q TZEN0, MSIS4/MSIK4/equal buses/Range4, caches off. Selected SRAM4/LPDMA1 startup and retained LSE RTC access remain live. LPDMA0 and the entire LPTIM1 controller are exclusive; no other channel, timer writer, IRQ user or external reset exists. Config/face/control storage must be separate. Rejection retains no new reference.

Bounded producer/master isolation, never independent settlement.

Note
Producer UEDE withdrawal precedes DMA suspend/reset/idle. All final peripheral/IRQ references and Stop2 restoration precede final release. Unknown clock/access profile permits no peripheral MMIO; external DMA or LPTIM reset during a loan permanently quarantines that loan.

◆ nx_stm32u575_lpdma_lptim1_start()

nx_result_t nx_stm32u575_lpdma_lptim1_start ( const nx_stm32u575_lpdma_lptim1_t * receiver,
uint32_t poll_limit )

Explicitly prepare cold LPTIM1 access gates and LSE kernel.

Note
Unmasked privileged Thread, positive per-phase poll budget. Owns only LPTIM1EN, LPTIM1SEL and added LSESYSEN, preserving RTC/LSE provenance. LPTIM1 must be reset/cold and initially unclocked with reset mux. A failed preparation can retain effects; keep owner live and call stop until it succeeds. It never starts the timer or borrows a request.

Note
