◆ nx_rtc_port_submit()

nx_result_t nx_rtc_port_submit ( const nx_rtc_port_t * port,
nx_rtc_request_t * request )

Borrow and arm one future alarm; no queue, allocation or worker.

Parameters
[in]portInitialized serialized owner with a valid copied Core clock.
[in,out]requestExact READY request for the current setting domain.
Returns
SUCCESS means ACCEPTED; INVALID/STATE/BUSY/TIMEOUT/UNSUPPORTED rejects without retained references or effects.
Note
Closed/stale/already-matching pattern returns STATE; active is BUSY. An observed expired finite deadline returns TIMEOUT before admission. Calendar, counter and Core deadline are separate domains. Assembly keeps the copied clock face's borrowed context live, disjoint and non-reentrant for the entire owner lifetime and all external joins.
