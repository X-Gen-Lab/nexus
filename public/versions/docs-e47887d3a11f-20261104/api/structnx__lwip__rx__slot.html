Detailed Description

One exact RX token shared by all retained pieces of that frame.

Note
The union provides eight-byte alignment in the maintained profile. A free callback only decrements references; it never touches hardware. A slot cannot be reused until the provider accepts the exact release. Raw users cannot access a pbuf after returning its final reference.
