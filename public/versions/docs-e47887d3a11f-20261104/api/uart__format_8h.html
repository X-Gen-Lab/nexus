nx_result_t nx_uart_format_validate ( nx_uart_format_t format)

Validate the common USART-v1 subset without hardware access.

Parameters
[in]formatExplicit payload width, parity, stop and flow selection.
Returns
Success for 7E/O, 8N/E/O or 9N with one/two stop bits; INVALID for unknown values, UNSUPPORTED for a known incompatible combination.
Note
Pure, bounded, task/IRQ safe; Board admission remains separate.
