Detailed Description

Cold selected rank order, actual integer layout and scheduling facts.

Note
Arrays belong to immutable selected facts and outlive this port. A physical rank can be discarded padding required by silicon errata; format describes only valid logical results. No implicit data packing, engineering units, aperture timestamp or trigger counter is promised.
