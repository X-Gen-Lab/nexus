◆ nx_io_diagnose()

nx_result_t nx_io_diagnose ( const nx_io_diagnostic_facts_t * facts,
nx_io_diagnostic_t * out )

Classify supplied observations without touching live I/O.

Parameters
[in]factsStable aligned copies; no pointer is retained.
[out]outAligned output distinct from every input span.
Returns
SUCCESS, INVALID for malformed facts/alias, STATE for reversed service time. Rejection leaves output unchanged.
Note
Task/IRQ bounded fixed work, no MMIO, locks, allocation, service or recovery. Deadline and quarantine never revoke an accepted borrow. Callers must still drain controls and join observers before storage reuse.
