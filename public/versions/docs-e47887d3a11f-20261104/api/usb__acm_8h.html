◆ nx_usb_acm_approve()

nx_result_t nx_usb_acm_approve ( nx_usb_acm_t * acm,
uint64_t epoch,
bool accepted )

Authorize staged intent before STATUS, or reject this epoch.

Parameters
[in,out]acmSame active adapter and serialized task executor.
[in]epochExact operation identity.
[in]acceptedTrue authorizes only; false requests guarded STALL.
Returns
SUCCESS changes authorization; other results retain live loans and do not authorize a change. Malformed line coding cannot be approved; false is still allowed at DATA_READY.
Note
Approval must not apply UART/physical lines. After a newer committed_epoch appears, the external owner applies the copied intent and owns application failures/recovery. No callback runs here. SEND_BREAK records 0 (stop), 0xffff (indefinite), or a finite millisecond intent, without timer, automatic expiry or assertion that physical break occurred.

◆ nx_usb_acm_begin()

nx_result_t nx_usb_acm_begin ( nx_usb_acm_t * acm,
uint64_t epoch,
nx_time_us_t deadline )

Dispatch the current software-published SETUP to the subset.

Parameters
[in,out]acmBound inactive adapter; no other EP0 packet user.
[in]epochExact nonzero published SETUP identity.
[in]deadlineOne independent absolute deadline for all stages and external approval; NEVER permits an indefinite wait.
Returns
SUCCESS accepts the operation; BUSY/STATE/TIMEOUT reject without a new loan. Unknown requests return UNSUPPORTED and malformed fields INVALID after guarded STALL succeeds; otherwise the guarded rejection error is returned.
Note
Exact class/interface direction, wIndex, wValue and wLength are checked. GET_LINE_CODING returns seven committed bytes. SET_LINE_CODING receives exactly seven bytes but waits for explicit approval. Control-line/break requests wait before starting STATUS. Invalid/unknown dispatch deliberately has the documented STALL effect, but retains no new loan. Route standard/other-class requests externally before calling.

Cancel one active identity, preserving all admitted storage.

Parameters
[in,out]acmSame executor, retained through actual drain.
[in]epochExact active identity.
Returns
SUCCESS requests drain or discards unadmitted zero-data intent; STATE for stale identity. Cancellation only requests drain. A matching STATUS ACK acquired before or during cancellation still wins at the packetizer; step commits the approved original epoch on acquire outer SUCCESS without later epoch revocation.

Returns

Copy staged intent for external validation/authorization.

Parameters
[in]acmSame task; SET_LINE_CODING must be DATA_READY.
[out]pendingDisjoint naturally aligned value output; unchanged on rejection. No pointer into the borrowed payload escapes.
Returns
SUCCESS, STATE, INVALID or CONTEXT. INVALID on a malformed or short line-coding DATA stage; owner can reject explicitly.
Note
Wire format allows nonzero rate, stop bits 0..2, parity 0..4 and data bits 5/6/7/8/16. External hardware/policy may support fewer values. This value may become stale; approve rechecks the software epoch. Inspecting is not approval.

◆ nx_usb_acm_step()

nx_result_t nx_usb_acm_step ( nx_usb_acm_t * acm)

Advance USBControl once and fold only acquired completion.

Parameters
[in,out]acmSame executor; keep all storage while active.
Returns
Progress/provider result; an error never revokes a loan.
Note
At most one underlying USBControl step, with its one service, one state read and one packet action bounds. No loop drains a transaction. Continue after cancel/supersession/timeouts. OUT0 quarantine still needs explicit external device-owner stop, then further steps. Never auto-stop the controller. Only approved outer acquire SUCCESS commits intent: it proves the matching STATUS packet's real ACK. A later SETUP/reset, closing or failed state read cannot revoke an ACK already acquired by the packetizer. Supersession before ACK aborts and drains without commit. Resetting class state after a completed command is separate external owner policy. Software epoch checks do not promise atomicity with uncollected physical SETUP packets.
