◆ nx_lwip_adapter_service()

nx_result_t nx_lwip_adapter_service ( nx_lwip_adapter_t * adapter,
size_t receive_budget )

Progress MAC, bounded complete RX frames and stack timer callbacks.

Parameters
[in,out]adapterLive storage, including any unfinished loans.
[in]receive_budgetNonzero maximum acquired frames this invocation.
Returns
Success, one pending settled TX failure, or provider/release/state error. A settled TX failure is consumed once before further progress.
Note
Same task owner as every lwIP raw API/callback. Timer callback cost is governed by the fixed stack profile and application callbacks; this is not a hard bound on the entire invocation. The copying profile copies RX bytes before exact release. The explicit loaned-RX profile retains immutable payload tails until its custom-pbuf references end. A failed release retains its token and closes progress; stop retries release without feeding duplicate bytes into the stack. Inline and deferred TX failure remain observable before request reuse; while pending, new link output returns ERR_IF without admitting bytes. Success inline completion remains immediately reusable. Consuming an already-settled failure makes the TX request READY, without automatic reset, replay, adapter close or forced restart. The product chooses provider recovery; an actual unfinished borrow is never revoked.

nx_result_t nx_lwip_adapter_start ( nx_lwip_adapter_t * adapter,
const nx_lwip_config_t * config )

Attach one caller-owned netif without initializing MAC or PHY.

Parameters
[in,out]adapterZero-initialized backend storage, not already live.
[in]configExplicit configuration; copied without retaining it.
Returns
Success, invalid inputs, or BUSY for an already attached netif.
Note
Task-only, one serialized stack execution owner. Address configuration is static IPv4; the underlying stack is the pinned NO_SYS profile. Storage must be disjoint from configuration, TX bytes and RX views. Failure retains no new hardware borrow. Link starts down; only an explicit external PHY observation may bring it up.

◆ nx_lwip_adapter_stop()

nx_result_t nx_lwip_adapter_stop ( nx_lwip_adapter_t * adapter)

Close adapter admission and detach only after actual MAC drain.

Parameters
[in,out]adapterLive storage retained on any unfinished withdrawal.
Returns
Success after detachment; otherwise the actual withdrawal error.
Note
The product first closes its PCBs, raw callbacks, queues and observers. This stops only the netif/MAC adapter, not the global lwIP stack or all application connections. A timeout or failed drain never revokes TX or RX loans; retry after explicit provider recovery. No automatic reset or replay occurs. Stop is idempotent after successful detachment.
