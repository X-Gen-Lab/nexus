Detailed Description

One whole L2 frame, excluding preamble, hardware pad and hardware FCS.

Note
The fragment array and every fragment remain borrowed after ACCEPTED. Requested TX capture is optional: wire success may have an unavailable or corrupt stamp. Read stamp only after acquire-observed SETTLED.
