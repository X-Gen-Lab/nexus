Detailed Description

Value frame with an exact byte length, never raw or shifted DLC.

Note
FD admits0..8/12/16/20/24/32/48/64 bytes; no rounding or padding on wire. FD remote frames and classic BRS are invalid. A provider may reject a valid value when its selected hardware mode lacks that form.
