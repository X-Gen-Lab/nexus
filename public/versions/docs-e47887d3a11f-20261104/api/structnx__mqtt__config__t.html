Detailed Description

Caller-owned ports retained until deinit.

Note
All calls/callbacks use one serialized task context. Event and optional idle callbacks must be bounded and may not reenter this client. Idle may service/wait on lower layers; no worker, lock, scheduler or implicit reconnect is created. Idle SUCCESS/BUSY permit retry; other results fail the session. Event views are not NUL-terminated strings.
