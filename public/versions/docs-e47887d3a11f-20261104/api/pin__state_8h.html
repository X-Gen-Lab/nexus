nx_result_t nx_pin_state_select ( const nx_pin_state_port_t * port,
nx_pin_state_selection_t state )

Select one explicitly supported GPIO state without waiting.

Parameters
[in]portExclusive static pad/gate lease, with all writers quiescent.
[in]stateDefault or sleep; neither name implies electrical safety.
Returns
SUCCESS after actual target readback, or INVALID/UNSUPPORTED/ CONTEXT/STATE/BUSY/IO while preserving provider ownership.
Note
Serialized same-CPU privileged Thread with incoming masks clear. No ISR/NMI, competing pad/RCC owner, AF switching, clock transition, wake or retention policy. Partial failure retains the lease; retry an explicit supported target or let the owner perform checked cleanup. This does not prove physical transients, external bias or PCB safety.
