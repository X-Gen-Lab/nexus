nx_result_t nx_usb_control_approve ( nx_usb_control_t * control,
uint64_t epoch,
bool accepted )

Approve OUT policy before STATUS IN, or reject with a bounded STALL.

Parameters
[in,out]controlDATA_READY same-owner adapter.
[in]epochExact active SETUP epoch, checked against fresh state.
[in]acceptedTrue permits status; false stalls the old transaction.
Returns
Success changes policy only; the next step performs packet/STALL.
Note
Bytes, class dispatch, configuration readiness and recovery policy are external. No CDC/HID stack is supplied. A guarded decision excludes an already software-published replacement SETUP. Physical bus packets not yet collected by IRQ are outside that software epoch boundary. Cancellation drains before the outer loan ends.

nx_result_t nx_usb_control_begin ( nx_usb_control_t * control,
nx_usb_control_request_t * request )

Admit one explicit reply to the current authoritative SETUP epoch.

Parameters
[in,out]controlBound single-executor adapter; no other live reply.
[in,out]requestREADY metadata and disjoint payload. OUT capacity must cover wLength; IN sends min(length,wLength), including required ZLP.
Returns
Success means ACCEPTED; every failure retains no request or payload.
Note
No packet is submitted by admission. Payload, request, profile and adapter remain alive until acquire-observed outer SETTLED. Never call prepare/reinitialize to revoke a loan. Epochs do not repeat. Products stage SET_ADDRESS explicitly; transport success means wire ACK only.

◆ nx_usb_control_initialize()

nx_result_t nx_usb_control_initialize ( nx_usb_control_t * control,
const nx_usb_device_profile_t * profile )

Bind zero-initialized caller storage to a stable validated ROM profile.

Parameters
[in,out]controlZero-initialized storage, disjoint from the profile.
[in]profileImmutable facts and faces outliving every adapter loan.
Returns
Success or rejection; no hardware, task or allocation is created.
Note
Every function except preparation uses one serialized privileged task executor with IRQ masks clear. No callback, second task or ISR may reenter. The owner gives this adapter exclusive EP0 packet use; it retains external event-ring and explicit device recovery policy. No controller/endpoint reset invalidates a loan. A successful bind owns no provider references until begin.

◆ nx_usb_control_step()

nx_result_t nx_usb_control_step ( nx_usb_control_t * control)

Make one bounded progress step, at most one poll and one packet action.

Parameters
[in,out]controlSame serialized executor and lifetime as begin.
Returns
Success or provider error; an error never revokes accepted storage.
Note
No queue or worker. All packet deadlines use the outer independent absolute monotonic deadline. Poll while borrowed, even after cancel, reset, SETUP supersession or device stop. Cancel/drain/quarantine retain descriptor bytes and outer context. OUT0 quarantine exposes NEEDS_DEVICE_STOP; only the external controller owner may authorize stop. This adapter never stops the shared controller automatically. One SETTLED packet is folded before observing newer controller epochs.
