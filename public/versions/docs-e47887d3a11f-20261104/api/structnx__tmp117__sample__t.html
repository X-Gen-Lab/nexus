Detailed Description

Independent copied sample, published only on SUCCESS.

Note
micro_celsius rounds raw/128 Celsius to nearest microdegree, ties away from zero. raw/offset use 1/128 Celsius per LSB; offset is not added again. Reviewed output is -55..150C. observed is software register-read completion with unknown physical uncertainty, never hardware conversion time. Conversion occurred within [conversion_started_at, observed.ticks] in that same domain/epoch. A consumer can use the lower bound for conservative logical-age checks; recent read completion alone does not establish freshness. All fields are values, with no retained device/payload references. Copies survive stop; clock-domain assumptions still require the caller's continuity/lifetime contract.
