Parameters
[in]portStarted serialized privileged Task owner, IRQ masks clear.

[in]endpoint_addressUSB address byte; EP0 is not admitted.
[in]activeRequested active state, never packet submission.
Returns
Success after proof; UNSUPPORTED when the operation is absent. INVALID/CONTEXT/STATE/BUSY reject before writes. IO may have partial effects and closes controller admission until explicit recovery.
Note
No request or buffer is borrowed. Existing loans must be explicitly cancelled and drained before target changes; failure never revokes other loans. Configuration/class policy remains external.
