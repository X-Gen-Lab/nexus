◆ nx_freertos_mpu_gpio_close()

nx_result_t nx_freertos_mpu_gpio_close ( void )

Revoke further calls without deleting or stopping the GPIO.

Returns
SUCCESS, INVALID, CONTEXT or STATE; preserves all pins.
Note
The same privileged lifecycle owner serializes open/close/ join and task start/delete. NMI/HardFault never access this authority. Incoming interrupt masks are preserved.

◆ nx_freertos_mpu_gpio_join()

nx_result_t nx_freertos_mpu_gpio_join ( void )

Join a closed authority before task deletion or GPIO stop.

Returns
SUCCESS detaches the pin; INVALID/CONTEXT/STATE retain it.
Note
The single-core saved-mask boundary excludes every active scalar effect. Join detaches its task pin before returning; it does not delete the task or reset its lifetime epoch.

◆ nx_freertos_mpu_gpio_open()

nx_result_t nx_freertos_mpu_gpio_open ( void )

Open the fixed grant for its exact live protected task.

Returns
SUCCESS or INVALID/CONTEXT/STATE/BUSY. Rejection leaves no partial pin.
Note
Privileged Thread; scheduler running or not yet started. BASEPRI/FAULTMASK must be zero, except the selected port's bootstrap BASEPRI before scheduler start. PRIMASK is saved and restored. This operation pins task deletion until join.
