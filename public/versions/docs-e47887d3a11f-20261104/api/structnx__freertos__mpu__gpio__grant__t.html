Detailed Description

Immutable WRITE grant in privileged Flash.

Note
port_slot addresses the readonly generated nx_binding_led pointer. The initialized exact GPIOC PC7 face, operations and provider state outlive an open authority through successful join. The sole lifecycle owner does not stop or reconfigure that GPIO. No READ, toggle, pointer-copy or MMIO mapping is granted.
