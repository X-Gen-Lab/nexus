nx_result_t nx_adc_format_decode ( const nx_adc_format_t * format,
const void * samples,
size_t bytes,

Decode one integer from a caller-owned or consumer-acquired scan.

Parameters
[in]formatValid immutable uniform-channel scan description.
[in]samplesReadable storage; any producer/DMA access must be joined.
[in]bytesPositive exact multiple of scan_stride, including padding.
[in]scanZero-based complete scan index.
[in]channelZero-based channel position in provider order.
[out]valueSeparate aligned output, unchanged on rejection.
Returns
SUCCESS or INVALID; all32-bit unsigned/signed raw values fit int64_t.
Note
No pointer is retained. Input/output/format overlap and wrapping spans reject before access. Sample loads have bounded1..4 byte work. This operation performs neither calibrated engineering-unit conversion nor synchronization with an active producer. The consumer owns that join.
