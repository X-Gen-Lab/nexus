Detailed Description

Bounded trusted kernel identity and fault-contained copies.

Note
identity authenticates the current entry, never user input. Copy operations guarantee complete checked CPU access and mapping/process lifetime for the callback duration. Neither success nor error retains a user address, kernel scratch pointer, mapping or observer after return. Errors may have partially copied bytes; the copied payload cell is wiped on rejection, and reply failure is recoverable through exact slot/epoch. No callback blocks, dispatches recursively, or substitutes a permission observation for fault-safe copying. Identity/copy callbacks may close this mediation. A new kernel/CMSE wrapper must actually establish these preconditions; this component does not. 
             claim is a trusted exclusive role authority for the actual
             owner/controller binding. It rejects a second live role even
             with a larger session, and rejects reused/non-increasing
             nonzero sessions from persistent, nonwrapping history across
             fresh storage, process/device reset and reconstruction.
             Failed claim retains no reference/effect. Successful claim
             permanently consumes that session and retains the exact role
             until release. release SUCCESS proves outer
gateway/transport observers joined and detaches all authority references; failure retains the original role unchanged. drained SUCCESS permanently fences future outer gateway entry and joins all gateway/transport observers, while the exact role remains claimed. Failed drained preserves the role and every cell unchanged. It must not modify bound configuration, cell identities or requests. Claim, release and drained are bounded and cannot recursively construct, dispatch, close, reap or join. Context/history must remain live; no source code implements this kernel authority, physical isolation, storage partition or recovery policy. Alternate wrappers of one controller are not distinct roles.
