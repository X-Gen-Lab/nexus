Prepare distinct unborrowed request, frame and sample storage.

Parameters
[in,out]requestInitialized READY or fully consumed SETTLED storage.
[out]samplesNaturally aligned writable caller sample array.
[in]sample_countPositive exact sample count; provider checks DMA.
[in]frameReadable descriptor copied by value during this call only; its complete duty array remains live through SETTLED.
[in]deadlineFinite absolute monotonic deadline for the whole window.
Returns
SUCCESS or INVALID/STATE; no hardware access or provider borrow.
Note
Request, sample span, source frame descriptor and duty span must be naturally aligned, nonwrapping and disjoint. The caller has consumed prior results and joined every adapter observer before preparing again. NX_DEADLINE_NEVER is rejected; an expired finite deadline can be prepared but cannot admit new physical effects. Preparation does not access sample contents, borrow hardware or establish rate/region support. Failure leaves the initialized request unchanged.

nx_result_t nx_pwm_adc_stop ( const nx_pwm_adc_t * port)

Close admission and attempt final drain without revoking a loan.

Parameters
[in]portSame live coupled face and serialized privileged task.
Returns
SUCCESS proves stopped sources; BUSY/IO retains recovery storage.
Note
Continue the unique service/stop until quiet. Cold close additionally joins vectors and restores saved leases. Fault recovery does not automatically restart PWM or resume acquisition. SUCCESS does not release pads, clocks or private storage. Those cold leases remain held until the platform's final joined close succeeds.

◆ nx_pwm_adc_submit()

nx_result_t nx_pwm_adc_submit ( const nx_pwm_adc_t * port,
nx_pwm_adc_request_t * request )

Admit and arm one complete finite window on the unique task owner.

Parameters
[in]portInitialized stable selected coupled face and cold leases.
[in,out]requestExact READY window prepared by the caller.
Returns
SUCCESS means ACCEPTED, including a possibly already SETTLED error. Rejection means no retained pointer, payload access or new effect.
Note
Post-admission arm/prime failures drain under the accepted request. Normal completion stops the PWM sources before SETTLED and never rearms. DMA TC alone is insufficient for completion or safe output. An error/cancellation reports zero guaranteed valid samples; an aborted DMA remaining count cannot establish a valid prefix. A successful window reports exactly sample_count. After successful ordinary completion, another explicitly prepared submission may begin; an explicit stop or latched fault requires cold close/reinitialization. Provider checks context, fixed frame, region and overlap with all cold descriptors/MMIO before admission. The complete duty frame is constant for the window; sample count does not promise an exact PWM pulse count. Without a trusted completion timestamp, completion first observed at or after the request deadline reports TIMEOUT, even if DMA is already complete. This conservative observation rule promises no physical execution-time bound and never relaxes the required source drain.
