nx_frame_dma_loan_t * loan,
const nx_dma_drain_facts_t * drain )

Release only after the adapter proves final DMA access.

Parameters
[in,out]framedOriginal owner; another instance cannot release.
[in,out]loanExact acquired control, cleared only on success.
[in]drainActual provider observations of engine, IRQ and peripheral quiescence; counter completion alone is not proof.
Returns
SUCCESS, BUSY while any source remains, STATE for stale or foreign tokens, or INVALID for impossible drain counters.
Note
Bounded task/IRQ metadata. Timeout/cancel is not quiescence; failed drain retains the queue borrow, including during stop. This helper checks proof facts and does not stop hardware.

Derive a strided byte rectangle from a live frame loan.

Parameters
[in]loanExact live immutable DMA consumer loan.
[in]planePlane index in the bound layout.
[in]xByte column within a row, not a pixel count.
[in]yFirst complete row.
[in]widthPositive bytes per selected row.
[in]heightPositive selected row count.
[out]viewFresh output unchanged on failure.
Returns
SUCCESS, INVALID for out-of-plane rectangles or STATE for stale/foreign loans; no DMA access begins here.
Note
Task/IRQ; an O(n) immutable-pool output check precedes the O(1) guarded view calculation. Output cannot alias the loan, queue controls or any full-capacity pool payload. The adapter checks pixel alignment, resource and DMA domain.

◆ nx_frame_stream_acquire()

nx_result_t nx_frame_stream_acquire ( nx_frame_stream_t * framed,
nx_frame_dma_loan_t * loan )

Acquire the next complete immutable DMA consumer loan.

Parameters
[in,out]framedSame serialized consumer, one call per observed output boundary when using underrun accounting.
[in,out]loanZero or previously released control, unchanged on error.
Returns
SUCCESS, EMPTY with saturating underrun count, BUSY for a live loan, INVALID for output alias or STATE for an incomplete queued block.
Note
Task/IRQ; output disjointness scans the fixed pool in O(n) before the O(1) guarded queue operation. Output cannot alias queue controls or any full-capacity pool payload. EMPTY creates no loan and never repeats a previous frame. Caller owns silence/blanking/stop policy. Do not use retries as additional observed boundaries.
