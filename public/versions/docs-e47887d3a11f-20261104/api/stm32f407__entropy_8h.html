◆ nx_stm32f407_entropy_instance()

const nx_entropy_port_t * nx_stm32f407_entropy_instance ( void )

Return the existing static source face without starting it.

Returns
Stable readonly face, including while the source is stopped
Note
No allocation, register access, clock acquisition, locking or registration. The face's private state belongs to the unique explicit constructor target. Data calls use its shared provider table directly; a cold face reports STATE.

◆ nx_stm32f407_entropy_instance_start()

nx_result_t nx_stm32f407_entropy_instance_start ( const nx_stm32f407_entropy_config_t * config)

Start the explicit source after successful Platform startup.

Parameters
[in]configExact validated Board/profile facts, copied during this call; source/PLL48 dependency stays live until stop
Returns
SUCCESS, CONTEXT, INVALID, BUSY, STATE, UNSUPPORTED or IO
Note
Privileged unmasked serialized task. One unique hardware RNG owner; a repeated live start returns BUSY. No scheduler, Platform startup or clock-profile change is implicit. A post-write IO may retain owned effects; stop must succeed before releasing Platform clock resources or recovery state.

◆ nx_stm32f407_entropy_instance_stop()

nx_result_t nx_stm32f407_entropy_instance_stop ( void )

Stop the source before withdrawing Platform clock resources.

Returns
SUCCESS when stopped; IO retains failed cleanup ownership
Note
Privileged unmasked serialized task after source consumers have joined. Retry the same stop on failed withdrawal; do not reset or rebind private state. The existing static face remains valid and reports STATE while admission is closed.
