◆ nx_silicon_preflight()

nx_result_t nx_silicon_preflight ( const nx_silicon_source_t * source,
const nx_silicon_admission_policy_t * policy,
nx_silicon_admission_t * out )

Read one explicit source before acquiring I/O resources.

Parameters
[in]sourceStable source and context, no concurrent teardown.
[in]policyReadonly policy/rules, stable during this call.
[out]outDistinct aligned output; never aliases source context, complete policy/rules or MMIO. No reference is retained.
Returns
SUCCESS for admitted software policy, UNSUPPORTED for unknown/missing revision, PERMISSION for blocked/missing workarounds, IO for group/density mismatch, INVALID for malformed inputs; source errors propagate unchanged.
Note
Cold caller-serialized Thread context, O(rule_count) policy validation. Malformed inputs reject before read. Source failure leaves output untouched. A completed comparison copies its rejection reason too; that never authorizes startup. No reset, scheduling, clocks, IRQs or factory operations are performed. Default platform behavior does not invoke this optional explicit preflight.
