◆ nx_tls_abort()

nx_result_t nx_tls_abort ( nx_tls_session_t * session)

Free synchronous session state and wipe its stage after final access.

Parameters
[in,out]sessionExclusive owner, all external facade users joined.
Returns
Success after cleanup (also cold), BUSY if crypto/BIO is executing.
Note
BUSY retains all storage; the outer owner retries after callback join. No network I/O or replay. Underlying transport closure remains external. The pinned builtin synchronous crypto profile retains no callback after return. PSA domain/arena stays live for the next explicit session.

nx_result_t nx_tls_handshake_step ( nx_tls_session_t * session,
nx_time_us_t deadline )

Perform one public handshake step under the first locked deadline.

Parameters
[in,out]sessionInitialized exclusive client.
[in]deadlineFinite deadline; later calls cannot extend the first.
Returns
Success only after verified auth; BUSY for progress/WANT; fatal error.
Note
First step publicly reseeds PSA with a finite guard. Trusted UTC is sampled coherently; loss during a library date check is latched and overrides a successful library result. Renegotiation is disabled.

nx_result_t nx_tls_try_read ( nx_tls_session_t * session,
uint8_t * data,
size_t bytes,
size_t * received,
nx_time_us_t deadline )

Try to copy authenticated plaintext without retaining caller output.

Parameters
[in,out]sessionEstablished serialized client.
[out]dataUnretained output disjoint from all live session storage.
[in]bytesWritable capacity; zero performs no I/O.
[out]receivedDisjoint count; zero on BUSY/error or auth EOF.
[in]deadlineFinite absolute deadline for this nonblocking attempt.
Returns
Success/bytes, BUSY, authenticated close-notify EOF, or error.
Note
Raw transport EOF without close-notify is a sticky truncation error. An expired preflight retains session state and creates no new borrow. An invalid aliased count is rejected before writing that count. A pending stage with a later effective deadline returns BUSY without automatic I/O; the owner explicitly services that earlier acceptance.
