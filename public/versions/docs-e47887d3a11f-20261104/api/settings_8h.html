◆ nx_settings_commit()

nx_storage_status_t nx_settings_commit ( nx_settings_t * settings)

Commit the complete staged snapshot through durable Storage.

Parameters
[in,out]settingsOpen exclusively owned instance
Returns
OK or underlying storage error
Note
Task-only settled call; underlying Flash may stall execution. Clean staging does not write. Successful save clears dirty. A mutating I/O failure closes the instance and preserves the dirty flag for diagnosis, but retains no staging borrow. Reopen Storage, then Settings to determine the surviving commit; failure may occur after a new marker became durable. Retrying a failed commit without recovery is rejected.

Load one exact schema or stage an empty, uncommitted image.

Parameters
[out]settingsUnused or closed instance, exclusively owned
[in,out]storageOpen durable store; no other mutating client while this settings instance is open
[in]schemaProduct-defined schema identity, including zero
[in,out]imageCaller buffer, disjoint from both instances and the storage workspace; borrowed until close or a failed commit
[in]image_bytesAt least HEADER_SIZE and at most UINT32_MAX
[in]max_entriesNonzero upper bound on staged entries
Returns
OK, INVALID, NO_SPACE, CORRUPT, UNSUPPORTED or port error
Note
Synchronous task-only scan. Missing blob stages an empty image, without reading defaults or writing Flash. Different schema/format is UNSUPPORTED and never rewritten. Truncated, duplicate or unordered keys are CORRUPT. A failed load never becomes an empty writable store; the instance stays closed.

[in]keyExact product-assigned identifier
