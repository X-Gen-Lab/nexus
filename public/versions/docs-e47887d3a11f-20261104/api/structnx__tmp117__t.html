Detailed Description

Exact caller-owned instance, fresh zero before first init.

Note
Task-only single executor, no concurrent/reentrant calls. Uncertain physical state retains the port for explicit cancel/resync; it creates no MCU buffer loan. Fields are implementation state, never permission to reclaim a loan.
