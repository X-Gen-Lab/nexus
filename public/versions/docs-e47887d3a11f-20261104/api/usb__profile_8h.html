◆ nx_usb_profile_validate()

nx_result_t nx_usb_profile_validate ( const nx_usb_device_profile_t * profile)

Validate exact selected FS facts without observing the controller.

Parameters
[in]profileStable readable immutable facts, faces and endpoint array.
Returns
Success or INVALID, including misaligned public metadata; no allocation, MMIO, discovery or lifecycle effect.
Note
Task/ISR bounded and read-only. Facts identify selected software support; they never imply PCB routing, VBUS wiring or physical qualification. Public metadata, endpoint arrays, faces and operations tables require their natural C alignment and nonwrapping extents. Numeric rejection is not a probe of arbitrary addresses or opaque private contexts. EP0 selects control/64; nonzero bulk selects 8/16/32/64-byte MPS. Interrupt selects nonzero IN with 1..64-byte MPS. Host polling interval belongs to the external descriptor, not this profile.

◆ nx_usb_setup_reject()

nx_result_t nx_usb_setup_reject ( const nx_usb_setup_decision_port_t * port,
uint64_t epoch )

Reject one published SETUP epoch by a checked EP0 IN STALL.

Parameters
[in]portStable selected decision face, same controller owner.
[in]epochNonzero software-published SETUP identity to reject.
Returns
Success after guarded STALL readback; STATE for a superseded epoch/closing source, BUSY while either EP0 packet is live, INVALID for malformed metadata, CONTEXT for an invalid executor, IO for failed STALL readback, or UNSUPPORTED without the optional operation. Rejection retains no loan.
Note
Same privileged unmasked single task executor. The provider checks its published epoch and performs STALL in one local IRQ critical section, preserving the incoming mask. This excludes an already software-published replacement SETUP; it does not promise atomicity with physical bus packets not yet collected by the IRQ. No cancellation, global stop, allocation, class policy or address commit is implicit.
