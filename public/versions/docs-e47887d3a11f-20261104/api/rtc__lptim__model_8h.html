nx_result_t nx_native_lptim_model_advance ( const nx_lptim_port_t * port,
uint32_t ticks )

Advance a finite source, saturating at its exact shot limit.

Parameters
[in]portExact Native LPTIM face, serialized with all public calls.
[in]ticks0..65536 source ticks; idle/unarmed does not accumulate.
Returns
SUCCESS or INVALID/STATE/UNSUPPORTED.
Note
At full65536 the sampled 16-bit counter is zero; pending completion is independent. Held withdrawal permits final progress beyond cancel/time observation. Does not touch the request, terminal cause or Core clock.

◆ nx_native_rtc_model_advance()

nx_result_t nx_native_rtc_model_advance ( const nx_rtc_port_t * port,
uint32_t seconds )

Advance a set raw calendar by bounded explicit source seconds.

Parameters
[in]portExact Native RTC face, serialized with every public call.
[in]seconds0..86400; zero never creates an event.
Returns
SUCCESS, STATE if unset/unconstructed, INVALID or UNSUPPORTED.
Note
Constant bounded work, at most one date carry. A closed set calendar may advance; this does not reopen admission or prove backup retention. Does not read/advance Core clock, publish, settle or change terminal cause. Source changes are not an IRQ, worker or hardware qualification.
