Detailed Description

Client credentials copied by the backend during initialization.

Note
DER only, no implicit files, key discovery or default trust. hostname has hostname_length non-NUL bytes followed by NUL, length 1..253. Mutual-authentication certificate and key are both supplied or absent. TX staging is exactly 512 caller-owned bytes, disjoint from runtime, session, arena and transport state. It stays borrowed until abort. The single serialized executor owns all session and PSA calls.
