Detailed Description

Explicit clock identity and expected existing calibration.

Note
Nonzero domain/epoch follow nx_io_timestamp_t. The owner changes epoch on discontinuity/reset/rate change. Offset is already applied by the chip; this driver only verifies and reports it, never programs calibration or EEPROM.
