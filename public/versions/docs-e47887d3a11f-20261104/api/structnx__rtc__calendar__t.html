Detailed Description

Raw YY calendar; no UTC, century, timezone or oscillator policy.

Note
YY is 00..99 and leap years satisfy YY modulo 4 == 0. Weekday is an independent 1..7 value, not inferred from the date. Other fields use month/day 1-based and 24-hour hour/minute/second values, without leap seconds. Natural year99->00 wrap does not reset the setting domain.
