Borrow a wake sink after validating the actual enabled IRQ source.

Parameters
[in]portSole task owner, started and incoming masks clear.
[in]wakeImmutable sink retained through successful detach/stop.
[in]syscall_ceilingAdditional numerical BASEPRI ceiling.
Returns
Success, BUSY while publishing, PERMISSION, INVALID or CONTEXT.
Note
NULL detaches. Rejection preserves the earlier sink. Notification must be bounded and legal in both task and configurable IRQ contexts.

Request cancellation while preserving the accepted storage loan.

Parameters
[in]portSelected face owned by the sole task executor.
[in,out]requestExact request previously accepted by this instance.
Returns
Success requests drain, STATE rejects an unrelated request.
Note
Physical transmission may win cancellation and remain SUCCESS. Timeout/cancel do not release storage. Failed drain is QUARANTINED.

Close admission, drain transmit loans and withdraw IRQ publishers.

Parameters
[in]portSole task owner; separate observers must also join.
Returns
Success releases provider loans; failure retains incomplete leases.
Note
Never reset a shared peripheral domain to revoke another owner. Retry after physical progress. Stop success is not observer join.
