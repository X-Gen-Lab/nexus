Request controller-wide TX withdrawal without replay.

Note

Read a coherent current hardware counter in its own domain.

Note
No clock synchronization, UTC mapping, acquired-time fallback or PHY compensation. source is SERVICE_OBSERVATION, not an SFD event. The owner extends seconds wrap and rejects regression, overflow and ambiguous gaps; ticks are nanoseconds with rate1e9 and unknown uncertainty.

◆ nx_eth_frames_port_recover()

nx_result_t nx_eth_frames_port_recover ( const nx_eth_frames_port_t * port,
nx_time_us_t deadline )

Explicit recovery by the exclusive MAC owner after failed drain.

Note
Task owner; finite absolute deadline. Held RX or captured publishers return BUSY without reset. Reset acknowledgement is mandatory before detached pending TX can settle with their locked terminal cause; never report wire success without its actual status. No auto replay. Reset invalidates the old hardware clock epoch and records an RX gap. Source failure/timeout retains QUARANTINED loans and recovery responsibility.

Close admission and prove DMA/MAC/IRQ withdrawal before release.

Note
Held RX and captured publishers retain ownership. Any failure keeps unfinished leases. Do not flush a nonempty TX FIFO to fake quiet. Caller joins all external producers/consumers/observers separately.

◆ nx_eth_frames_port_submit()

nx_result_t nx_eth_frames_port_submit ( const nx_eth_frames_port_t * port,
nx_eth_frames_tx_request_t * request )

ACCEPT one complete frame after all storage and slots are validated.

Note
Task owner, privileged/unmasked; no pool, heap, worker or OS lock. REJECTED retains no references or OWN effects. ACCEPTED borrows request, fragment array and every payload until acquire-observed SETTLED. One returned descriptor does not prove wire completion. transferred is whole frame bytes on proven MAC success, otherwise zero.

◆ nx_eth_frames_tx_prepare()

nx_result_t nx_eth_frames_tx_prepare ( nx_eth_frames_tx_request_t * request,
const nx_eth_fragment_t * fragments,
size_t fragment_count,
bool timestamp,
nx_time_us_t deadline )

Prepare unborrowed request storage without hardware effects.

Note
Serialized task owner. Validate nonempty fragments, overflow and the complete Ethernet II header across fragments; permit one in-band C-tag. Untagged length is 14..1514, tagged 18..1518, excluding FCS. Hardware inserts padding/FCS. Length-coded 802.3, QinQ and 0x88A8 reject. Failure preserves request and retains no references. Deadline is an absolute monotonic provider time, distinct from the PTP clock domain.
