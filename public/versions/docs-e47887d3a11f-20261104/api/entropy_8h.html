typedef struct nx_entropy_port nx_entropy_port_t

Static two-pointer source face with private mutable state.

Note
Caller serializes use and lifecycle; face/table/state outlive each call. No buffer or request is retained after return. Source enable, clock dependencies, recovery and stop belong to its explicit lifecycle owner, not to TLS or this face.

Fill exactly the requested bytes before a finite deadline.

Parameters
[in]portLive serialized source; no concurrent lifecycle change
[out]outputWritable byte span; NULL only for zero bytes
[in]bytesExact required output size, not an entropy estimate
[in]clockLive monotonic microsecond clock in one stable domain
[in]deadlineFinite absolute deadline in that clock domain
Returns
SUCCESS only for a complete fill; TIMEOUT, IO, STATE or source error; INVALID/UNSUPPORTED for preflight rejection
Note
Task-only synchronous polling; no heap, worker or OS wait. BUSY causes another clock-bounded poll. The supplied clock must continue advancing throughout the call; changing its domain or stopping its timer violates the contract. NX_DEADLINE_NEVER is rejected. Complete words are emitted least-significant byte first; unused final-word bytes are discarded. A zero-byte request validates face and clock but performs no clock/source access and accepts NULL output. Preflight rejection leaves output unchanged. Once admitted, any error erases the complete output using volatile writes; no partial entropy may be consumed. Output is disjoint from face/table/clock and all their opaque live contexts. This function detects known-span aliases, not opaque extents. Crypto libraries own conditioning, DRBGs and trust policy.
