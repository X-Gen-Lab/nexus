Detailed Description

Caller-owned backend storage; include only at the composition site.

Note
This explicit backend header is tied to the pinned lwIP profile and exposes its exact netif layout to avoid a maximum-size opaque pool. Fields are implementation state, not an application control API. Application raw PCBs use this netif only during live attachment.
