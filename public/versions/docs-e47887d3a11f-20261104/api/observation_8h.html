◆ nx_io_timestamp_budget()

nx_result_t nx_io_timestamp_budget ( const nx_io_timestamp_t * first,
const nx_io_timestamp_t * last,
uint64_t maximum_ticks,
nx_io_timestamp_budget_result_t * out )

Compare a complete timing-error interval with a budget.

Parameters
[in]firstStable aligned extended timestamp, causally paired.
[in]lastStable aligned fact in the same domain/epoch/rate.
[in]maximum_ticksInclusive maximum, in the stated tick units.
[out]outDistinct aligned result, unchanged on rejection.
Returns
SUCCESS, INVALID/UNSUPPORTED/STATE as elapsed, or EXHAUSTED when the uncertainty sum or upper bound cannot fit.
Note
Pure O(1) Task/IRQ work with no clock access or retention. WITHIN requires upper <= maximum; EXCEEDED requires lower > maximum. An overlapping or unknown error interval gives UNKNOWN. SUCCESS alone does not mean within budget. The existing timestamp-owner/provenance contract applies: this does not extend raw DWT, validate epoch continuity, synchronize sampling, establish IRQ arrival or prove WCET.

◆ nx_io_timestamp_elapsed()

nx_result_t nx_io_timestamp_elapsed ( const nx_io_timestamp_t * first,
const nx_io_timestamp_t * last,
nx_io_timestamp_delta_t * out )

Compare two explicitly related observed events.

Parameters
[in]firstStable aligned first fact, not concurrently modified.
[in]lastStable last fact in the same domain, epoch and rate.
[out]outDistinct aligned result, unchanged on rejection.
Returns
SUCCESS, INVALID for malformed/overlapping storage, UNSUPPORTED for UNKNOWN source, STATE for incompatible domains or reversed ticks, EXHAUSTED for bound overflow.
Note
Task/IRQ pure constant work; no clock, hardware, allocation, lock or reference retention. Inputs may coincide. The caller proves event pairing and timestamp provenance. Different explicit source kinds may be compared to observe delivery latency, without relabeling either observation.
