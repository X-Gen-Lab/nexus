Bind a fresh executor without opening hardware or admission.

Parameters
[in,out]executorZero fresh storage, distinct from capability/face.
[in]bindingInitialized bus exclusively serviced by this owner.
Returns
Executor for nx_bus_owner_init, zero port on invalid input.
Note
Task-only, all lifecycle users joined before replacement. Uses original FIFO/slots/epochs; final provider terminal result survives late cancellation. Continue unique executor service during stop and quarantine. Hardware stop, publisher join and observer join remain explicit external steps.

Check typed storage, then use bounded owner admission.

Parameters
[in,out]ownerOwner with this exact typed executor.
[in,out]requestPrepared READY outer request.
[in]operationImmutable chain through outer SETTLED.
[in]completionOptional static caller hint, or NULL.
[out]ticketStable slot/epoch identity on SUCCESS.
Returns
SUCCESS means ACCEPTED; failure retains nothing.
Note
The request has an absolute deadline including queue time. Task multi-producer checks run outside the metadata guard. There is no capacity scan, allocation, OS lock or worker. One operation has one CS interval with allowed SCK gaps. Schedule bounded service even when hints fail. Waiters never service the shared controller. Queued provider failures settle later without converting admission into rejection.
