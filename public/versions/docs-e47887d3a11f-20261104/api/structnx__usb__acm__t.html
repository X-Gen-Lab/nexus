Detailed Description

Fixed caller storage; fields are private while bound.

Note
Metadata require natural C alignment and nonwrapping extents; wire bytes require only byte alignment. Bind once from zero initialization. Never zero/rebind to revoke a loan. The profile, faces and this complete context outlive every packet/outer loan and separate observer. No dynamic allocation, per-instance operation table, worker or default instance exists. Provider faces retain shared readonly ops.
