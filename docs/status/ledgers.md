# Historical execution ledgers

The original CSV files and derived views retain their original IDs, source,
exit conditions and evidence references. They are not the current production
support catalogue and are excluded from current-site navigation and translation
admission. Their source-byte checks remain available independently.

Read [the fixed original views](https://github.com/X-Gen-Lab/nexus/tree/8e147fc2c812d81ab6596e0d1a6bc8908d30ac18/docs/status/ledgers)
when auditing those executions. The current refactor does not rewrite historical
results or create another competing task ledger.

Use [current support](../reference/platforms/support.md) and
[current delivery boundaries](../delivery/README.md) for this source.
