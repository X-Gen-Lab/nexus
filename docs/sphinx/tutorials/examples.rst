Maintained External Examples
============================

See :doc:`../getting_started/examples_tour` for the actual eight applications in
`nexus-examples <https://github.com/X-Gen-Lab/nexus-examples>`_. They consume public
Nexus targets/headers, fix SDK identity and own main, worker/component order,
resources and product policy. Nexus does not contain business application sources.

Formal consumption uses matching Gitlink/lock. Candidate CI may test a specified
full commit without changing that formal pin, records actual checkout identity
and runs its own source-pair matrix. A workflow definition is not an executed
result; current validation reports identify exact counts, source and artifacts.

Native models, RAM Config roundtrips and compiled MCU targets do not establish
physical transport, Flash persistence, safety/secure boot or enterprise/LTS
qualification. Boards are deferred and all physical evidence remains unverified.
