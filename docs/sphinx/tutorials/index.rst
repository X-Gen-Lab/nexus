Application Examples and Contract Tutorials
===========================================

The maintained runnable examples live in
`nexus-examples <https://github.com/X-Gen-Lab/nexus-examples>`_, which fixes a
Nexus source revision and owns application main/workers/policy. The pages below
explain public contracts and point to those actual consumers. They do not add
unsupported hardware by copying draft tutorial code.

Start with the finite Native example matrix, then reviewed MCU software profiles.
Typed MCU I2C, ADC/PWM and arbitrary EXTI routes are not implemented. The user has
deferred boards; no tutorial execution establishes physical qualification.
