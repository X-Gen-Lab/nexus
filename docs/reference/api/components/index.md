# Optional component reference

Choose reusable protocol or coordination mechanisms by responsibility. Components consume explicit ports and caller-owned storage; products own scheduling, application policy and physical recovery. Exact-profile storage headers belong only at static composition.

The API reference describes current software contracts. It does not authorize an unselected MCU mode, Board connection, kernel gateway or physical result.
