# Init 设计边界

依赖方向：外部固件 → 可选 Init 组件 → HAL 公共状态类型与链接段。通用 Runtime 独立负责 HAL/OSAL owner 和失败回滚，不依赖 Init 组件，不执行产品回调。

初始化条目使用编译器/链接器段注册，级别 1–6 按级别排序；0 和 7 是内部边界。Native GNU/Clang 使用维护中的 linker fragment，MCU 使用所选平台 linker。注册项必须实际存在于最终目标中，不能仅依赖静态 archive 的按需抽取。

生产实现先校验段地址、顺序、对齐、条目长度和计数上界，再遍历。首次运行统计全部结果，失败时继续尝试后续项并返回失败；重复调用保留已执行结果，不重跑初始化。查询统计与完成状态不初始化硬件。

该组件没有自动线程、scheduler 启动、main 回调、应用健康状态或组件回滚。调用者必须串行使用初始化入口，并检查最终状态再允许业务运行。初始化级别不代替应用依赖图或资源所有权。

厂商 Reset/startup 与 C runtime 初始化由平台维护。本组件不替换 SP/向量表/Reset_Handler，也不引入编译器 main 重定向。
