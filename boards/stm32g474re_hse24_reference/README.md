# STM32G474RE HSE24 software reference

This package describes a source-reviewed STM32G474RET6 reference using the
NUCLEO-G474RE / MB1367 C04/C05 documentation. The name identifies a software
profile. Physical PCB revision, fitting, bridges and all HIL remain unknown.

The fixed clock profile is `hse24-pll170`: X3 24 MHz, PLLM6/N85/R2, HCLK and
APB1/APB2 170 MHz. [UM2505 Rev7 section7.5.1 page22](https://www.st.com/resource/en/user_manual/um2505-stm32g4-nucleo64-boards-mb1367-stmicroelectronics.pdf)
specifies X3 as the default, with SB25/SB26 on, SB24/SB28/SB27 off and C56/C59
6.8 pF. The alternate 8 MHz ST-LINK MCO bridge profile is unsupported here.

`led0` authorizes PA5 / LD2, active high with inactive zero and SB6 on.
`uart1` selects LPUART1 PA2 TX / PA3 RX, AF12. The reviewed VCP choice requires
SB17/SB23 on and SB18/SB22/SB13/SB19 off. These facts describe the manual, not
an inspected Board. Products must confirm their PCB and electrical path before
commissioning.

The original LED/VCP profile remains available. Additional bindings select
GPIOB0/GPIOC0, USART1 PA9/PA10 AF7, USART2 PA2/PA3 AF7, USART3 PB10/PB11 AF7,
UART4 PC10/PC11 AF5 and UART5 PC12/PD2 AF5 as silicon-route software fixtures.
Their connector exposure, bridges, attached loads and voltage are not inspected.
They do not redefine the documented LPUART1 VCP bridge as USART2. UART reception
uses an explicit generated byte ring and priority5; no event/block RX or DMA is
advertised. TIM2/IRQ28 and PF0/PF1 HSE pads remain reserved. Conditional PG10/NRST
is reserved until a reviewed option policy exists.

SPI1 PA5/PA6/PA7 AF5 with PA4 CS and SPI2 PB13/PB14/PB15 AF5 with PB12 CS are
unattached software fixtures. Active-low CS starts high; no external sensor or
Board electrical connection is inferred. Only finite byte polling is maintained,
with a 42.5 MHz fixed-profile ceiling and actual rate selected by APB divisor.
`watchdog0` exposes IWDG without enabling or feeding during startup. Once enabled,
its irreversible responsibility prevents complete Platform shutdown.

TIM3 CH1 PA6 AF2 and TIM4 CH1 PB6 AF2 are unattached fixed-base PWM software
fixtures. Each owns its complete timer, has an explicit inactive GPIO level,
and supports active-high upcounting with staged duty0..period. No load, connector,
advanced break, complementary output, capture or DMA behavior is inferred.
SPI/PWM select OSPEEDR11. Logical counter rates are separate from physical pad
limits; actual VDD, capacitive load and pulse width must meet DS12288 Table56
and the selected peripheral conditions before commissioning.

The exact CPU/Flash/RAM contracts are in the
[G474 design](../../docs/design/stm32g474.md). ADC, I2C, Flash programming,
FDCAN and other unlisted modes remain unsupported.

Generated cold assembly leases only selected GPIO fields. It snapshots those
fields after acquiring the selected GPIO bank gates and before changing pin modes.
All providers join before the fields are restored and only newly acquired gates
are withdrawn, with readback. Failed restoration retains the platform lifecycle
for explicit cleanup retry; no factory lookup acquires or initializes hardware.

## 中文参考边界

这是基于 NUCLEO-G474RE／MB1367 C04/C05 文档的软件配置，未检查实物 PCB、晶振、
焊桥或连接器，全部 HIL 未执行。固定配置使用 24 MHz X3 和 170 MHz PLL；LD2 为
PA5，VCP 为 LPUART1 PA2/PA3 AF12。必须按上文 UM2505 的焊桥条件核对实际硬件。

其他 GPIO、UART、SPI、PWM binding 仅为芯片路线软件夹具，不授权未审的电气连接。
SPI1/2 使用独立低有效 CS、有限 polling，最高 42.5 MHz；TIM3 CH1 PA6 AF2 和
TIM4 CH1 PB6 AF2 仅提供独占整个 timer 的固定 base PWM。IWDG startup 不自动启用，
激活后不可逆。TIM2、HSE 焊盘与条件 NRST 焊盘保持保留；未列模式必须拒绝。
SPI/PWM 选择 OSPEEDR11；逻辑计数范围与实际引脚频率分开，投运前须按 DS12288
Table56 及对应外设条件验证实际供电、电容负载和脉宽。

引脚、gate 与部分失败的恢复责任由生成的静态装配持有，factory 查询只返回已有对象。
详细合同与双语说明见[G474 设计](../../docs/design/stm32g474.md)。
