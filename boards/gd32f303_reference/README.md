# GD32F303RCT6 精确封装软件参考

本包是 GD32F303RCT6 LQFP64 的软件夹具，不描述已制造 PCB。根据官方数据手册，
它声明 PA4/PA5 GPIO、默认 USART0 PA9/PA10、SPI0 PA5/PA6/PA7 芯片路线；SPI
夹具使用独立 PA4 低有效 CS，不假定已连接器件。内部 FWDGT 不占引脚。

装配选择内部 IRC8，不虚构外部晶振频率。PA13/PA14 及其余 SWJ 引脚保持保留，
不修改 option bytes、SWJ remap 或启动绑带。

本包不证明 LED、收发器、电源、晶振、连接器或外部调试器已安装。实际复位、电压、
上拉、布线、时钟容差及物理测试由另行标识的 Board 包和 HIL 工装负责。

[GD32F303 实现合同](../../soc/gd32/gd32f303/README.md)说明精确模式、静态所有权、
有限时间域和不支持的范围。芯片路线可配置不等于 PCB 电气或实板行为已验收。
