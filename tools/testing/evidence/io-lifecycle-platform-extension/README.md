# I/O lifecycle platform extension development evidence

This archive binds 203 reviewed finite properties to a fresh, unfiltered
37-target Google execution with 710 passing cases and no failed or skipped
cases. It extends CAN (22), USB (24), raw Ethernet (30), G474 software-reference
UART/factory (11), and capture/advanced timer (36) properties. The original
first 80 property objects and their separate historical archive are unchanged.

`manifest.json` records exact original/stored paths and SHA256 identities.
`raw/matrix-execution-attempt1/` contains discovery, actual subprocess commands,
fresh XML, the existing execution summary, preexecution inputs and the audited
property report. Capture bound 161 catalogue source inputs, 79 reviewed TUs,
142 compiled contexts and 122 target-local contexts, including nine actual
generated factory `bindings.c` files. `build-identity/` preserves the observed
CMake plan and compile database; `source-capsules/` preserves available exact
bound source bytes. Large object/executable bytes remain at their development
paths and are hash-bound in the report rather than copied here.

Seven new real boundary cases first failed against production capture/audit
(six failed assertions and one missing field), then passed. The maintained
tool has 25 passing cases; its final run with the four existing integration
cases passed all 29 with the four maintained inputs unchanged. Mutation cases
reject changed generated TU/object identities, missing objects, sources outside
checkout/build, symlinks and object paths escaping their target. The initial
configure failure from the older typed-model fixture is preserved separately;
the source owner repaired it before these binaries were built and executed.

The property audit completed before other active configuration work changed
two emission files and `secondary_controllers.py`. The archive input check
rejected copying those later bytes as the earlier snapshot. Their exact
historical capsules were unavailable during archival and are explicitly listed
in `unavailable_historical_source_capsules`; their original identities remain
in the unchanged report. The later source receives no inherited qualification.

Raw logs, XML, generated files and source snapshots preserve their original
bytes. Historical source snippets and `.txt` subprocess logs use `.raw` storage
suffixes so they are evidence rather than maintained source files. The authoring
and one-shot development scripts are historical artifacts, not new production
runners or a second target registry.

This is a dirty-checkout development subset, not the complete clean candidate
gate. Root's final whole CMake Google plan must rebuild, capture, execute and
audit the then-current source without `allow_subset`. Author assertion/source
review is complete; an independent tool-boundary review was queued and is not
claimed here. Neither test names nor hashes alone prove semantics, complete
interleavings, full header closure or machine-code behavior. CAN bus, USB host,
PHY/transceiver, timer waveform, electrical safe output, actual IRQ latency
and board qualification remain `not_executed`.
