# 显式执行的电机与轴控制

本目录提供可选 C11 控制组件。调用者拥有每个实例的参数、历史、时间和执行者；
组件不创建任务、堆、设备注册表或全局时钟，也不直接操作厂商 SDK。

[控制架构与 FIG-35](../../docs/explanation/motor-control.md)区分算法决策、应用桥、
唯一硬件 owner 及最终退出；公共头保持各字段的权威合同。

| 入口 | 责任 | 调用者仍负责 |
| --- | --- | --- |
| `Nexus::MotorControl` | 有感电流计算、坐标变换、调制、校准候选及算法故障 | 真实测量、功率约束、硬件提交和完整退出 |
| `Nexus::AxisControl` | 命令准入、速度／位置级联、参考采用与参数切换 | 执行节拍、机械侧换算、授权与设备恢复 |

算法决策、输出暂存、硬件采用和机械结果分别观察。控制组件的成功返回不证明
功率级已经采用输出，也不证明机构已经停止。底层请求和 callback 的借用仍以
provider 的最终退出为准；不能通过清零算法状态解除它们。

任务与 IRQ 不得同时逐字段修改同一个实例。跨上下文交接由应用已有的有界
queue／guard 或具有独立同步合同的对象负责。参数按完整 revision 切换，停机、
清故障和重新使能分别执行。

通用数学继续复用 `../algorithms`；PWM、ADC、角度源、门极与 IRQ 由唯一硬件
provider 管理。底盘协调、升降承重、机械抱闸和整机动作属于外部应用。完整示例
保存在 `X-Gen-Lab/nexus-examples`，物理 HIL 与实时性能仍需精确设备执行。
