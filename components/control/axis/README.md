# 显式目标的旋转轴计算

`Nexus::AxisControl` 提供调用者拥有状态的 C11 电流目标、速度 PI 和位置级联。
组件不读取硬件、创建任务、分配内存或隐式读取时钟。通过
`nexus/control/axis.h` 使用，依赖既有 `Nexus::Algorithms` 的梯形轨迹。

## 组合与单位

```text
完整命令 → 接纳槽 → 下一周期采用 → 轨迹／速度参考
                                      ↓
机械反馈 → 位置修正 → 总速度限制 → f32 速度 PI＋电流前馈
                                      ↓
                             总电流限制 → 独立电流目标
```

位置为 rad、速度为 rad/s，均位于同一个明确的机械侧；电流输出为 A。
齿比、方向、标定及转矩到电流的转换由外部工程提供。反馈速度描述显式
`[interval_start, sampled_at]` 区间；时间标签不自动证明硬件采样孔径。
`CURRENT` 输出受限的电流目标；`VELOCITY` 使用速度目标及电流前馈；
`POSITION` 采用静止到静止的梯形／三角轨迹，当前不选择带速重规划。

## 单一执行者和时间

同一执行者串行调用 initialize、enable、accept、step、参数及停止方法。
任务／IRQ 之间先通过已有的有界队列或 guard 复制完整输入；普通结构体字段
不是并发发布协议。每轴积分、轨迹和观察独立。

调用者提供同一微秒 `clock_domain` 和完整 64 位 `epoch`，以及有限的时间预算。
step 使用连续反馈序号、严格递增控制时间和与时间差一致的 `dt_s`。
缺样、无效反馈、过期、时间倒退和超间隔不能通过重复旧输入修复。
位置规划发生在 accept 中；逐周期计算不进行轨迹规划或访问外设。

命令保存原始本地 `received_at`，不能在解析完成后重新打时间戳。
重复／旧序号不续期；新命令可以保持相同数值。接纳只复制命令，
`command_sequence`／`adopted_at` 在实际计算周期采用后才更新。
它们描述软件目标采用，不代表 PWM shadow 已装载或机械动作完成。

## 限制、参数与观察

速度先合并轨迹和位置修正，再作总限速、限加速度。电流先合并 PI 和前馈，
再受当前下游 `nx_axis_limits_t` 与参数电流限制共同约束。
向饱和方向的积分增量被冻结，反向积分仍可恢复。额外的下游电流参考限制可用
`nx_axis_track_current` 按精确周期回算一次；该值不是测得的绕组电流。

先完成本周期 tracking，再 stage 新参数。pending revision 存在时 tracking
返回 BUSY 且不消费周期，避免已接受反馈被旧候选积分覆盖。
参数只在下一计算边界或 enable 时整组切换；不执行持久化。
运动中的位置轨迹不能修改速度／加速度几何。位置范围必须包含保留目标和反馈。

`trajectory_complete` 只描述规划。`target_reached` 还检查有效位置误差、速度和
连续观察停留时间；数据丢失或超期不会伪造停稳。输出不借用设备数据。

## 停止与恢复

命令在 `now >= valid_until` 时过期。仍有效的反馈允许继续执行受控速度下降；
过期目标在采用之前被发现时，不会记录为已采用。重复 stop 不重启停留计时。
`config.stop_policy` 明确选择满足速度停留后的算法行为：

| profile | 行为 |
| --- | --- |
| `NX_AXIS_INHIBIT_AFTER_DWELL` | 输出零电流目标；正常退出到 READY，超时退出到 FAULT |
| `NX_AXIS_HOLD_ZERO_VELOCITY` | 进入 HOLDING，继续零速 PI 并拒绝新的运动命令 |

HOLDING 可以保留命令超时原因并继续 step；反馈失效等硬错误仍进入 FAULT，由外部
撤回输出。重复 stop 不退出 HOLDING。清故障、参数改动和重新运行需要显式关闭。
双轮教学组合明确选择前者，不把零电流解释为机械制动或断能。

零速调节不保证重力负载已经被托住，也不是位置保持、抱闸到位或机械安全证据。
外部机器必须核对真实电流／转矩、供能和机械条件，完成支撑交接后再显式 disable。

`parameters.stop_feedforward_a` 是机器明确提供的停止／保持电流偏置，必须有限且
不超过配置电流范围；双轮参考显式设为零。STOPPING／HOLDING 使用这份完整参数，
不继承可能含加速成分的旧命令前馈。偏置与 PI 合并后仍受动态下游总限制及抗饱和
约束。重力偏置是控制请求，不是已经建立承重的测量证明。

disable 只关闭算法准入。provider 的输出抑制、IRQ／DMA 撤回、借用 SETTLED 和
使用者 join 仍由外部 owner 完成。故障只能在 DISABLED 中显式清除，清除后仍不使能。

`tests/google/components/axis_control_test.cpp` 执行真实 C，检查接纳／采用、限制、
到位、参数完整性、周期绑定、超时及独立实例。主机行为不建立实板控制稳定性或
最坏执行时间。物理 HIL 保持 `not_executed`。
