# 电流标定与重构

`Nexus::CurrentControl` 提供无硬件、OS、堆和隐式时间的 C11 计算。
公共入口为 `nexus/control/current.h`。调用者提供不可变标定、一次捕获和独立输出，
失败不发布部分结果；不同实例没有共享可变状态。

| 入口 | 输入与结果 |
| --- | --- |
| `nx_current_calibration_check` | 校验非零身份／版本、偏置、增益、方向与范围 |
| `nx_current_convert` | 将两／三相逻辑 ADC 码转换为安培，必要时重构第三相 |
| `nx_current_reconstruct_bus` | 根据两个独立有效开关矢量重构单母线分流电流 |

相位 mask 的 A/B/C 对应 bit 0/1/2；开关矢量的上桥臂 A/B/C 对应 bit 2/1/0。
原始寄存器布局、ADC rank 和采样路线由 provider 转换，控制组件不认识厂商类型。

标定身份和 revision 必须与捕获匹配，它们是配置身份而非认证。
未安装传感器的偏置、增益和方向全为零，不需要伪造第三路标定；至少一路真实存在。
实测 mask 指向未安装通道时拒绝。单母线分流只需要 slot 0，其他 slot 可以缺席。
调用者另外验证真实周期、计划、epoch、零流条件、AFE 和方向依据。
低噪声、零均值或 PWM 关闭都不能单独证明零电流；本组件不激励硬件、不采用候选，
也不写持久化存储。

`EXPLICIT` 提供同周期不回绕的实际 aperture tick；`BOUNDED` 只提供真实来源的
组参考和正偏差上界，不读取 aperture 数组。不能把总扫描跨度按 rank 均分后冒充
已测孔径。显式声明上界时，它必须覆盖已知跨度，并原样保留在输出中。
非零 skew 表示被明确接受的有界偏差，调用者仍须证明电流斜率引起的误差可接受。
单分流的两个值必须来自同一实际计划，
零矢量以及只观察同一相的相反矢量不能恢复三相。

输出保留实测和重构 mask。三独立测量可以检查三相和；两相重构后的三相和恒等为零，
不能作为传感器一致性证据。ADC rail、幅度、身份和偏差错误均有明确结果。

GoogleTest 直接执行生产 C。模型通过不等于模拟前端精度、采样孔径或实板资格。
