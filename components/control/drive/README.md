# 显式参考与连续反馈的电驱组合

`Nexus::DriveControl` 通过 `nexus/control/drive.h` 连接 Task 中的轴控制与
单执行者电流计算。组件不创建任务、访问硬件、分配内存或读取隐式时钟。
调用者持有实例、队列槽、时间、参数与最终硬件会话。

```text
Task：Axis → 完整有限参考 → SPSC
                              ↓
快环：合格相电流／角度 → Drive → Motor 电压请求
                              ↓
              选定调制与采样规划 → 最终电压 tracking → provider 提交
                              ↓
           连续外环反馈 SPSC → Task
```

## 所有权与容量

参考队列由一个 Task 发布、一个快环执行者消费。反馈队列由一个快环发布、一个
Task 消费。槽数组由调用者提供，容量是非零的二次幂；索引使用 Arch 的
acquire／release 发布，不使用 OS 队列或隐藏锁。所有生产者、消费者及硬件
发布源完成 join 后，才能重新初始化或归还存储。

参考满时拒绝新记录，不覆盖旧值。每个快环最多采用一条；暂时没有新记录时，
只能继续使用尚未过期的已采用参考。独立 inhibit 不受普通队列容量阻挡。
该信号只要求下一次计算拒绝，不代替硬件快速保护与最终退出。

`received_at` 保留原始本地授权时刻。排队不能刷新它；接纳不等于快环采用。
`adopted_cycle` 和 `adopted_at` 保留该 generation 首次采用事实，不能称为
PWM 或机械回执。参数 revision 标识停止时初始化的 Motor profile，与 Axis
独立采用的参数 revision 不混用。运行中不能逐字段修改被借用的 Drive。

## 电压与反馈

Drive 使用 `nx_motor_voltage_step`，不选择固定 duty。调用者使用选定调制器
共同规划 PWM 与采样，按输出角将最终计划电压反馈一次，再由唯一 provider
提交。提交失败需要故障并撤回原会话；已经推进的算法历史不能继续运行。

反馈 sampler 按固定的实际快环间隔数发布；位置是对应采样时刻的合格有界
弧度值，速度由真实区间的位置差求得。多圈整数保持、机械侧换算和角度质量
由上游提供。丢周期、时间倒退、epoch 变化或反馈队列满都不能通过重编号修复。

连续反馈与可丢遥测使用不同对象。反馈中的 `accepted_iq_a` 是指定参考
generation 的采用值，不是测量电流。Axis 下游 tracking 必须对应原始输出；
不能把延迟回执拿来修正新一轮 Axis 决策。
`command_sequence` 说明到这份观察时快环已采用的命令，不伪造命令最早采用时刻。
外部组合可将参考 generation 直接选为 Axis sample sequence，避免额外映射环。

## 母线与退出

可选 `nx_drive_bus_limit` 在 Task 中计算消费与回生两个独立的保守功率比例，
不把一轴制动当作另一轴必然可用的供能。预算必须有明确来源和有限时效；产品
根据母线电容、供电吸收和制动硬件提供它，并将限制落实到参考。计算不证明
母线电压安全，也不代替硬件过流／过压保护。

组件没有功率使能能力。标定资格、运动授权、机械停止、抱闸与恢复属于外部
组合。PowerStage 借用直到 acquire 观察 `SETTLED`；输出抑制、算法故障或清零
状态都不能提前归还算法 context。退出失败保留原存储和恢复责任。

GoogleTest 直接执行生产 C 的记录交接、真实区间、限制及故障路径。Native
结果不证明 MCU WCET、电流精度、物理制动或双轴硬件行为。
