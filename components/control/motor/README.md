# 有感 PMSM 计算核

`Nexus::MotorControl` 提供独立 C11 电流控制：标定后的三相电流、明确时间的机械角、
母线电压和 dq 电流目标，经过变换、PI、矢量限幅和共同偏移调制，产生完整三相 duty
计划。它不访问外设、不创建任务、不分配内存，也不依赖 MCSDK 或其他电机产品固件。

## 执行与输入

一个执行者串行使用每份 `nx_motor_t`。输入使用 A、V、机械 rad、rad/s，三相方向和
相序已归一化。配置只应用一次极对数及电角偏置；不把减速比或机械回零混入换相角。

采样、角度、观察和计划输出时间使用同一个微秒时基与 64 位 epoch。角度可以在
采样之后、观察之前取得，分别进行有界反向投影和输出预测。实际采样间隔用于后续
积分；首次计算采用显式 nominal period。
序号必须逐次递增，重复、漏期、旧 epoch、过期角度和无效测量会锁存故障。

三相输入表示同一控制测量快照。顺序 ADC rank 不会自动获得同时采样资格；桥接者
必须审核转换偏斜与误差预算。计划时间也不表示真实 aperture 或实际输出已生效。

## 限制与提交

线性电压圆同时考虑母线、调制度和对称 duty 留白，限制反馈用于 PI 回算。这个数值
留白本身不能证明具体 PWM 边沿下的全低侧采样窗口；硬件 provider 仍须审核触发、
模拟稳定时间和完整输出计划。最终量化或额外采样窗口约束可使用带 cycle 身份的
`nx_motor_track_voltage` 回算，每份最新计划只接受一次跟踪。

`nx_motor_latch_fault` 关闭后续计算，并通过原硬件 owner 撤回输出与引用。故障步骤

## 校准候选

固定样本数的 raw offset 估计只产生独立候选，不直接修改运行参数或保存介质。
零电流条件由外部证明；低噪声或均值稳定不证明真实电流为零。越量程或噪声超限会
使候选失效，不能丢弃坏样本后继续宣称通过。电角偏置由显式配置提供；实际对齐、
功率授权、机械运动及持久化流程属于外部应用。

## 软件验证

`motor_control_test.cpp` 执行真实生产 C，覆盖变换、预测、限制、回算、故障、身份、
别名和校准候选。独立的平均值 PMSM 模型具有电气及机械状态，控制器只看到量化后的
电流、编码器观察和母线，不读取模型真值；完整输出延迟一个周期后采用。

该模型只建立所选软件场景，不模拟全部开关、电磁、温度和功率保护过程。真实稳定性、
采样精度、IRQ 时延、WCET、功耗和实板 HIL 均未由这些测试建立。
