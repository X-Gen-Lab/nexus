# 显式时间输入去抖

`Nexus::Debounce` 使用 `nexus/components/debounce.h`，提供 caller-owned 的 Boolean
稳定判定。调用者传入同一 Core 单调微秒域的快照，独立配置上升和下降稳定时间。
组件不读取全局 tick、不申请堆、不创建 timer 或 worker，也不接管输入采集。

## 行为合同

初始化指定的电平已经可信，不产生边沿。首次观察到另一电平时开始候选计时，持续达到
对应 hold 时间才提交稳定变化，等于时间边界即生效。候选期间回到稳定电平会立即
清除候选；再次变化重新计时。零 hold 在首次观察时立即提交，每次稳定变化仅有一次
`changed=true`。漏采样期间的真实输入变化无法反推，不用上次采样时间猜测边沿。

时间倒退、非有限时间或非法输出拒绝且不改状态与输出。域停止、重置或换源后，由
调用者等待退出旧使用者，再显式初始化新域。ClockDomain 只可参与外部生命周期协作，
不是组件依赖。多实例候选时间互不影响，同一实例由一个执行者串行调用。

采样与分发复用已有 device/owner 和队列路径。长按、双击、连发、输入映射及故障
处置由产品提供；去抖器不带这些策略，也不引入另一个输入 broker。

GoogleTest 位于 `tests/google/components/common_debounce_test.cpp`，验证精确边界、
抖动重启、非对称窗口、倒退拒绝、域上限和实例隔离。宿主结果不证明实物采样周期、
GPIO 电气特性或输入器件的抖动参数。
