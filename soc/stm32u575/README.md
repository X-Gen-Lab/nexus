# STM32U575 single-state reference

This provider targets exact STM32U575ZIT6Q and the source-reviewed NUCLEO-U575ZI-Q
MB1549 reference. The maintained slice is CPU startup, reset-like MSIS 4 MHz,
reserved TIM2, PC7 GPIO and USART1 PA9/PA10 AF7 IRQ bytes. The default linker RAM
is SRAM1 192 KiB. It does not allocate storage or create tasks, workers or runtime
registries. The typed factory returns existing readonly faces; instances own
private state and share readonly GPIO/UART operations.

The official STM32U5 CMSIS device source is pinned to
`624374fa1e21ca195d6f2102ac0caaa50d0ea4c8` (v1.4.3, Cube v1.9.0). The original
Apache-2.0 license and ST notices remain intact. SDK register types remain private.
CMake selects only required source units and the official U575 startup; it never
links the vendor stock `SystemInit` alongside the owned implementation.

## Startup and execution

The only supported boot contract is **TZEN=0**, SWAP_BANK=0, one address state.
The reference never changes option bytes, security attribution or bank layout.
A station/boot owner must observe compatible option bytes before executing this
image. Reading an option register after startup cannot turn a TZEN1 boot into a
valid single-state boot, and cannot establish Secure/NonSecure isolation.

`SystemInit` executes before primary `.data` and `.bss`. It touches CPU CPACR,
VTOR and priority grouping through constant MMIO addresses and barriers. It
never reads or writes initialized context, `SystemCoreClock`, libc or a heap.
Post-RAM cold admission checks the effective MSIS range 4, selected clock/status,
equal HCLK/APB dividers, inactive PLLs and caches, Flash readiness, and unowned
TIM2/IRQ 45. Unknown running profiles fail before hardware writes. No RCC/power
reset sequence, automatic clock adoption or external crystal is needed.

TIM2 uses PSC 3, ARR 0xffffffff and IRQ 45 at priority 0 for a nominal
1 MHz domain.
Start observes the update generated by UG within the explicit bounded poll
budget, then observes UIF cleared before publishing a usable time domain.
A masked snapshot corrects one pending wrap and restores the incoming mask;
epoch validity is checked inside that same exclusion. The IRQ must execute at
least once every 2^32 microseconds. A refused runtime UIF acknowledgement records
`timer_error=NX_ERROR_IO`, invalidates time and retains timer ownership without
incrementing the overflow count. Finite ISR actions attempt DIER, CEN and NVIC
withdrawal once. The lost deadline domain is always terminal, including
successful isolation: preserve the terminal interrupt mask, call the platform
fault observer and park if it returns. Invalid zero time never resumes deadline
consumers. A product may supply separately reviewed non-returning recovery;
normal stop/restart does not resume this terminal path.
No ISR polling, kernel calls or borrow release is authorized by this failure.
Stop observes timer, IRQ and added gate withdrawal before releasing effects.
Timing accuracy and latency remain physical measurements. Dynamic clocking,
bootloader handoff, NMI/HardFault time calls and deep STOP continuity are outside
this contract.

## GPIO and serial ownership

The Board selects PC7/LD1 active high and PA9/PA10 USART1/VCP AF7. Cold assembly
leases only selected pin fields, preserving adjacent pins and preexisting shared
GPIO clocks. Input/analog pins may be leased; locked, alternate-function and
output owners are rejected. Assembly observes all selected port gates, validates
all selected pin modes/locks, then captures leases before the first pin change.
A later rejected bank therefore cannot authorize restoration writes to an
earlier untouched port. Rollback first observes analog mode, then restores
latch and exact mux fields; failed cleanup retains lifecycle responsibility.

GPIO preloads and observes the output latch before publishing output mode.
Masked BSRR writes are direct hardware commands. Toggle requires serialization
with every owner of the same pins. Startup/stop are privileged task operations.

USART1 selects IRQ 61 priority 5, PCLK2=4 MHz, PRESC 1, oversampling 16, 8N1
and FIFO disabled. BRR is the rounded clock/baud divisor 16..65535; accepted baud bounds
are 62..250000. For 115200 the encoded divisor is 35, nominal 114285.7 baud, about
-0.794%; oscillator/remote errors require external electrical validation. The
IRQ moves at most one RX and one TX byte. Arbitrary positive ring capacities
use comparison wrap; read copies at most one queued byte per short masked
section and reports aggregate loss without replacing older payload.

TX borrows request and payload until final wire TC and source withdrawal precede
release-publication of SETTLED. Cancel/deadline begin drain; failed drain leaves
QUARANTINED storage borrowed. Stop joins captured wake callbacks and observes
UE/TEACK/REACK/NVIC withdrawal before releasing ring/wake references. Wake is a
hint, and selected kernel IRQ policy is validated before kernel notifications.

## Capability and physical limits

The maintained CPU tuple has DSP, FPv5-SP-D16, exactly eight MPU regions and
eight physical SAU regions. RM0456 revision 7 sections 3.5.2/3.7.1 specify eight
MPU regions; DS13737's broader wording "up to 16" is not an exact 16 guarantee.
The configured count retains its exact-match meaning: protected FreeRTOS rejects
hardware whose observed TYPE differs, including 16. This is not a lower-bound
or automatic MPU discovery field.
Selected single-state execution does not grant SAU access or a TrustZone broker.
The separate [dual-world software reference](../../docs/design/u575-trustzone-contract.md)
uses explicit Secure/NS builds and a cold-owner mechanism; its no-OS mapper
independently observes and initializes all 8 or 16 actual MPU regions. That
reference does not change this provider's TZEN0 contract or exact CPU tuple.
Optional DWT CYCCNT is disabled until its exact U575 implementation is reviewed;
a Cortex-M33 architecture string does not authorize a cycle-counter capability.
SoC ICACHE/DCACHE peripherals are disabled; their existence does not declare SCB
cache lines. GPDMA1 and LPDMA1 have distinct physical bus paths and linked-list
semantics, but **no DMA provider or descriptor authorization is implemented**.
SRAM2/3/4, backup SRAM and Secure aliases are not selected by this first provider.
Secure and NonSecure aliases never count as two physical capacities.

ES0499 Rev 12 section 2.21.1 describes receive corruption from a sub-half-bit low
glitch in the second half of a stop bit. Revisions W/U have no software workaround;
the stated measures are a noiseless line or an external glitch filter. IRQ error
flags cannot promise detection or noise immunity. Section 2.21.2 describes missing
DMA requests after clearing/re-setting DMAT. Its UE-cycle workaround excludes
receiver use; it is not claimed solved here, because all DMA modes are excluded.

The official Q-package inventory has 111 GPIOs, independently checked against the
package table and figure. Inventory does not expose 111 reviewed PCB routes.
Actual PCB revision, bridge states, supply/SMPS population, silicon revision and
option bytes remain unobserved. Model tests establish software contracts, and
real ARM ELF gates establish compilation/link/resources. Physical HIL remains
`not_executed`; neither static instructions nor clock-derived estimates are
measured cycles, WCET, safety certification or a product release.
