# STM32U575 single-state reference

This provider targets exact STM32U575ZIT6Q and the source-reviewed NUCLEO-U575ZI-Q
MB1549 reference. The maintained slice is CPU startup, reset-like MSIS 4 MHz,
reserved TIM2, exact-package GPIOA through GPIOH, USART1 PA9/PA10 and USART2
PA2/PA3 AF7 IRQ bytes, optional finite USART1 GPDMA TX with independent IRQ RX,
and an explicitly enabled independent watchdog. The default linker RAM
is SRAM1 192 KiB. It does not allocate storage or create tasks, workers or runtime
registries. The typed factory returns existing readonly faces; instances own
private state and share readonly GPIO/UART/watchdog operations. Each package GPIO
pad has a source-reviewed route; its inventory does not establish Board wiring.

The selected finite peripheral extension adds SPI1, I2C1, ADC4, TIM3 CH1,
EXTI0/1 and physical Flash. These reference selections keep TZEN0, MSIS4MHz,
static typed factory objects and caller execution. Those six selections add no
DMA engine, task, runtime registry or automatic clock adoption. The separate
USART1 `dma-tx` selection owns its exact GPDMA channel. The official U5 LL
headers are private, hash-locked CubeU5 v1.9.0 inputs; readonly configuration
queries, encodings and selected register operations are reused without HAL
handles, vendor IRQ callbacks, HAL ticks or a second transfer owner.

The official STM32U5 CMSIS device source is pinned to
`624374fa1e21ca195d6f2102ac0caaa50d0ea4c8` (v1.4.3, Cube v1.9.0). The original
Apache-2.0 license and ST notices remain intact. SDK register types remain private.
CMake selects only required source units and the official U575 startup; it never
links the vendor stock `SystemInit` alongside the owned implementation.

## Startup and execution

The only supported boot contract is **TZEN=0**, SWAP_BANK=0, one address state.
The reference never changes option bytes, security attribution or bank layout.
A station/boot owner must observe compatible option bytes before executing this
image. Reading an option register after startup cannot turn a TZEN1 boot into a
valid single-state boot, and cannot establish Secure/NonSecure isolation.

`SystemInit` executes before primary `.data` and `.bss`. It touches CPU CPACR,
VTOR and priority grouping through constant MMIO addresses and barriers. It
never reads or writes initialized context, `SystemCoreClock`, libc or a heap.
Post-RAM cold admission checks the effective MSIS range 4, selected clock/status,
equal HCLK/APB dividers, inactive PLLs and caches, Flash readiness, and unowned
TIM2/IRQ 45. Unknown running profiles fail before hardware writes. No RCC/power
reset sequence, automatic clock adoption or external crystal is needed.

TIM2 uses PSC 3, ARR 0xffffffff and IRQ 45 at priority 0 for a nominal
1 MHz domain.
Start observes the update generated by UG within the explicit bounded poll
budget, then observes UIF cleared before publishing a usable time domain.
A masked snapshot corrects one pending wrap and restores the incoming mask;
epoch validity is checked inside that same exclusion. The IRQ must execute at
least once every 2^32 microseconds. A refused runtime UIF acknowledgement records
`timer_error=NX_ERROR_IO`, invalidates time and retains timer ownership without
incrementing the overflow count. Finite ISR actions attempt DIER, CEN and NVIC
withdrawal once. The lost deadline domain is always terminal, including
successful isolation: preserve the terminal interrupt mask, call the platform
fault observer and park if it returns. Invalid zero time never resumes deadline
consumers. A product may supply separately reviewed non-returning recovery;
normal stop/restart does not resume this terminal path.
No ISR polling, kernel calls or borrow release is authorized by this failure.
Stop observes timer, IRQ and added gate withdrawal before releasing effects.
Cold admission excludes SMCR, CR2, CCER and CCMR trigger/channel state as well as
CR1/DIER. Because unclocked APB reads may return zero, it repeats this admission
after observing the TIM2 gate, before PSC, CNT or UG writes. A rejected foreign
timer releases only the added gate; it never clears foreign timer fields or IRQs.
Owned setup temporarily selects `MMS=1` while `CEN=0`, so UG cannot export the
reset-mode TRGO pulse. It observes update and clear, restores `MMS=0` before
starting the counter, and retains ownership if clearing its quiet mux fails.
Timing accuracy and latency remain physical measurements. Dynamic clocking,
bootloader handoff, NMI/HardFault time calls and deep STOP continuity are outside
this contract.

## GPIO and serial ownership

The Board selects PC7/LD1 active high and PA9/PA10 USART1/VCP AF7. The additional
PA2/PA3 USART2 and single-pad GPIO bindings are software reference selections;
connector availability, attached devices and electrical state remain unobserved.
PG[15:2] additionally require an externally prepared VDDIO2 rail, a live PWR
register clock and observed `PWR_SVMCR.IO2SV`. Cold preflight rejects missing
configuration before acquiring gates; the GPIO provider repeats the check before
pin effects. It never enables a supply monitor, changes isolation or infers rail
voltage from IO2SV. RM0456 10.4.5/10.6.3 supply sequencing and physical validation
remain the external Board power owner's responsibility. PG0/PG1 use VDD.
Cold assembly
leases only selected pin fields, preserving adjacent pins and preexisting shared
GPIO clocks. Input/analog pins may be leased; locked, alternate-function and
output owners are rejected. Assembly observes all selected port gates, validates
all selected pin modes/locks, then captures leases before the first pin change.
A later rejected bank therefore cannot authorize restoration writes to an
earlier untouched port. Rollback first observes analog mode, then restores
latch and exact mux fields; failed cleanup retains lifecycle responsibility.

GPIO preloads and observes the output latch before publishing output mode.
Masked BSRR writes are direct hardware commands. Toggle requires serialization
with every owner of the same pins. Startup/stop are privileged task operations.

Ordinary IRQ-byte USART1 selects IRQ61 with PCLK2; USART2 selects IRQ62 with
PCLK1. Both use
priority 5, 4 MHz, PRESC 1, oversampling 16, 8N1
and FIFO disabled. BRR is the rounded clock/baud divisor 16..65535; accepted baud bounds
are 62..250000. For 115200 the encoded divisor is 35, nominal 114285.7 baud, about
-0.794%; oscillator/remote errors require external electrical validation. The
IRQ moves at most one RX and one TX byte. Arbitrary positive ring capacities
use comparison wrap; read copies at most one queued byte per short masked
section and reports aggregate loss without replacing older payload.

TX borrows request and payload until final wire TC and source withdrawal precede
release-publication of SETTLED. Cancel/deadline begin drain; failed drain leaves
QUARANTINED storage borrowed. Stop joins captured wake callbacks and observes
UE/TEACK/REACK/NVIC withdrawal before releasing ring/wake references. Wake is a
hint, and selected kernel IRQ policy is validated before kernel notifications.

### Optional USART1 finite GPDMA TX

The maintained [normal TOML fixture](../../cmake/package/verification/io_evolution/u575-uart-gpdma.toml)
selects `dma-tx`: USART1 PA9/PA10 AF7,8N1/FIFO-off at4MHz; GPDMA1 channel0,
request25/IRQ29 and USART1 IRQ61, both priority5. Its single UART prefix retains
independent IRQ-byte RX; the selected-only extension does not grow ordinary
IRQ-byte state or operations. Each TX payload is1..65535bytes entirely within
nonsecure SRAM1 `[0x20000000,0x20030000)`.

DMA `TCF` does not prove wire `TC` or release the borrow. Active cancellation
uses fresh `SUSPF`/`IDLEF`, legal `RESET` and disabled/idle readback; its IRQ
preserves the actual suspension proof. ES0499 2.21.2 persistent `DMAT` is set
before first `UE` and stays high until whole stop proves UE/ACK, both vectors
and publishers joined. Failed withdrawal retains `QUARANTINED` storage.
The [complete execution and recovery contract](../../docs/design/u575-uart-gpdma.md)
explains caller progression, source/IRQ/wake join and exact limits.

Current development checks passed40 real-provider model cases,8 generated
factory cases and the normal ARM configure/build with linked resource and
provider-retention checks. They do not establish a clean-source full-gate
candidate, physical erratum qualification or measured cycles. HIL is
`not_executed`. USART2 DMA, RX DMA, linked lists, continuous streaming,
low-power/autonomous operation and a TrustZone broker remain unselected.

### Optional USART1 bounded hardware FIFO bytes

The independent `irq-fifo-bytes` selection uses USART1 PA9/PA10 AF7, 8N1,
priority 5 and the existing TZEN0/MSIS4 reference. Hardware RX/TX FIFO depth is
8 bytes per direction, with one additional RDR receive stage. Its explicit
thresholds and independent RX/TX byte budgets bound one handler entry. A
checked RX-not-empty fallback drains subthreshold tails without another IDLE;
per-head error ACK precedes RDR pop. TX space or FIFO-empty never substitutes
for wire TC. Cancel and stop retain storage until required source, vector,
publisher and UE/ACK withdrawal is proved.

Only this selected state adds a const-profile link. Ordinary UART state/ops,
initialization and the separate FIFO-disabled GPDMA mode remain unchanged.
The implementation shares one compile-time algorithm with the H743 selection
and uses the already pinned official U5 LL USART leaves. It does not enable
USART2 FIFO, DMA/FIFO combinations, non-8N1, flow control, TrustZone or
autonomous/low-power behavior. See the
[FIFO selection and lifecycle contract](../../docs/design/uart-fifo.md).
Its 45 real-provider and 9 normal-TOML/generated-factory model cases passed,
along with the selected normal ARM build, resource and retention checks.
Physical HIL is `not_executed`;
neither register counts nor model success establish noise immunity or latency.

优先级5，每方向 FIFO 为8字节，RX 另有1字节 RDR。阈值与每次中断 RX/TX 字节

## Independent watchdog

Static assembly only binds IWDG, RCC, FLASH and DBGMCU; it never starts the
watchdog or changes LSI. The application explicitly chooses enable, feed and
recovery policy. RM0456 Rev7 Chapter61 requires activation before PR/RLR shadow
updates; the provider retains `enabled=true, irreversible=true` on any later
failure. Platform stop cannot revoke activation or release a retained LSI gate.
Before activation, private stop retries withdrawal of only its added LSI enable
and debug-freeze change; failed withdrawal blocks another enable and remains
retryable through platform stop.
The bounded enable path observes LSI and debug-freeze writes, then observes
shadow synchronization and PR/RLR before reload. Failure bounds include mixed
old/new prescaler and reload values. Failed LSI startup withdraws only the enable
introduced by that attempt, preserving a preexisting shared source.

The maintained mode has window and EWI disabled and `LSIPREDIV=0`. A 250 Hz LSI,
foreign window/EWI or shadow update is rejected without adoption. Unlike F4,
the U5 four-bit PR supports divisors /4 through /1024. Nominal timeout range is
375 us through 131072000 us. The minimum reload is two, as recommended by
RM0456 61.7.3. DS13737 Rev10 Table84 characterizes LSI at
30.4--33.6 kHz over its declared voltage/temperature range; reported bounds use
that envelope and are not physical measurements. Refresh must occur before
counter one. Hardware-option activation is observed without reprogramming;
unmaintained prescaled or updating option-start state reports `UNSUPPORTED` with
the irreversible effect retained and unknown timeout fields zero. Reset causes
come from captured boot flags without acknowledging hardware; BOR alone does
not invent a separate power-on cause.

The maintained `mainstream.toml` and `mainstream-freertos.toml` fixtures select
both USARTs, eight GPIO banks and an inactive watchdog. They exercise actual
static construction, selective CMake sources, ARM linking and SDK consumption.

## Selected errata controls

The source review uses official ES0499 Rev12, June2026, PDF SHA256
`52dac38c801ae72c42ebffd39296ddf7c80ae378cd555f1a1d1baf49daf86a56`.
SPI keeps CRCSIZE=7 even with CRC disabled to address2.23.1, accepts the real
reset CFG1 fields, and waits one actual SCK period plus two1MHz timer ticks
after EOT/TXC before reset to address2.23.7. Poll counts are progress bounds,
never measured microseconds. I2C uses the reviewed2.20.2 spurious master BERR
clear-and-continue policy. A separately acquired HSI16 kernel avoids the
4MHz MSI tolerance boundary in2.20.1 while preserving the4MHz system and1MHz
TIM2 domain. At DS13737 Table81's15.65..16.25MHz envelope, the selected
prescaler/counters give low/high periods above5.9us and SCLDEL above1.96us,
allowing rise<=1000ns/fall<=300ns and Standard250ns setup. Package/solder,
pull-up and real bus timing still require station measurements. Cold admission
rejects foreign HSI/HSIKERON or I2C1SEL owners and nondefault HSITRIM;
factory calibration is preserved without rewriting the trim. Failed source/mux withdrawal
retains ownership and blocks global teardown. H7-only receive reload policies
are not inferred for U5.

ADC4 admission rejects an enabled ADC1/2 interface owner to keep the selected
single-converter contract separate from2.9.1 simultaneous-conversion conditions.
It does not adopt ADC12 prescalers or linearity state. Calibration must be
observed as accepted before waiting for completion; regulator/ready/sample
status flags must be observed clear before new evidence can be accepted.
The declared reference is1000..3600mV per ADC4 Table106; external VDDA must be
at least1.62V and at least VREF+. Neither the number nor ASV measures supply
quality. Flash never starts an
erase while WDW is set, and supplies all four quad-word writes before another
operation, excluding the2.2.25 partial-write-buffer/STRT sequence. Its geometry
declares fresh-erase provenance: callers must erase a sector before programming
each16byte unit once, and erase again after a failed/interrupted pulse. Visible
non-FF targets reject before unlock; FF reads cannot prove hidden ECC history.
All-FF source units issue no programming pulse.
Every physical pulse requires observed clearing of previous EOP/error flags
and a fresh EOP after BUSY/WDW drain; idle status alone cannot certify a refused
erase/program command. RM0456 gates EOP with EOPIE, so admission exclusively
leases a disabled/inactive/not-pending FLASH IRQ; checked EOPIE is set for the
pulse while NVIC stays disabled. Cleanup clears mode/EOPIE and locks before
observing pending withdrawal, preserving IRQ priority. Failed cleanup retains
the port for retry and blocks global teardown. Low-power,
autonomous modes, SPI CRC/Ready, advanced timer break/ocref_clr and Flash option
programming are not selected by these finite providers.

## Capability and physical limits

The maintained CPU tuple has DSP, FPv5-SP-D16, exactly eight MPU regions and
eight physical SAU regions. RM0456 revision 7 sections 3.5.2/3.7.1 specify eight
MPU regions; DS13737's broader wording "up to 16" is not an exact 16 guarantee.
The configured count retains its exact-match meaning: protected FreeRTOS rejects
hardware whose observed TYPE differs, including 16. This is not a lower-bound
or automatic MPU discovery field.
Selected single-state execution does not grant SAU access or a TrustZone broker.
The separate [dual-world software reference](../../docs/design/u575-trustzone-contract.md)
uses explicit Secure/NS builds and a cold-owner mechanism; its no-OS mapper
independently observes and initializes all 8 or 16 actual MPU regions. That
reference does not change this provider's TZEN0 contract or exact CPU tuple.
Optional DWT CYCCNT is disabled until its exact U575 implementation is reviewed;
a Cortex-M33 architecture string does not authorize a cycle-counter capability.
SoC ICACHE/DCACHE peripherals are disabled; their existence does not declare SCB
cache lines. GPDMA1 and LPDMA1 have distinct physical bus paths and linked-list
semantics. Only the exact finite USART1/GPDMA1 TX selection above is maintained;
LPDMA1, linked-list descriptors and RX DMA are not selected. SRAM2/3/4, backup
SRAM and Secure aliases are outside this maintained DMA source domain.
Secure and NonSecure aliases never count as two physical capacities.

ES0499 Rev 12 section 2.21.1 describes receive corruption from a sub-half-bit low
glitch in the second half of a stop bit. Revisions W/U have no software workaround;
the stated measures are a noiseless line or an external glitch filter. IRQ error
flags cannot promise detection or noise immunity. Section 2.21.2 describes missing
DMA requests after clearing/re-setting DMAT. Its UE-cycle workaround excludes
receiver use. The selected USART1 DMA provider instead uses the documented
persistent-DMAT workaround described above, retaining independent IRQ RX.
Register-model passage does not establish the physical workaround's silicon
revision or station qualification.

The official Q-package inventory has 111 GPIOs, independently checked against the
package table and figure. Inventory does not expose 111 reviewed PCB routes.
Actual PCB revision, bridge states, supply/SMPS population, silicon revision and
option bytes remain unobserved. Model tests establish software contracts, and
real ARM ELF gates establish compilation/link/resources. Physical HIL remains
`not_executed`; neither static instructions nor clock-derived estimates are
measured cycles, WCET, safety certification or a product release.
