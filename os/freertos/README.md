# FreeRTOS：显式静态内核适配

本目录将锁定的官方 FreeRTOS 内核及精确 CPU 端口连接到 Nexus 等待、任务、队列
和通知合同。公开声明在 `include/nexus/os/freertos.h`，普通实现为
`freertos.c`；`CMakeLists.txt` 选择内核和端口，`lowpower.c` 处理可选无节拍
空闲，`hooks.c` 提供保留资源责任的故障停机路径。

## 构建与资源

CPU 事实决定真实 M0／M3／M4F／M7／v8-M 端口及 FP／MVE／安全态 ABI，不能统一
套用 CM4F。普通配置启用静态分配，关闭动态分配和软件定时器后台任务，不链接
`heap_*.c`。调用者提供任务控制对象、栈、队列有效数据和明确容量。普通配置的
Idle 可以使用内核提供的静态存储；MPU／分域安全配置要求应用提供对应 Idle
TCB／栈。默认不创建产品工作线程。

`nx_platform_start()` 不启动调度器。应用在合法冷态中显式进入真实内核，
负责任务拓扑、执行进度、公平性和停机。普通运行 API 要求特权线程模式，且
PRIMASK、BASEPRI、FAULTMASK 清零；启动前规范屏蔽状态是独立例外，详见
[OS 总览](../README.md)。内核 ISR 唤醒还核对真实异常范围、优先级分组和系统
调用上限。

## 请求与任务退出

通知只提示重查判定条件。可返回任务发布完成后挂起，唯一外部退出会合者完成
真实删除，再回收控制对象、栈和上下文。退出等待超时保留存储，不得凭完成提示
提前复用。永久任务和直接通知是独立可选路径；只有不需要退出等待的任务才能
选择相应较小控制对象。

可关闭队列另带调用者控制对象和每操作等待者。关闭后拒绝新发送，允许旧数据
排空。关闭准入后继续推进服务，结清请求，等待生产者和资源责任者退出，撤销
全部 IRQ 发布者，最后销毁通知、队列及保护区。复制队列成本随单项大小增长，
关闭广播随等待者数增长。

## 可选配置与证据

[MPU](mpu/README.md)和 [Secure companion](secure/README.md)是显式独立配置，
不会使普通 I/O 自动可从非特权或另一安全域调用。无节拍空闲必须绑定完整定时器
端口及连续时钟，不代表任意 SoC 已具备深睡眠接入。
