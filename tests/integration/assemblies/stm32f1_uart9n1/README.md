# STM32F103RB USART2 9N1 软件参考

选用 HSI8、PA2 发送、PA3 接收。应用通过强类型 factory 获取
`nx_uart_word_port_t`，每个 `uint16_t` 保存一个 0～511 的字，
请求长度和完成计数都以字为单位。DMA、校验、硬件流控和地址唤醒不在此模式内。

USART2 IRQ 只负责接收、填充发送寄存器和记录实际 TC。
调用者通过 `nx_uart_word_port_service` 推进超时、回收及停止。
取消后要等待最后一个已装载的字发完，撤回发送 IRQ 后才能回收请求。
接收出错或溢出时保留旧字，读取报告丢失。

示例按 115,200 baud 请求生成 BRR=69，HSI 标称 8 MHz 时约为
115,942 baud。该值属于分频计算。外接九位通信端点、板桥接、连线及波形
需要实板验证。Nucleo 默认 ST-LINK VCP 接线不是此软件参考的九位链路。
