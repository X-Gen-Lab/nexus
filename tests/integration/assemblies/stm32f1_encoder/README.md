# STM32F103RB TIM3 正交编码器软件参考

`f103rb-tim3.toml` 选择 HSI8 裸机和 TIM3 的默认引脚。PA6 对应 TI1，
在 NUCLEO-F103RB 上接到 Arduino D12。PA7 对应 TI2，接到 D11。
两脚均为浮空输入，需要外部驱动的兼容电平和公共地。选定模式以 x4 计数，
独立设置每相极性和输入滤波，滤波时钟为标称 8 MHz。

`nx_encoder_read()` 读取一次 16 位模计数和软件观测时间。停止保留计数。
关闭释放整个定时器并恢复引脚字段。该装配独占 TIM3，无法同时选用
TIM3 PWM 或 TIM3 TRGO 的 ADC 触发。TIM1 CC1 触发仍可独立选用。
没有 IRQ、DMA、扩展计数、输入采样队列或产品位置计算。

RM0008 Rev21 第 15.3.12 节与所锁定 ST HAL／LL 对 x2 的 TI1、TI2 标签存在差异。
本参考只选用共同定义的 `SMS=011`。ES096 Rev15 第 2.3.8 节的重映射路线
在冷态被拒绝。第 2.6.5 节涉及捕获寄存器读取，本实现只读 `CNT`。
D12、D11 路线来自 UM1724 Rev17 表 12，封装引脚来自 DS5319 Rev20 表 5。

测试验证配置、寄存器状态与链接产物。实际转向、输入噪声、滤波时延和可用
边沿速率待实板验证。
