# STM32F103RB USART2 单线半双工软件参考

装配选择 HSI8、PA2 复用开漏、8N1 和字节 IRQ。使用外部上拉。
HDSEL 将内部接收通路接到 PA2，PA3 保持原用途。

空闲时接收器开启。提交先检查线电平和待处理 RX 状态，再切换为发送。
写入最后一个字节后等待新的 TC，IRQ 随即撤回 TX 并恢复 RX。
请求归还还需通过任务服务。取消已发送部分时沿用相同的撤回顺序。

产品负责节点间仲裁与对端周转时间。一次空闲电平采样只能决定本端
是否尝试启动。外部上拉、总线电容、对端时序和实板桥接均需验证。
此装配使用外部半双工端点，Nucleo 默认 ST-LINK VCP 电路是独立路径。
