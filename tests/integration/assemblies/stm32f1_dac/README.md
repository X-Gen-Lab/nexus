# STM32F1 DAC1 软件装配

三份参考分别选择 STM32F100RBT6B、STM32F103ZET6、STM32F103ZGT6，均以
HSI8 运行 DAC 通道 1，输出连接 PA4。应用从强类型
factory 获取通用 DAC 接口，显式启动，写入原始码，再恢复空闲码和释放。
提供 8 位和两种 12 位数字格式，选定装配使用 12 位右对齐。没有任务、
IRQ、触发、DMA 或双通道输出。输出电压和负载条件需由实板验证。

资料见 RM0041 Rev6 §11.3、RM0008 Rev21 §12.3、DS6329 Rev9 表 46、
DS5792 Rev13 表 63 和 DS6558 Rev4 表 66。
