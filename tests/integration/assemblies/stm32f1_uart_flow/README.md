# STM32F103RB USART2 RTS/CTS 软件参考

选择 HSI8、8N1 和接收事件。PA0 为低有效 CTS，PA1 为低有效 RTS，
PA2／PA3 负责发送和接收。PA0 上拉，PA1 在接收器准备前保持不就绪。

CTS 不就绪时，硬件可能保留一个已经写入 TDR 的字节。取消停止继续
写入，但已装载字节仍等待对端允许发送。取得实际 TC 后，任务才归还
请求并报告已退出硬件的字节数。对端长期阻塞时，请求保持隔离，
平台停止返回忙。

事件环满前，或发现 ORE 时，驱动按 ES096 §2.9.6 在读取 DR 前将
PA1 保持高电平。接收者释放空间且 RX 状态清空后再恢复硬件流控。
驱动保留旧事件并报告丢失。勘误中对端违规后、ISR 读取状态前的
引脚波形仍属于硬件行为。LIN break 与 CTS 组合属于 ES096 §2.9.5
的限制范围，当前模式仅接受字节请求。

实板连线、对端时序、IRQ 延迟和电气波形尚未测量。
