# STM32F103RB USART2 同步主机软件参考

USART2 使用 PA2 发送、PA3 接收、PA4 输出 CK。16 分频过采样适用
异步接收；同步模式由 CK 直接采样。发送有效负载才产生时钟，
起始位、停止位和空闲期间无时钟。应用通过现有 UART TX 请求发送数据
或填充字节，再读取相应的 RX 事件。片选由上层设备协议管理。

该参考装配固定为 8N1 和 HSI8，选择 CPOL=0、CPHA=0、LBCL=1
（为第 8 位发送时钟）。请求 115,200 baud，BRR=69，标称位率约
115,942 bit/s。可在同一装配模型中选择另外的极性、边沿和末位时钟
组合。对端时钟约束、时序与信号完整性须用实板确认。

ES096 Rev15 §2.3.2 和 §2.3.3 约束 PA4 上的 USART2 同步时钟。装配
独占 SPI1 资源，启动也会拒绝已启用的 SPI1 时钟。SPI1 软件片选
绕法需改变另一个控制器的配置，参考实现不使用这一绕法。
