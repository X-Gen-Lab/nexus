# STM32F100RB HDMI-CEC 软件参考

裸机装配固定 STM32F100RBT6B、HSI8、PB8 和 CEC IRQ 42。PB8 使用复用开漏，
外接 27 kΩ 上拉至 3.3 V。板级配置保留 PB8、控制器和向量，示例负责申请与释放。
连接实际总线前，由板级所有者确认接口、电气环境和已分配逻辑地址。示例使用逻辑
地址 4，向地址 0 发送一次首部轮询。

驱动复制发送数据，每次最多一个 16 字节原始帧。接收队列保留第一个已完成帧，
后续未取出的帧直接丢弃。发送状态区分完成、无应答与其他线路错误，驱动不提交
额外重试。关闭等待硬件报告空闲，超时保留 IRQ 和引脚供调用方重试。实际电气
和总线互操作性待实板验证。

实现依据 RM0041 Rev6 表 47、§24.3.1、§24.7.2 及 §§24.7.7–24.9.5，
DS6517 Rev9 表 4 和 ES093 Rev8。
