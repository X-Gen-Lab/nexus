# STM32F103ZE SD 卡软件参考

STM32F103ZET6 使用 HSI8、单线轮询和 SD v2 高容量卡。接线为 PC8 D0、
PC12 CK、PD2 CMD 和 PC13 低有效卡检测。软件参考假定独立 3.3 V 供电、
CMD／DAT 外部上拉和已消抖的卡检测。实际 PCB、电气和卡兼容性待实板验证。

Platform 启动取得引脚。调用者通过 typed factory 获得端口后用 `activate` 识别
卡片。读取一次最多一个 512 字节扇区。引脚和主机在 `stop` 确认撤回后释放。
板级所有者确认拔卡后通过 `media_removed` 报告，再停止和重新识别。

`ze-1bit.toml` 默认只读。`ze-1bit-write.toml` 显式选择 `sdio-poll-write`，
仅在卡片 CSD 声明支持 512 字节写入、容量属于 SDHC 且未写保护时开放单扇区
`CMD24`。确认进度要求正向数据 CRC 状态和卡片以 `CMD13` 回到传输就绪状态。
失败时当前扇区可能已改变，调用方通过同步或停止确认当前状态。主机时钟固定在
约 364 kHz，符合 ES0340 Rev17 §2.13.6 的单线发送约束。固件示例只提交越界
写请求验证拦截，然后读取第一扇区。成功写路径由 Native 模型验证，实卡写入待测。
