# STM32F103RB TIM1 / ADC1 有限采样反馈

`f103rb-cycle.toml` 用一个静态 `nx_pwm_adc` 实例独占 TIM1 和 ADC1。
TIM1 在 8 MHz 计数，周期为 2,048 ticks。CH1 和 CH1N 对应 PA8、PB13，
PB12 为低有效 BKIN。内部 CC4 比较在第 512 tick 触发 ADC1 的 PA1
注入转换。采样配置的 41 个 ADC 周期占约 82 个定时器 ticks。
该装配关闭 CH4 输出、ADC DMA 和自动重启。默认固件保持 PWM 停止。

单脉冲模式在周期更新时停止计数。更新 IRQ 撤销 MOE，核对本窗口的 CC4 和
JEOC，并锁存当时的 12 位转换结果。迟到转换和后续寄存器值无法改写已锁存的结果。
任务在截止时间前取得记录，验证 PWM、触发和中断排空后才交付单次采样。
无法确认安全退出时保留原请求，继续 service 或执行显式停止。
硬件 BKIN 独立于任务和 IRQ 起作用。实际引脚停止延迟还需测量。

显式启用断开负载的探针后，示例最多运行四次窗口。每次结算成功后，将原始
ADC 码反向映射到下一次的合法占空比区间。窗口失败即终止序列并停止平台。
此组合只验证单路 PWM 与单路 ADC 的反馈链路。三相电流采样、门极驱动及
电机闭环的验收需要独立装配与实物。依据 RM0008 Rev21 表 68、§14.3.15，
DS5319 Rev20 表 5 和 ES096 Rev15 §§2.5.1、2.6.1–2.6.3。

## 三路互补输出和单路采样的软件参考

`f103rb-three-legs.toml` 使用 TIM1 默认映射。PA8～PA10 与 PB13～PB15 是三对互补
输出，PB12 是低有效 BKIN。每个完整请求提供三个占空比和一个 PA1 原始 ADC 样本
的缓冲区。三个比较值在定时器停止且 MOE 关闭时写入并核对，用一次更新装入预装载值。
第三路写入失败、任一路占空比超出固定采样窗口或 BKIN 有效时，不会开启输出或提交
有效样本。撤回过程核对六路 GPIO、使能位、计数器和中断，成功后才归还请求。

这个参考用于无负载的软件和探针验证。TIM1 单脉冲停止计数，周期结束 IRQ 撤回 MOE。
真实 IRQ 延迟、输出脉宽、门极驱动时序、相电流采样与电机闭环均需另行验证。本装配的
ADC 只有 PA1 一路，因此公共接口继续报告一个样本。参考 RM0008 Rev21 表 46、68 和
§14.3.11～14.3.15，DS5319 Rev20 表 5，以及 ES096 Rev15 §2.6.1～2.6.4。
