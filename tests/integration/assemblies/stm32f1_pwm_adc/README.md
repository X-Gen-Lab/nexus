# STM32F103RB 单次 TIM1 / ADC1 软件窗口

`f103rb-cycle.toml` 用一个静态 `nx_pwm_adc` 实例独占 TIM1 和 ADC1。
TIM1 在 8 MHz 计数，周期为 2,048 ticks。CH1 和 CH1N 对应 PA8、PB13，
PB12 为低有效 BKIN。内部 CC4 比较在第 512 tick 触发 ADC1 的 PA1
注入转换。采样配置的 41 个 ADC 周期占约 82 个定时器 ticks。
该装配关闭 CH4 输出、ADC DMA 和自动重启。默认固件保持 PWM 停止。

单脉冲模式在周期更新时停止计数。更新 IRQ 撤销 MOE，并记录这次窗口
是否观察到新的 CC4 和 JEOC。窗口结束后观察到的迟到转换无法补全这份记录。
任务在截止时间前取得记录，验证 PWM、触发和中断排空后才交付一个 12 位值。
无法确认安全退出时保留原请求，继续 service 或执行显式停止。
硬件 BKIN 独立于任务和 IRQ 起作用。实际引脚停止延迟还需测量。

配置供断开输出和负载的工装验证。没有上电执行证据，也没有电机控制、
驱动器死区或同步采样精度的结论。依据 RM0008 Rev21 表 68、§14.3.15，
DS5319 Rev20 表 5 和 ES096 Rev15 §§2.5.1、2.6.1–2.6.3。
