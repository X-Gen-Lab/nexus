# STM32F103RB USART2 IrDA SIR 软件参考

PA2 接外部光学收发器的发送输入，空闲为低。PA3 接接收输出，
空闲为高。装配使用普通功耗 SIR、8N1 和 PSC=1，启用编码器后才
将 PA2 交给 USART。光学收发器的电源与使能由集成方控制。

HSI8 下请求 115,200 baud，按上取整选择 BRR=70。标称速率约
为 114,286 baud，正常模式脉冲宽度为位周期的 3/16。实测速率、
光学波形和收发器极性仍待验证。

软件独占切换发送和接收，发送完成的 TC 后保持至少 10 ms 才重开
接收，再归还请求。TC 已经观察到时，之后的周转等待不改变请求结果。
接收线电平和待处理状态只用于本地准入。对端收发轮次由上层协调。
