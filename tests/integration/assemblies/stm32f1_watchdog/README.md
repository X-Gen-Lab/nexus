# STM32F103xB IWDG 软件候选

应用通过 `nexus/io/watchdog.h` 获取独立看门狗端口，平台启动只发布 owner。
激活前验证当前 HSI8 / APB1 8 MHz 配置，并确认硬件影子寄存器可写。
开启 LSI 时记录软件取得的位，启动失败仅撤回本次取得的 LSION。
等待 LSIRDY 后继续等待 128 个标称微秒，再通过官方 LL 写入启动密钥。
密钥寄存器为只写。驱动先记录不可逆状态，启动后等待 PVU 和 RVU 都清除，
核对配置值，再发第一次喂狗。写入后的失败保留 owner，后续允许产品决定
继续喂狗或复位。硬件选项字节先行启动时也会保留同样的所有权。

RM0008 Rev 21 §19 和表 96 定义 40 kHz 标称时钟与 100 至 26,214,400 µs
标称范围。DS5319 Rev 20 表 25 的频率范围在 3.0 V 条件下表征。当前
3.3 V 软件参考中，公共接口的最小和最大超时均保留为未知。
ES096 Rev 15 §2.2.2 限制 CPU 读取 DBGMCU。驱动拒绝 CPU 管理的 debug
freeze 请求，避免将读取结果误作外部调试器配置。
ES096 §2.2.12 要求 LSIRDY 之后再等待至少 100 µs。§2.7.1–2 要求 APB
时钟大于看门狗时钟两倍。§2.7.3 要求进入 Stop 前等待 RVU/PVU 清除。
候选仅在已启动的 HSI8 运行时启动软件看门狗。本候选没有添加低功耗路径。

参考固件仅查询状态，软件选项空闲时关闭平台。GoogleTest 验证生产 C
启动、配置和失败恢复路径。实板启动、超时复位和复位原因仍待验证。
