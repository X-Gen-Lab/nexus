# STM32F103RB TIM4 输入捕获

这个软件参考配置将 NUCLEO-F103RB 的 D10（CN5 引脚 3）接入 TIM4 CH1。UM1724 Rev17 表 12 和 DS5319 Rev20 表 5 记录了这条连接。使用具有兼容逻辑电平和公共地的外部信号源，在 1 MHz 标称计数频率下捕获上升沿。TIM4 原始计数为 16 位，事件的观察时间取自平台 TIM2。硬件时钟精度和物理信号仍待实板验证。

TIM4 独占 PB6，并为 ES096 §2.6.5 补救措施保留 EXTI6 和 EXTI9_5 IRQ。应用提供事件队列，在停止返回 `BUSY` 后读取剩余事件，再尝试停止并归还队列。捕获报告可观察到的丢失迹象，事件字段保留硬件回环计数。
