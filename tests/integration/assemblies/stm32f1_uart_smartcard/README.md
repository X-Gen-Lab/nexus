# STM32F103RB USART2 Smartcard 软件参考

PA2 为双向开漏数据，空闲时由外部上拉保持高电平。PA4 输出连续时钟，
PA3 未占用。外部接口负责电平、电源、卡片复位和激活时序。该装配没有
绑定实际读卡器。

HSI8 的 APB1 标称为 8 MHz。PSC=1 将 PA4 分频到 4 MHz，BRR=744
给出 372 个卡时钟周期每 ETU。硬件模式固定为 8E1.5。参考设置的
GT=2 使 TC 在 guard time 结束后置位。

应用通过普通 UART 接口一次发一个字符，通过 RX 事件取得接收数据和
错误。发送期间接收器仍开启，以便观察对端 NACK。驱动将该字符的
无 RXNE 帧错误归为 NX_ERROR_NACK，等到 TC 才归还缓冲。应用协调收发轮次并决定是否重发。配置的自动 NACK 只控制接收奇偶错误时的硬件反馈。ATR、PPS、
重试次数和卡电源控制由上层实现。

ES096 §2.9.1／§2.9.3 要求保留提前出现的奇偶错误。驱动等待 RXNE
后读 DR，并取消可能覆盖此错误的排队发送。

PA4 与 SPI1 共享交叉复用，参考装配独占 SPI1 资源。卡接口的电气
时序与连续 CK 波形仍需实板测量。
