# STM32F1 ADC 软件参考

此装配通过公共工厂取得 PA0 的 ADC1 接口，查询 12 位格式和标称转换
时间，然后执行一次有截止时间的常规组软件采样。固件检查一个原始值
和停机结果。参考配置不要求固定读数。

ADC 使用 HSI8、APB2 /1、ADCPRE /2，标称 ADC 时钟为 4 MHz。
采样编码 5 选择 55.5 个采样周期，合计 68 个 ADC 时钟，标称 17 µs。
噪声、转换误差与物理时间由产品验证。
配置中的 3300 mV 为标称 VDDA/VREF+；PA0 位于 A0、CN8-1。
接入实际信号前须按 DS5319 表 47/48 确认输入范围、参考电压和源阻抗。

实现启动时校准，超时后中止转换。停止状态无法回读时保留门控和引脚
所有权等待重试。常规组接入不使用 ES096 §2.5.1 涉及的注入触发。
硬件采样精度及波形尚待实板验收。

可选的 `f103rb-trigger-dma.toml` 通过同一 ADC 工厂与调用方式取单个 PA0
样本。TIM3 以名义 8 µs 的一次性 Update TRGO 触发常规组，DMA1 通道 1
把一次半字结果写入驱动的静态 SRAM。固件观察完成或错误后撤回事件、
ADC 请求和 DMA，再发布样本。该装配与占用 TIM3 的 PWM 装配互斥。
截止时间由仍运行的 TIM2 判断。采样和触发的物理时序待实板验收。

`f103rb-tim1-trigger-dma.toml` 使用 TIM1 CC1 → ADC1 常规组 → DMA1 通道 1。
RM0008 表 67 对应 `EXTSEL=000`。TIM1 从复位空闲状态取得专用计数器，
以 1 MHz 计数，在计数 2 产生内部匹配，并在第 8 个周期停止。
`CCER`、`BDTR` 和中断源保持零，配置独占 TIM1，无法与其互补 PWM 装配同时使用。

完成需同时证明 CC1 匹配、单脉冲停止、DMA 减至零及写入通道排空。
ADC 触发在 DMA 准备后才启用。超时或错误后停止计数和 ADC，再撤出 DMA。
业务只接收成功复制的单个原始值。该参考提供内部触发采集的软件证据，
实板采样孔径、功率输出和闭环行为尚未测量。

## STM32F103ZET6 双 ADC 常规同步模式

`f103ze-pair.toml` 通过 `nx_adc_port_sample` 取得一对有序的 12 位原始值，
依次对应 ADC1 的 PA1 和 ADC2 的 PA2。两路必须选择相同的采样窗口。
默认窗口含 28.5 个采样周期，两路并行转换，共用 41 个 ADC 时钟周期，
在 4 MHz ADC 时钟下标称为 10.25 µs。

ADC1 启动两路常规组，DMA1 通道 1 把 ADC1_DR 的一个 32 位字写入
驱动内部 SRAM。只有两路完成且 DMA 地址撤回后，应用才收到这一对样本。
选择该装配时独占 ADC1、ADC2、对应引脚和 DMA1 通道 1。
软件参考使用 LQFP144 的 35、36 脚，实际板级接线、参考电压、源阻抗、
两路采样偏差依据 DS5792 表 5、59、60 做实板核验。
