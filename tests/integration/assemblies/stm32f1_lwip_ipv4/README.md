# STM32F107 MB784 MII 与最小 lwIP 软件参考

装配复用相邻 MII 板卡事实。平台启动后，通过同一控制器的强类型 factory
取得连续帧 Ethernet 和 MDIO。DP83848 协商只广告 10／100 Mb/s 全双工。
取得真实 PHY 链路事实后，示例才使 MAC 与 lwIP 接口进入链路启用状态。

装配选择 NO_SYS 的 network-ipv4，只运行 IPv4、ARP 和 ICMP。内存由
4 KiB lwIP 静态堆、4 个 512 字节的 pbuf pool、两个 MAC RX 缓冲、
一个 MAC TX 描述符以及一个对齐的应用 TX 缓冲组成。校验和由软件计算。
TCP／UDP、硬件校验和、VLAN、散布聚集、PTP 和随机回调均未选用。

示例私有适配器为 lwIP 提供单片段视图，保留原始 MAC RX 令牌直到
成功归还。出站使用单独的原始 TX 请求，只在它完成后归还上层请求。
示例在任务侧驱动协议栈，按有限时间和次数重试关闭。复位撤回失败会
保留静态存储和借用，重启整条 MAC 会话才能重新打开链路。

软件验收覆盖真实锁定的 lwIP ARP 应答、RX 归还失败重试、TX 复位期间
保留借用和 ARM 链接。实板连线、PHY 自协商和实际流量仍待验证。

## UDP 和 TCP 软件装配

`f107vc-network.toml` 使用现有 `network` 复制接收配置和 `Nexus::LwIPTCPStorage`。
它复用同一 MB784 MII PHY、帧桥接和退场顺序，增加一路 UDP 收发入口和一个 TCP
客户端。两个传输共享同一个 NO_SYS 前台执行域。停止时先撤回 PCB 和 TCP
缓冲，再停止适配器并归还 MAC。配置为 112 KiB Flash 和 52 KiB 静态 SRAM
上限，包含 2 KiB 主栈预留，使用 lwIP 的 16 KiB 静态堆和 24 项接收池。

软件夹具的 `fixture_seed` 默认为零，零值会在硬件启动前退出。测试人员可
在隔离工装中显式设置非零种子，测试流量使用文档网段 192.0.2.0/24。夹具的
可重复随机序列用于软件验证，产品接入须对接自己的熵源。当前证据覆盖构建、
接口保留和资源预算。线缆收发、对端互通及时间指标待实物验证。
