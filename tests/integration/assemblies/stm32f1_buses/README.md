# STM32F103RB Morpho 轮询总线软件参考

此装配固定使用 HSI8 裸机。I2C1 采用 PB6/PB7 默认路线、80 kHz 标称
标准模式和地址 0x50。SPI2 采用 PB13/PB14/PB15、PB12 低有效片选、
模式 0 和 1 MHz 标称时钟。编译、链接及资源检查使用公共工厂、控制器
及端点入口。固件初始化资源和查询接口，未发送 I2C 或 SPI 事务。

I2C 引脚对应 Morpho CN10-17/CN7-21。实际总线需确认外部上拉、负载、
公共地、目标地址和上升时间。80 kHz 给 HSI 容差留余量并遵从 ES096
对标准模式重复 START 不超过 88 kHz 的限制。短读按芯片手册控制
ADDR、ACK、POS，并在勘误规定窗口通过开漏方式保持 SCL。

超时或启动错误只复位本地控制器。检测到线路持续为低时，保留复位
和所有权。持续 BUSY 需要板级验证和恢复，不自动发送清除时钟。
C 模型覆盖正常传输、异常和停止路径。实板波形、设备交互及物理验收未执行。

来源为 ST UM1724 Rev17 表 27、RM0008 Rev21 §25/§26、ES096 Rev15 §2.8。
