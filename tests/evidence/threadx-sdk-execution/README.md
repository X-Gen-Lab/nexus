# Installed SDK ThreadX real Native execution

The external product uses only public installed Nexus targets and the same pinned
GoogleTest 1.16 framework. Two fresh, unfiltered cases run inside the actual
official Linux kernel: arbitrary-byte queue and final kernel task deletion, then
monotonic notification. The permanent coordinator resets the entire host process
after Google writes its XML; it never stops clocks under a live kernel.

The package is an unsigned dirty-source development fixture. Its exact full
manifest, commands, reports and failed setup attempts are retained as original
bytes. This record does not rewrite the separate 31-case SDK suite or establish
clean candidate, MCU execution, physical clock-step, stack peak or HIL results.
