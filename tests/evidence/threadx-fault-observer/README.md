# ThreadX terminal observation

Three new regressions first fail against the prior production source: two
actual official-kernel callback faults and one mocked external timer failure.
The central observer runs before an overridden product hook with the real domain,
result and static location. Full fresh execution then passes 53 Google cases,
26 configuration cases, nine Linux overlay cases and strict owned-file style.
A separate intermediate run passes its tests but fails the peer Core fault-file
format gate; that original failure remains retained.

The public failure contract now accurately allows masked, ISR and unprivileged
fault callers. Observation is best-effort, does not repair context, and never
authorizes reclaiming borrowed storage. These development tests establish no
physical reset, safe output, fault-stack reliability or HIL result. The earlier
50-case frozen source/evidence remains an independent immutable record.
